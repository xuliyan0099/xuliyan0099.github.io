    工厂方法模式FACTORY METHOD

    物流系统一开始只有卡车，后来加了轮船、飞机。如果“造哪一种”写死在客户端，每加一种交通工具就要改一遍下单代码。工厂方法把这句 new 挪进工厂：客户端只传类型名，工厂返回已经造好的产品。

    客户端不 import 具体类新增产品只加工厂C 用创建函数表 · C++ 用虚函数

    01问题：坏代码长什么样

    坏写法是客户端自己判断：

    Transport *t;
if (strcmp(type, "truck") == 0)      t = truck_new();
else if (strcmp(type, "ship") == 0)  t = ship_new();
else                                 t = NULL;

    它有三个问题：新增“飞机”要改这里；每个调用方都得抄一遍判断；测试要覆盖所有分支组合。

    工厂方法只做一件事：把“选具体类”从客户端搬到工厂。客户端拿到的是统一的产品接口，只调 deliver()，不再关心轮子还是螺旋桨。

    02结构：客户端、工厂、两个产品

    左边是下单方，中间是工厂，右边是两种产品。点方框看它负责什么。

    客户端只认工厂，不认具体运输工具structure
    职责工厂是唯一知道“有哪些产品”的地方；产品只负责自己的业务。

    03两份实现：C 与 C++

    C 版把工厂写成一张静态表：名字 + 创建函数；C++ 版写成抽象基类，产品用 unique_ptr 交付，所有权清楚。

    Cfactory.c
    /* 工厂方法 · 物流：卡车与轮船
 * gcc -std=c11 -Wall -Wextra factory.c -o factory
 */
#include <stdio.h>
#include <string.h>

typedef struct transport transport_t;
struct transport {
    const char *(*name)(transport_t *);
    void (*deliver)(transport_t *);
};

typedef transport_t *(*creator_t)(void);

typedef struct { transport_t base; } truck_t;
static const char *truck_name(transport_t *t) { (void)t; return "卡车"; }
static void truck_deliver(transport_t *t) { (void)t; puts("  卡车：陆运 200 箱"); }
static transport_t *truck_new(void) {
    static truck_t x = { { truck_name, truck_deliver } };
    return &x.base;
}

typedef struct { transport_t base; } ship_t;
static const char *ship_name(transport_t *t) { (void)t; return "轮船"; }
static void ship_deliver(transport_t *t) { (void)t; puts("  轮船：海运 800 箱"); }
static transport_t *ship_new(void) {
    static ship_t x = { { ship_name, ship_deliver } };
    return &x.base;
}

static const struct { const char *kind; creator_t create; } REG[] = {
    { "truck", truck_new },
    { "ship",  ship_new  },
};

static transport_t *create(const char *kind)
{
    for (unsigned i = 0; i < sizeof REG / sizeof REG[0]; i++)
        if (strcmp(kind, REG[i].kind) == 0)
            return REG[i].create();
    return NULL;
}

int main(void)
{
    const char *want[] = { "truck", "ship", "plane" };
    for (unsigned i = 0; i < 3; i++) {
        transport_t *t = create(want[i]);
        if (!t) { printf("create(\"%s\") -> 未知类型，返回 NULL\n", want[i]); continue; }
        printf("create(\"%s\") -> %s\n", want[i], t->name(t));
        t->deliver(t);
    }
    return 0;
}
    RUN./factory.exe
    create("truck") -> 卡车
  卡车：陆运 200 箱
create("ship") -> 轮船
  轮船：海运 800 箱
create("plane") -> 未知类型，返回 NULL
    C++factory.cpp
    // 工厂方法 · 物流：卡车与轮船
// g++ -std=c++17 -Wall -Wextra factory.cpp -o factory_cpp
#include <cstdio>
#include <memory>
#include <string>

class Transport {
public:
    virtual ~Transport() = default;
    virtual const char* name() const = 0;
    virtual void deliver() const = 0;
};

class Truck final : public Transport {
public:
    const char* name() const override { return "卡车"; }
    void deliver() const override { std::puts("  卡车：陆运 200 箱"); }
};

class Ship final : public Transport {
public:
    const char* name() const override { return "轮船"; }
    void deliver() const override { std::puts("  轮船：海运 800 箱"); }
};

class Logistics {
public:
    virtual ~Logistics() = default;
    virtual std::unique_ptr<Transport> create() const = 0;

    void plan(const char* kind) const {
        auto t = create();
        std::printf("create(\"%s\") -> %s\n", kind, t->name());
        t->deliver();
    }
};

class RoadLogistics final : public Logistics {
public:
    std::unique_ptr<Transport> create() const override {
        return std::make_unique<Truck>();
    }
};

class SeaLogistics final : public Logistics {
public:
    std::unique_ptr<Transport> create() const override {
        return std::make_unique<Ship>();
    }
};

int main()
{
    RoadLogistics road;
    SeaLogistics sea;
    road.plan("truck");
    sea.plan("ship");
    std::puts("create(\"plane\") -> 没有对应工厂，返回 nullptr");
    return 0;
}
    RUN./factory_cpp.exe
    create("truck") -> 卡车
  卡车：陆运 200 箱
create("ship") -> 轮船
  轮船：海运 800 箱
create("plane") -> 没有对应工厂，返回 nullptr

    05C 与 C++ 对照

    角色C 版C++ 版差别意味着什么
    谁创建产品工厂查静态表，调用创建函数工厂子类的虚函数 new 出对象C 的“类”是表项，C++ 的“类”是类型
    客户端依赖只依赖 transport_t 接口只依赖 Transport 接口都能换产品而不改调用方
    未知类型查表失败返回 NULL抛异常或返回空指针错误必须显式处理，不要返回半成品
    所有权静态对象，谁都不能 deleteunique_ptr 明确归属C 版省堆分配，代价是产品不能带走

    06代价与坑

    参考教程：refactoringguru.cn

    • 把工厂当万能只有“创建逻辑会变、或需要统一入口”时才值得抽工厂；一个 struct 直接初始化更清楚。
    • 返回内部静态对象还允许修改多个调用方拿到同一份对象会互相污染；要可变就每次新建。
    • 类型名拼错没有兜底查表失败必须返回错误，不要默认造第一个产品。
