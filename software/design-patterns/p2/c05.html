    组合模式COMPOSITE

    整车自检要遍历“整车 → 总成 → 零件”。如果枝和叶用两套接口，遍历代码就要在每一层判断“这是组还是零件”。组合模式让枝和叶实现同一个接口：组自己递归孩子，叶只报结果，调用方从根调一次就够。

    枝与叶同一接口遍历只写一遍增删子树不改调用方

    01问题：树形结构，遍历代码越写越像

    坏写法通常是两套结构 + 手写递归：

    if (node->is_group) {
    for (child in node->children) run_group(child);
} else {
    run_leaf(node);
}

    这行代码会在每个层级复制一遍，问题随之而来：

    • 层级一深就漏。“总成里还有子总成”时，run_group 忘了递归，孙子节点永远不跑。
    • 统计口径不一。有的分支只算叶子，有的把组也算一项，最后总数对不上。
    • 新增节点类型要改遍历。加一个“虚拟节点”或“占位节点”，所有遍历函数都要动。

    组合把“遍历孩子”收进组自己：组的 run() 负责递归，叶的 run() 只报自己的结果。调用方只看到 run(root)。

    02结构：枝和叶同一接口

    三层树：整车是根，动力/底盘是枝，发动机、变速箱、ABS 是叶；点方框看每层职责。

    整车自检树：枝和叶同一接口composite
    职责点方框：组负责递归，叶负责报结果。

    03两份实现

    C 版用孩子数组 + 统一 run_node()；C++ 版用 unique_ptr 容器，析构自动递归。

    Ccomposite.c
    /* 组合：一棵诊断树，叶子是零件，枝是分组，遍历代码只写一遍 */
#include <stdio.h>
#include <stddef.h>

typedef struct node node_t;
struct node {
    const char *name;
    int is_leaf;
    int pass;
    node_t *kids[4];
    int nkids;
};

static int run_node(const node_t *nd, int depth)
{
    for (int i = 0; i < depth; i++) printf("  ");
    if (nd->is_leaf) {
        printf("- %-10s %s\n", nd->name, nd->pass ? "PASS" : "FAIL");
        return nd->pass;
    }
    printf("+ %s\n", nd->name);
    int ok = 1;
    for (int i = 0; i < nd->nkids; i++)
        if (!run_node(nd->kids[i], depth + 1)) ok = 0;
    return ok;
}

int main(void)
{
    node_t eng  = { .name = "engine",  .is_leaf = 1, .pass = 1, .kids = {0}, .nkids = 0 };
    node_t gear = { .name = "gearbox", .is_leaf = 1, .pass = 0, .kids = {0}, .nkids = 0 };
    node_t abs  = { .name = "abs",     .is_leaf = 1, .pass = 1, .kids = {0}, .nkids = 0 };
    node_t power = { .name = "powertrain", .is_leaf = 0, .pass = 0, .kids = { &eng, &gear }, .nkids = 2 };
    node_t chassis = { .name = "chassis", .is_leaf = 0, .pass = 0, .kids = { &abs }, .nkids = 1 };
    node_t root = { .name = "vehicle", .is_leaf = 0, .pass = 0, .kids = { &power, &chassis }, .nkids = 2 };

    int ok = run_node(&root, 0);
    printf("整车自检：%s\n", ok ? "PASS" : "FAIL");
    return 0;
}

    C++composite.cpp
    // 组合 · C++：Group 持有 unique_ptr，析构自动递归
// 编译：g++ -std=c++17 -Wall -Wextra composite.cpp -o composite_cpp
#include <cstdio>
#include <memory>
#include <string>
#include <vector>

class Component {
public:
    explicit Component(std::string name) : name_(std::move(name)) {}
    virtual ~Component() = default;
    virtual bool run(int depth) const = 0;
protected:
    std::string name_;
};

class Leaf : public Component {
public:
    Leaf(std::string n, bool pass) : Component(std::move(n)), pass_(pass) {}
    bool run(int depth) const override
    {
        for (int i = 0; i < depth; i++) std::printf("  ");
        std::printf("- %-10s %s\n", name_.c_str(), pass_ ? "PASS" : "FAIL");
        return pass_;
    }
private:
    bool pass_;
};

class Group : public Component {
public:
    explicit Group(std::string n) : Component(std::move(n)) {}
    Group &add(std::unique_ptr<Component> c) { kids_.push_back(std::move(c)); return *this; }
    bool run(int depth) const override
    {
        for (int i = 0; i < depth; i++) std::printf("  ");
        std::printf("+ %s\n", name_.c_str());
        bool ok = true;
        for (const auto &c : kids_)
            if (!c->run(depth + 1)) ok = false;
        return ok;
    }
private:
    std::vector<std::unique_ptr<Component>> kids_;
};

int main()
{
    auto root = std::make_unique<Group>("vehicle");
    auto power = std::make_unique<Group>("powertrain");
    power->add(std::make_unique<Leaf>("engine", true));
    power->add(std::make_unique<Leaf>("gearbox", false));
    root->add(std::move(power));
    auto chassis = std::make_unique<Group>("chassis");
    chassis->add(std::make_unique<Leaf>("abs", true));
    root->add(std::move(chassis));

    bool ok = root->run(0);
    std::printf("整车自检：%s\n", ok ? "PASS" : "FAIL");
    return 0;
}

    05C 与 C++：谁管孩子

    角色C 版C++ 版差别意味着什么
    孩子容器node_t *kids[4]vector<unique_ptr<Component>>C 固定上限；C++ 动态扩容且自动释放
    统一接口函数指针 run_node纯虚 run()都让枝和叶长得一样
    遍历组内部递归组内部递归调用方只调一次根
    失败传播返回 int，逐层与返回 bool，逐层与口径要统一，别有的层吞掉失败
    增删子树改数组 + nkidspush_back / eraseC 要手维护计数，C++ 容器代劳

    06代价与坑

    • 别在叶里访问父节点。叶一旦反向依赖父节点，树就变成图，递归容易成环；需要上下文就通过参数往下传。
    • 递归深度要设上限。诊断树通常不深，但配置错误可能造出自引用；入口处限制 depth 或检测环。
    • 组也可以是空组。空组应明确返回“通过”还是“未配置”，别让 0 个孩子默默算 PASS 掩盖配置缺失。
    • C 版孩子数组要初始化。kids 未清零、nkids 又写大了，会读到野指针；统一用指定初始化器。
    • 统计不要混层。“通过率”按叶算还是按组算要写死；否则同一棵树两个报表两个数。
