    备忘录模式MEMENTO

    调参数、写文本时，改错是常事。如果只保留当前状态，就没有退路。备忘录把“某一刻的状态”复制出来单独保存：编辑继续改原对象，需要时再把快照倒回去。

    快照与对象分离恢复即覆盖C 用值结构 · C++ 用 friend 封装

    01问题：坏代码长什么样

    坏写法是“撤销”直接清空：

    editor.text[0] = 0;   /* 只能回到空，回不到上一个版本 */

    要回到任意一步，就得在每次修改前保存整份状态；但状态里有游标、选区、滚动位置，调用方不一定都拿得到。

    备忘录由对象自己产出快照：save() 复制一份，restore() 覆盖回去。调用方只保管快照，不直接改内部字段。

    02结构：快照与恢复分离

    左边是编辑器，中间是快照，右边是恢复后的状态。

    快照是值复制，编辑不影响它structure
    职责调用方只保管快照，不透视内部字段。

    03两份实现：C 与 C++

    C 版快照就是同构的值结构，复制即可；C++ 版把字段设为私有，用 friend 让编辑器访问。

    Cmemento.c
    /* 备忘录 · 撤销快照
 * gcc -std=c11 -Wall -Wextra memento.c -o memento
 */
#include <stdio.h>
#include <string.h>

typedef struct { char text[64]; int cursor; } editor_t;
typedef struct { char text[64]; int cursor; } memento_t;

static memento_t save(const editor_t *e)
{
    memento_t m;
    strcpy(m.text, e->text);
    m.cursor = e->cursor;
    return m;
}

static void restore(editor_t *e, const memento_t *m)
{
    strcpy(e->text, m->text);
    e->cursor = m->cursor;
}

int main(void)
{
    editor_t e = { "hello", 5 };
    printf("初始：\"%s\" cursor=%d\n", e.text, e.cursor);

    memento_t snap = save(&e);

    strcpy(e.text, "hello world");
    e.cursor = 11;
    printf("编辑后：\"%s\" cursor=%d\n", e.text, e.cursor);

    restore(&e, &snap);
    printf("恢复后：\"%s\" cursor=%d\n", e.text, e.cursor);
    printf("快照是值拷贝，编辑过程不会污染它\n");
    return 0;
}
    RUN./memento.exe
    初始："hello" cursor=5
编辑后："hello world" cursor=11
恢复后："hello" cursor=5
快照是值拷贝，编辑过程不会污染它
    C++memento.cpp
    // 备忘录 · 撤销快照
// g++ -std=c++17 -Wall -Wextra memento.cpp -o memento_cpp
#include <cstdio>
#include <string>

class Memento {
public:
    Memento(std::string text, int cursor) : text_(std::move(text)), cursor_(cursor) {}
private:
    friend class Editor;
    std::string text_;
    int cursor_;
};

class Editor {
public:
    void setText(std::string t, int cursor) { text_ = std::move(t); cursor_ = cursor; }
    const std::string& text() const { return text_; }
    int cursor() const { return cursor_; }

    Memento save() const { return Memento(text_, cursor_); }
    void restore(const Memento& m) { text_ = m.text_; cursor_ = m.cursor_; }

private:
    std::string text_;
    int cursor_ = 0;
};

int main()
{
    Editor e;
    e.setText("hello", 5);
    std::printf("初始：\"%s\" cursor=%d\n", e.text().c_str(), e.cursor());

    auto snap = e.save();

    e.setText("hello world", 11);
    std::printf("编辑后：\"%s\" cursor=%d\n", e.text().c_str(), e.cursor());

    e.restore(snap);
    std::printf("恢复后：\"%s\" cursor=%d\n", e.text().c_str(), e.cursor());
    std::puts("快照是值拷贝，编辑过程不会污染它");
    return 0;
}
    RUN./memento_cpp.exe
    初始："hello" cursor=5
编辑后："hello world" cursor=11
恢复后："hello" cursor=5

    05C 与 C++ 对照

    角色C 版C++ 版差别意味着什么
    快照形态同构值结构Memento 私有字段C 直接复制，C++ 控制可见性
    谁能写快照编辑器编辑器（friend）调用方只传递，不修改
    恢复逐字段覆盖逐字段覆盖必须完整，不能只回滚一部分
    存储成本整份文本整份文本大对象要增量或压缩

    06代价与坑

    参考教程：refactoringguru.cn

    • 快照存指针原对象继续改，快照跟着变；必须深拷贝值。
    • 恢复漏字段文本回去了、光标没回去，用户体验仍然错。
    • 快照无限保存每次按键一份会爆内存；按操作合并或限制数量。
