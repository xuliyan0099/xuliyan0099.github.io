第 08 课 · 时钟与触发器：让电路拥有记忆

前面所有门都是「组合逻辑」：输入变，输出立刻跟着变，什么也记不住。可 CPU 必须记得「现在执行到第几条指令」——这份记忆由触发器提供，「什么时候更新」由时钟决定。这一课是数字设计的分界线：从这一刻起，电路有了状态。

这一课要回答的问题

① 组合逻辑为什么不能记忆？② 交叉耦合为什么能锁住一个比特？③ 为什么必须「边沿触发」而不是「电平触发」？④ 建立时间、保持时间是什么，超了会怎样？⑤ 24MHz 晶振怎么变成 528MHz 主频，时钟门控怎么省电？

1. 直觉：两个反相器首尾相接

把两个反相器串成一个环：A 的输出接 B 的输入，B 的输出接 A 的输入。假设 A 输出 1 → B 输入 1 → B 输出 0 → A 输入 0 → A 输出 1，稳定。假设 A 输出 0，同样稳定。于是这个环能停在任意一侧——它记住了上一次的状态。

这就是锁存器（latch）的原理。加上「控制端」允许它在某些时刻改变，就得到受控的存储单元。

失效处：纯电平触发的锁存器在控制信号为高的整段时间都「透明」，多个锁存器串起来会出现「数据一路穿透」的竞态。解决办法是边沿触发——只在跳变那一瞬间采样。

2. 硬件上：主从结构与边沿触发

一个 D 触发器内部是「主-从两个锁存器」串接，时钟反相后分别控制：

  • CLK 低电平：主锁存器透明（采 D），从锁存器保持（输出不变）。
  • CLK 上升沿：主锁存器关闭（锁住 D 的值），从锁存器打开（把主的值送到 Q）。
  • 结果：Q 只在上升沿更新一次，一个周期内只前进一格。

3. 时钟：全局节拍从哪来

i.MX6ULL 的时钟链路是典型的多级 PLL 结构：

环节典型值作用
外部晶振 XTAL24 MHz稳定但慢，成本低
PLL1（ARM PLL）528 MHz（或 996 MHz 再二分频）给 CPU 高主频
PLL2（528 PLL）528 MHz给 AHB/AXI 与外设分频
PLL3（USB PLL）480 MHzUSB PHY 专用
CCGR 门控逐模块开关不用的模块断时钟，动态功耗趋零

你在设备树和驱动里会反复遇到这些东西：assigned-clock-rates 改频率、clocks 声明依赖、clk_prepare_enable() 打开时钟。「打开时钟」不是「给电」，而是「让这块逻辑开始翻转」——这解释了为什么漏掉 clk_prepare_enable 时，寄存器读出来全是 0 或全是 1。

4. 亚稳态：为什么跨时钟域要同步器

如果 D 恰好在建立/保持窗口内变化，触发器可能进入一个既非 0 也非 1 的中间电平，并在不确定时间后随机落到某一侧——这叫亚稳态。它不烧芯片，但会让下游采到「不确定值」。

工程解法是两级或多级触发器串联做同步器：第一级可能亚稳态，但概率随等待时间指数衰减，第二级采样时几乎一定已稳定。代价是多一拍延迟。

这条知识在 Linux 驱动里同样有影子：中断跨域、DMA 与 CPU 的可见性、readl() 后的内存屏障，本质都是「两边时钟/顺序不一致，必须显式同步」。

5. 实验：模拟触发器、算清时钟预算

# ① 模拟 D 触发器：只在 clock 上升沿采样
class DFF:
    def __init__(self):
        self.q = 0
        self.last = 0
    def tick(self, d, clk):
        if self.last == 0 and clk == 1:
            self.q = d
        self.last = clk
        return self.q

ff = DFF()
seq = [(0,0),(1,0),(0,0),(1,1),(0,1),(1,0),(1,1),(0,0)]
for d, c in seq:
    print("D=%d CLK=%d -> Q=%d" % (d, c, ff.tick(d, c)))

# ② 一个周期的预算有多长
for f in (528e6, 792e6, 1.2e9, 3.0e9):
    print("%.0f MHz -> 每周期 %.3f ns" % (f/1e6, 1e9/f))

# ③ 24MHz 晶振要倍频多少倍才到 528MHz
print("倍频倍数 =", 528 / 24)

# ④ UART 波特率是怎么分频出来的（115200 从 80MHz 来）
print("分频值 =", round(80000000 / (16 * 115200)))

第②条值得盯着看：528MHz 一个周期只有 1.89 纳秒。光在 1.89 纳秒里只能走 57 厘米——这就是为什么 CPU 的物理尺寸与主频是强相关的，也是为什么芯片不能无脑做大。

7. 自测与动手

1

为什么纯组合逻辑无法实现「计数」？

看答案

计数需要「记住上一次的值」，而组合逻辑的输出只依赖当前输入，没有状态。

2

边沿触发相比电平触发解决了什么问题？

看答案

避免「透明期穿透」：电平触发在高电平期间输入会一路传到输出，串级时出现竞态；边沿触发每周期只采样一次。

3

建立时间违例会有什么现象？为什么难查？

看答案

随机性错误：与温度、电压、数据模式相关，仿真正常、实机偶发。需要用 STA 工具在时序上保证，而非靠测试碰运气。

4

clk_prepare_enable 漏调用，读寄存器会看到什么？

看答案

模块时钟没开，逻辑不翻转，读回固定值（常为 0 或全 1），写也没效果——很像「硬件坏了」，实则时钟没开。

5

528MHz 下一周期多少纳秒？光能走多远？

看答案

约 1.89 ns；光速约 30cm/ns，故约 57cm（芯片内信号速度更慢，实际更短）。

  2. 查 i.MX6ULL 参考手册 CCM 章节，找出 ARM PLL 的倍频寄存器字段。
