为什么 32 字节一行？ 内存是按突发传输的，一次取一整行（8 个字）比逐个字取快得多；所以命中时你拿到的其实是「邻居也顺便进来了」。
为什么同 set 的两个地址会互相挤？ 直接映射的 cache 里，地址低位固定了它只能放进某一行；两个地址低位相同、tag 不同，就会反复替换（抖动），命中率掉到很低。
写为什么比读麻烦？ 写命中要决定写回（write-back，行标脏等淘汰）还是写穿（write-through，同步写内存）；写未命中还要决定是否分配行。ARM 里这些由 CP15 / SCTLR 的 C、W 位控制。
