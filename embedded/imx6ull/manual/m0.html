六份文档，回答六类不同的问题

文档通常叫什么回答什么问题什么时候翻
Datasheet数据手册这个芯片的电气极限、引脚有哪些、几伏几瓦、能不能买选型、画板、算电源
Reference ManualRM / 参考手册每个模块的寄存器在哪、每位什么意思、模块怎么工作写驱动、调试、看内核代码
Errata勘误表这个芯片有哪些已知缺陷、怎么绕遇到「按手册写却不工作」
Application NoteAN / 应用笔记官方推荐的电路与流程（DDR 校准、USB、电源时序）画板、移植关键模块
原理图 + 硬件设计指南Schematic / HW Design Guide板子上到底怎么连的、上拉在哪、晶振几兆定位引脚、排查硬件
dts + 内核驱动源码设备树 / 源码别人已经怎么配的、字段叫什么抄作业、对照

一条最常见的错位：拿 Datasheet 去查寄存器。Datasheet 里确实有寄存器章节，但只有「几页摘要」，完整定义在 RM 里。反过来，拿 RM 去查某个引脚能接几伏——RM 不管电气特性，那在 Datasheet。

三份文档的命名规则

拿到 PDF 先看标题里的芯片型号后缀，这是判断「这份能不能用」的第一步。

  • Datasheet：型号主体 + 后缀，后缀编码了「温度等级 / 封装 / 主频」。同一个 i.MX6ULL，工业级和消费级是不同的料号。
  • RM：一份 RM 覆盖同一家族多个型号（i.MX6ULL 与 i.MX6UL 的 RM 常常合订）。因此章节里出现你不认识的模块，可能只是这颗芯片没做——先看该章开头的 "This chip does not..." 说明。
  • Errata：文件名里带芯片的硅版本号（silicon revision）。同一型号不同批次，勘误条目可能不同。查勘误前先确认你手上的片子是哪个 revision（一般印在芯片丝印或可读的系统寄存器里）。

手册里的「实例号」是关键

i.MX6ULL 有 8 个 UART、4 个 I2C、2 个 FlexCAN……手册里统一写成 UART1–UART8。这些编号不是「第几个」，而是独立的硬件实例，各有自己的基地址与时钟门控位。

所以：

  • 查寄存器时，寄存器名通常是通用的（UART_URXD），但地址按实例不同（UART1 基址 0x02020000、UART2 基址 0x02024000 之类，具体以 RM 的 Memory Map 为准）。
  • 内核里对应 uart1–uart8 的设备树节点，别把 uart3 写成 uart2——这种错误表现是「串口完全没输出」，极难一眼看出来。

引脚名的规则同样重要：GPIO1_IO03 是「GPIO 模块 1 的第 3 号」，而它在 IOMUXC 里的寄存器名是 SW_MUX_CTL_PAD_GPIO1_IO03。同一个物理脚还有第三种叫法（球号，比如 BGA 上的 A15）。三者要在脑子里有映射，06 篇讲怎么建这张表。

为什么「先读 RM 的目录」比「先读正文」重要

RM 是字典。字典的正确用法是先知道词在哪一页。i.MX6ULL 的 RM 目录结构是固定的：

Chapter 1  Introduction（芯片总览、框图、地址映射入口）
Chapter 2  ……
每个外设一章：CCM / IOMUXC / GPIO / UART / I2C / SPI / eMMC / ENET / LCDIF / CSI ……
靠后的章节：系统模块（SRC、WDOG、GPT、EPIT、GPC）与附录（引脚复用总表）

两个必须记住的入口：

  • Memory Map（在 Introduction 章或单独的 System Memory Map 一节）：所有模块基地址一张表。
  • Signal Multiplexing（在 IOMUXC 章末尾，有时单独成附录）：所有引脚 × 所有复用功能的一张巨表。这张表是全手册最该收藏的部分。

一份「够用」的资料夹

实际干活时，桌面开六个东西就够，不用每次翻两千页：

  1. RM 的 PDF（带书签），搜关键词用。
  2. Datasheet 的引脚表（打印一页贴在桌上）。
  3. 板子的原理图 PDF（能搜索网络名）。
  4. dts 与厂商提供的 dtsi。
  5. 一份自己的笔记（按「模块 / 基址 / 关键位 / 踩过的坑」记）。
  6. Errata（遇到怪现象才翻，但要有）。

本篇验收

  • 能说出 Datasheet 与 RM 各自回答哪类问题，并举一个「拿错会浪费半天」的例子。
  • 能解释「实例号」是什么，为什么 UART3 与 UART2 不能混。
  • 能说出 RM 里两张必须记住的表在哪（Memory Map、Signal Multiplexing）。
  • 拿到一份新芯片的 PDF，30 秒内能判断「这份是 Datasheet 还是 RM」。
