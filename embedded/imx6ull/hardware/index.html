硬件入口 · 你手上的 i.MX6ULL

先认识这块板子，再谈驱动

软件跑不起来，九成不是代码的问题，是板子上的某一环没到位：电没上去、时钟没起、启动脚拨错、串口接错线。这一页只干一件事——让你看着这块板子，能说出每块芯片是干什么的、上电后先发生什么、出问题时先量哪里。

一句话：这是一台「能自己启动的小电脑」

i.MX6ULL 是 NXP 的一颗 ARM Cortex-A7 单核 SoC，主频通常 528MHz，片内集成 DDR 控制器、eMMC/NAND 控制器、以太网 MAC、USB、UART、I2C、SPI、LCD、ADC、CAN。开发板做的事就是把它需要的「电、时钟、存储、调试口」都焊在周围，让它能从上电一路跑到 Linux 命令行。

Cortex-A7 · 528MHzDDR3L 512MB（常见）eMMC 8GB / NANDUART1 115200 调试口10/100M 以太网USB OTG 烧录

1. 先给一个能记住的模型：五块拼图

任何一块 i.MX6ULL 开发板，拆开看都是这五块，名字各家不同，作用一模一样：

电源5V 进 → 3.3V / 1.35V(DDR) / 1.1~1.3V(内核)坏了：灯不亮、反复重启、芯片发烫
时钟24MHz 晶振 → PLL 倍频，给所有人发节拍坏了：串口乱码、网口不通
存储eMMC 放系统，DDR 当运行内存坏了：卡在 Starting kernel、随机死机
调试口UART1 + USB OTG，你和板子唯一的对话通道坏了：上电一个字都没有
外设网口 / LCD / 按键 / TF / 排针坏了：单点失灵，网口灯不亮、屏幕花

记法：电源管「活不活」，时钟管「准不准」，存储管「记不记得住」，调试口管「你听不听得见」，外设管「能不能跟外界打交道」。

3. SoC 里面到底有什么

板子上最贵的那颗 BGA 就是 i.MX6ULL。它不是「一个 CPU」，而是「一个 CPU 加一堆外设控制器」焊在同一块硅片上：

片内模块干什么对应到板子上的谁
Cortex-A7 核执行指令，带 32KB L1 指令/数据 Cache、128KB L2就是它自己在跑 Linux
MMU / Cache虚拟地址翻译、内存保护没它 Linux 跑不起来（要开 MMU）
DDR 控制器（MMDC）直接管 DDR3L 颗粒的时序DDR 颗粒；时序配错就死在 uboot
SD/MMC 控制器 ×2SD1 接 TF 卡，SD2 接 eMMCTF 卡槽、eMMC 芯片
UART ×8串口，UART1 通常做调试口板上 USB 转串口那颗小芯片
以太网 MAC ×2MAC 在片内，PHY 在板外KSZ8081 之类的 PHY + RJ45
USB OTG / HostOTG 做烧录与 gadget，Host 接外设MicroUSB / Type-C / USB-A
LCD / CSI / I2C / SPI / PWM / ADC / CAN显示、摄像头、传感器总线、背光、采样、车载总线FPC 座、排针、板载传感器
IOMUXC把上面这些信号「接到具体的物理引脚」排针上那一堆复用脚

i.MX6ULL 和 i.MX6UL 的差别主要在主频与部分外设；写驱动时以你板子上那颗的具体型号（丝印如 MCIMX6Y2CVM05AB）查 NXP 参考手册，别拿别的型号的表硬套。

6. 引脚复用实验室：一个脚只能有一个主人

i.MX6ULL 的引脚比外设少，所以几乎每个物理脚都挂了 8 个候选功能（ALT0–ALT7）。同一时刻只能选一个：选了 UART1_TXD，它就不是 GPIO 了。这就是「复用」。

你选的引脚

UART1_TXD

写驱动的顺序永远是：查 IOMUXC 表 → 写 MUX 选 ALT → 写 PAD_CTL 设电气属性 → 开时钟 → 配外设。少一步就「没反应」，而不是「报错」。

8. 上手清单：今天就能做的六件事

不用等学完理论，先把这六件做完，你对这块板子的感觉就从「一块绿板子」变成「一台机器」：

  1. 认电源。找到 5V 输入口、电源开关、复位键；量一次 5V 与 3.3V，记住它们的位置。
  2. 接串口。USB-TTL 的 GND 接板子 GND，TX 接板子 RX，RX 接板子 TX；开 115200 8N1，上电看第一行字。
  3. 玩拨码。分别在 eMMC 与 TF 卡模式下上电，对比串口输出有什么不同。
  4. 认存储。看丝印分辨 eMMC 与 DDR；进系统后 lsblk、cat /proc/meminfo 对一遍容量。
  5. 点一个灯。从排针找一个 GPIO，用 /sys/class/gpio 或 gpioset 让它闪，再用万用表量电平。
  6. 插一次网线。看 PHY 灯、ip addr、ping 网关，把「板子能上网」这件事跑通。
