无源五件套：电阻、电容、电感、二极管、晶振

第 02 章约 26 分钟★ 必读

无源 = 不需要额外电源就能工作

「无源器件」指不需要供电、只靠信号本身就能发挥作用的元件。五个必备：电阻、电容、电感、二极管、晶振（严格说晶振是无源+有源的家族，这里按「被动谐振元件」讲）。

每一个都在解决一个具体问题。 记住问题，比记住名字有用。

① 电阻：三种用途，别混

用途解决什么问题典型值
限流别让电流烧掉器件（LED、三极管基极）100Ω–1kΩ
上拉 / 下拉让「没人驱动的线」有确定的电平4.7k–100k
分压 / 采样把高电压降到 ADC 能测的范围按比例算

上拉是这里面最常被误解的。 一条信号线在「所有器件都不驱动」时是悬空的，悬空意味着电平不确定——读到的值随机，甚至随手指靠近而变。

上拉电阻做的事：给这条线一个「默认是高」的弱连接。它很弱（几 kΩ 到几十 kΩ），所以任何一个真正的驱动器都能轻松把它拉低；但没人驱动时，它保证读到高。

这就是 I2C 必须上拉的原因：I2C 是「开漏」总线，器件只会「拉低」，不会「推高」，高电平完全靠上拉电阻。

② 电容：三种用途

用途解决什么问题典型值
去耦 / 旁路芯片瞬间要大电流时，就近给它0.1µF（每颗电源脚一个）
滤波把高频噪声短路到地10pF–10µF
定时 / 延时与电阻组成 RC，决定时间按 τ=RC 算

去耦电容是板上最多的元件，一颗芯片周围能有十几个。它的作用不是「储能给整板」，而是「芯片内部开关瞬间产生的电流尖峰，由就近的电容提供，避免整条电源线一起抖」。

所以布局规则是「尽量靠近电源脚」——离得远，走线的电感就把它的作用抵消了。

③ 电感：只对「变化」有反应

电感的阻抗与频率成正比：

ZL = 2π f L　　频率越高，感抗越大；直流时几乎为零。
  • 直流：阻抗几乎为 0，畅通。
  • 高频：阻抗很大，挡住。

用途：电源滤波（挡高频）、DC-DC 变换（储能）、共模扼流（抑制差分噪声）。

一个实用结论：开关电源旁边的电感发烫是正常的，它本来就在储能放能。但如果它啸叫，说明开关频率落到了音频范围。

④ 二极管：一个方向通

正向导通（有约 0.6–0.7V 压降，肖特基约 0.3V），反向截止。四种常见用法：

用法作用
整流把交流变直流（板子上少见）
续流 / 钳位感性负载断电时的反向尖峰，用它泄掉
防反接电源入口串一颗，接反了不通
TVS / ESD静电打过来时瞬间导通，把能量泄掉，保护后面的芯片

TVS 与普通二极管不同：它平时截止，只有电压超过阈值才动作，动作后能承受很大的瞬时电流。USB、按键、外部接口旁边那颗小元件多半就是它。

⑤ 晶振：给「节奏」

晶振提供精确的频率基准。i.MX6ULL 的板子上通常有两颗：一颗 24MHz（给 SoC 的主参考），一颗 32.768kHz（给 RTC 走时）。

为什么不能只用内部振荡器？精度。内部 RC 振荡器的误差可能有百分之几，做串口通信时波特率误差超过约 3% 就会开始丢字节；做 RTC 走时，一天可能偏几分钟。

两个配套元件：

  • 负载电容（两颗小电容）：晶振手册会指定，不能随便换，否则频率偏。
  • 串联电阻（有时有）：抑制过驱动，防止晶振「跑在谐振上」。

五件套的「谁解决什么」总表

元件解决的物理问题一句话记法
电阻电流太大 / 电平不确定限流与定电平
电容电压会抖 / 高频会串就近供能与短路高频
电感高频会串进电源只挡变化
二极管反向电压会打坏东西单向阀 + 泄压阀
晶振时间不准节奏的来源

在 i.MX6ULL 板子上找一遍

拿你的板子（或原理图）数一数：

  • 电阻：LED 限流、I2C 上拉（通常 4.7k）、复位上拉、USB 分压、DDR 端接（几十 Ω）。
  • 电容：每颗芯片电源脚旁 0.1µF、电源入口大电容（几十 µF）、晶振负载电容（十几 pF）。
  • 电感：DC-DC 旁边的功率电感（µH 级）、USB/以太网共模电感。
  • 二极管：电源防反接、TVS（USB/按键/网口）、LED 本身。
  • 晶振：24MHz 主晶振、32.768kHz RTC 晶振。

这五类都找到实物并说出它的作用，这一章就过了。

本篇验收

  • 能说出上拉电阻解决什么问题，并解释 I2C 为什么必须上拉。
  • 能说出「去耦电容为什么要靠近电源脚」。
  • 能解释电感的「只挡变化」，并举一个板上的用途。
  • 能区分普通二极管与 TVS 的作用。
  • 能说出主晶振与 RTC 晶振各自的频率与用途。
  • 在自己的板子上找到五类器件各至少一个。
