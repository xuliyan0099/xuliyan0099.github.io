Vim 与 Shell 脚本

板子上没有 IDE、没有鼠标。Vim 决定你改代码的速度，Shell 决定你把重复劳动交给机器的能力。这两样是嵌入式开发者的「手」。

★ 一读 纯读约 14 小时 左侧是本卷目录 理论为主 · 实作可跳

本章目标

① Vim 三种模式切换形成肌肉记忆，能无鼠标完成全部编辑；② 会搜索替换、分屏、批量操作；③ 能写带参数、判断、循环、函数的 Shell 脚本；④ 写完 4 个实用脚本。

5.1 Vim 的核心：三种模式

新手觉得 Vim 难，是因为它不像记事本「所见即所输」。它有三个模式，你敲的字在不同模式下含义完全不同：

普通模式默认状态
按键=命令（删、复制、跳转）
i / a / o
插入模式真正打字
Esc 回到普通模式
Esc
命令行模式普通模式按 : / ?
保存、替换、执行命令
最重要的一条 卡住了、不知道现在什么状态、敲出来的字跑进正文了——连按两下 Esc，回到普通模式再想。这是 Vim 的「复位键」。

5.3 Shell 脚本：把重复劳动交给机器

脚本就是一个装了命令的文本文件，开头写 #!/bin/bash 告诉系统用哪个解释器，然后加执行权限就能跑。

$ vim first.sh
#!/bin/bash
echo "hello, $USER"
$ chmod +x first.sh
$ ./first.sh
为什么是 ./first.sh 不是 first.sh 当前目录不在 PATH 里（这是安全设计）。不加 ./，shell 会去系统目录找，找不到就报 command not found。这也是新手第一个坑。

变量与引号

#!/bin/bash
name="imx6ull"           # 等号两边不能有空格
echo "$name"             # 双引号：变量会展开
echo '$name'             # 单引号：原样输出
num=$((1 + 2))           # 算术运算
files=$(ls)              # 命令结果赋值
echo ${name}             # 推荐带花括号，避免歧义
readonly ROOT="/opt"     # 只读变量
unset name               # 删除变量

脚本参数：$0 脚本名，$1 第一个参数……$# 参数个数，$@ 全部参数，$? 上一条命令的退出码（0 表示成功）。

判断

#!/bin/bash
if [ $# -lt 1 ]; then
    echo "用法: $0 <文件名>"
    exit 1
fi

if [ -f "$1" ]; then
    echo "$1 是普通文件"
elif [ -d "$1" ]; then
    echo "$1 是目录"
else
    echo "$1 不存在"
fi
判断含义判断含义
-f是文件-d是目录
-e存在-r -w -x可读/可写/可执行
-z字符串为空-n字符串非空
-eq -ne数值相等/不等-lt -gt小于/大于

循环

# for 遍历列表
for f in *.c; do
    echo "编译 $f"
done

# for 计数
for i in $(seq 1 5); do echo "第 $i 次"; done

# while 按行读文件
while read -r line; do
    echo "读到: $line"
done < list.txt

# until：条件不成立才循环
n=0
until [ $n -ge 3 ]; do n=$((n+1)); echo $n; done

函数

log() {
    echo "[$(date '+%F %T')] $*" >> /tmp/mylog
}
log "开始编译"
log "结束，退出码 $?"
set -e 加在开头 让脚本遇到错误立即退出，而不是带病继续往下跑。生产脚本必备。

5.4 四个必写脚本（本章作业）

脚本 1：批量重命名

#!/bin/bash
# 把所有 .txt 改成 .md，并加前缀 note_
for f in *.txt; do
    [ -e "$f" ] || continue
    mv "$f" "note_${f%.txt}.md"
done
echo "完成，当前 md 文件数：$(ls *.md 2>/dev/null | wc -l)"

脚本 2：一键编译 + 清理

#!/bin/bash
set -e
SRC=${1:-main.c}
OUT=${2:-app}
CROSS=arm-linux-gnueabihf-gcc

echo "== 编译 $SRC -> $OUT =="
$CROSS -Wall -O2 "$SRC" -o "$OUT"
file "$OUT"
echo "== 清理解压产物 =="
rm -rf *.o

脚本 3：日志按大小清理

#!/bin/bash
# 保留最近 7 天，超过 100MB 的日志清空
LOG_DIR=/var/log/myapp
find "$LOG_DIR" -name "*.log" -mtime +7 -delete
find "$LOG_DIR" -name "*.log" -size +100M -exec truncate -s 0 {} \;
echo "清理完成 $(date)"

脚本 4：备份并打时间戳

#!/bin/bash
SRC=/home/ubuntu/lab
DST=/home/ubuntu/backup
mkdir -p "$DST"
tar -zcf "$DST/lab_$(date +%Y%m%d_%H%M).tar.gz" "$SRC"
ls -lh "$DST" | tail -3

5.5 动手任务

  • 用 Vim 完成上面 4 个脚本，全程不用鼠标，不用其他编辑器。
  • 故意在 Vim 里按错键（比如按了 dd 删掉一行），用 u 撤销，连按两次 Esc 复位。
  • 用 :%s/old/new/g 把一个 C 文件里的所有 int 临时替换，再撤销回来。
  • 用可视块模式给 10 行代码批量加 // 注释，再批量取消。
  • 把脚本 2 改成接受「源文件、输出名、优化等级」三个参数，并做参数个数检查。
  • 给所有脚本加 set -e，然后故意让其中一步失败，观察是否立即退出。

5.6 验收标准

  • 能不查资料完成：打开文件、跳转行、搜索、替换、保存退出、分屏
  • 知道三种模式怎么切换，卡住时知道按两次 Esc
  • 能解释 ./script.sh 里 ./ 的作用
  • 能写带参数校验、if 判断、for 循环、函数的脚本
  • 能说清单引号和双引号的区别
  • 4 个脚本全部跑通，且能改造成自己的场景
