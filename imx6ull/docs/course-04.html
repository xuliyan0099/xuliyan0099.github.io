卷 01·机器与指令·第 05 篇

一个开关能做什么

整台计算机，抽象到最底层，就是几亿个「可控开关」。这一课看一个开关怎么变成「非门」，非门怎么串成「与、或」，以及为什么现代芯片用 CMOS 而不是用电阻搭逻辑——后者会让你的板子烫手、电池十分钟没电。

◆ 一读 纯读约 1 小时 左侧是本卷目录 理论为主 · 实作可跳

这一课要回答的问题

① MOS 管为什么能当开关？② 什么是「上拉」「下拉」，为什么按键电路离不开它们？③ 非门在电路上到底怎么接？④ 为什么 CMOS 静态几乎不耗电，翻转却耗电？⑤ 推挽输出和开漏输出有什么区别，为什么 I2C 必须用开漏？

1. 直觉：水阀

MOS 管像一个由「电压」控制的水阀：栅极（gate）加电压，源极到漏极之间就通；栅极不加电压，就断。区别是它控制的是电流，而且控制端几乎不耗电（栅极是绝缘的，只有极小漏电流）。

失效处：水阀是机械的、有惯性；MOS 管有寄生电容，栅极充电需要时间——这就是为什么频率不能无限提高，也是为什么「翻转」要耗电。

2. 硬件上：两个管子组成一个非门

CMOS 反相器只需要两个管子：

输入PMOS（上）NMOS（下）输出电流
0（0V）导通，把输出拉到 VDD截止1（VDD）几乎为零
1（VDD）截止导通，把输出拉到 GND0（0V）几乎为零
翻转中两个短暂同时导通—尖峰电流（短路功耗）

这就是 CMOS 的全部秘密：任何一个稳定状态，电源到地之间都没有直通路径。所以静态功耗极低，功耗几乎全部来自「翻转次数 × 每次翻转的电荷」。这直接推出两个工程结论：

  • 降频省电：翻转次数线性减少，功耗近似线性下降（实际还受电压平方影响）。
  • 关掉不用的模块省电：i.MX6ULL 的 CCGR 门控就是直接切断时钟，让那块逻辑「不翻转」，静态功耗趋近于零。

3. 上拉与下拉：让「没接东西」也有确定状态

一个按键接到 GPIO，如果不加电阻，松开时那条线是「悬空」的——电压不确定，可能被干扰到任意值。解决办法是在另一端接一个电阻：

  • 上拉：电阻接 VDD，空闲时线被拉高（读到 1），按下接地变低（读到 0）。按键最常用。
  • 下拉：电阻接 GND，空闲时线被拉低（读到 0），按下接高变高。

电阻值有讲究：太小费电（按下时电流大），太大抗干扰差、上升沿变慢。4.7kΩ ~ 10kΩ 是嵌入式里最常用的区间，你会在几乎所有原理图上看到它。

大多数 SoC 的 GPIO 内部可配置上拉/下拉（i.MX6ULL 有 PKE/PUS/PUE 寄存器位），外部可以省掉电阻。这也是「为什么板子上有的按键没看到电阻」的原因。

4. 推挽与开漏：两种输出级，对应两类总线

这个区别在驱动开发里非常具体：配置 I2C 的 SDA/SCL 引脚时，必须选「开漏 + 外部上拉」模式；如果误配成推挽，通讯可能偶发失败，或者干脆烧掉从设备的输出管。

5. 实验：用 Python 模拟一个 CMOS 门（可选硬件验证）

# ① 用逻辑值模拟反相器，验证「两个稳定状态，无直通」
def inverter(a, vdd=3.3, ron=100.0):
    # 简化模型：a=0 → PMOS 导通，输出≈VDD；a=1 → NMOS 导通，输出≈0
    return 0.0 if a else vdd

for a in (0, 1):
    print("IN=%d  OUT=%.1fV" % (a, inverter(a)))

# ② 算一下翻转功耗的量级（C=1pF, V=3.3V, f=100MHz）
C, V, f = 1e-12, 3.3, 100e6
print("单门动态功耗 ≈ %.2f mW" % (C * V * V * f * 1000))

第二条会算出约 1.09mW。乘上一颗芯片里几百万个门、再乘上翻转比例，就是几百毫瓦到几瓦的来源。这不是背公式，是理解「为什么手机要关核、降频、分电源域」的唯一正确入口。

硬件实验（有板子再做）：用万用表量按键两端电压，松开时接近 3.3V、按下接近 0V；把 GPIO 内部上拉关掉，再量一次，会看到电压漂浮、读数乱跳。

6. 三条常见误解

7. 自测与动手

1

CMOS 反相器在稳定状态下为什么几乎不耗电？

看答案

两个管子总是一个导通一个截止，VDD 到 GND 之间没有直通路径，只有极小的漏电流。

2

上拉电阻为什么常见 4.7k–10k？太大太小各有什么问题？

看答案

太小：按下时电流大、费电；太大：抗干扰差、上拉弱、上升沿慢（RC 时间常数大）。10k 左右是功耗与速度的折中。

3

I2C 为什么不能配推挽？

看答案

多个器件挂在同一根线上，推挽输出会互相「顶牛」造成短路；开漏只能主动拉低、高电平靠上拉，才能安全共享并实现仲裁。

4

降低主频为什么能省电？用「翻转」解释。

看答案

动态功耗正比于频率：每秒翻转次数减少，充放电次数减少，功耗随之下降（配合降压更明显，因功耗与 V² 成正比）。

5

一个引脚悬空会有什么现象？为什么难查？

看答案

读数随机跳变、误触发中断、功耗异常升高（两管同时半导通）。难查是因为它依赖温湿度、手靠近与否、邻近走线，复现不稳定。

  1. 跑上面的 Python 模拟，算出你板子主频下的单门动态功耗。
  2. 有板子：万用表量按键两端电压（松开/按下），再把内部上拉关掉对比。
  3. 找一份开发板原理图，标出三个上拉电阻并说明为什么是那个值。
  4. 查 i.MX6ULL 手册的 IOMUX PAD 寄存器，找出「开漏」和「上拉」分别是哪几位。
