卷 01·机器与指令·第 06 篇

与、或、非

计算机里所有「判断」最终都化简成三个动作：两个条件都要成立（与）、任一成立（或）、取反（非）。这一课把这三个动作做成门，再证明一件反直觉的事：只要给我「与非门」，我能搭出整台计算机——包括加法器、比较器、乃至 CPU 的每一条指令。

◆ 一读 纯读约 1 小时 左侧是本卷目录 理论为主 · 实作可跳

这一课要回答的问题

① 与、或、非在电路上分别怎么连？② 为什么 XOR 这么重要？③ 德摩根定律在硬件上意味着什么？④ 为什么说「与非门足以搭出一切」？⑤ 同一个逻辑功能，为什么简化后能又快又省电？

1. 直觉：三个开关控制一盏灯

想象两个开关串在一条线上：只有都闭合，灯才亮 → 与（AND）。改成并联：任一闭合灯就亮 → 或（OR）。把开关接成「按下就断开」→ 反相 → 非（NOT）。

失效处：开关串并联会带来电阻累积与电平衰减，逻辑门不会——它有「整形」能力，输出永远是接近 0V 或 VDD 的干净电平。这就是数字电路能级联几千级而不失真的原因：每一级都在重新生成信号。

2. 硬件上：门是管子的不同组合

用 CMOS 实现三种门，只需要调整管子的串并联方式：

门CMOS 结构（上拉网络 PMOS / 下拉网络 NMOS）管子数
NOT1 个 PMOS + 1 个 NMOS，栅极并联2
NANDPMOS 并联在上、NMOS 串联在下4
NORPMOS 串联在上、NMOS 并联在下4
ANDNAND + NOT6
XOR由 4 个 NAND 组成（经典接法）约 12

注意 AND 比 NAND 多两个管子。这不是巧合：CMOS 里「反相」是免费的（输出端天然反相），所以 NAND/NOR 比 AND/OR 更便宜、更快。这就是为什么实际芯片里 NAND 的数量远多于 AND——设计者会主动把逻辑往 NAND 形式推。

3. 德摩根定律：硬件工程师的日常工具

两条恒等式：

¬(A ∧ B) = ¬A ∨ ¬B        （与非 = 非或）
¬(A ∨ B) = ¬A ∧ ¬B        （非或 = 非与）

在硬件上它的意义非常实际：如果你手上只有 NOR 门，想把 A AND B 实现出来，就直接用德摩根：A AND B = ¬(¬A OR ¬B)——用三个 NOR 门（两个做反相，一个做或非）就搞定。「转换门类型」在软件里是改表达式，在硬件里是换一种管子接法。

4. 万能积木：与非门能搭出一切

三条事实：

  1. NOT(x) = NAND(x, x) —— 把两个输入接在一起。
  2. AND(x,y) = NOT(NAND(x,y))。
  3. OR(x,y) = NAND(NOT x, NOT y)（德摩根）。

既然非、与、或都能用 NAND 表示，而任何布尔函数都能用这三个组合表示，那么NAND 是功能完备的。这在工程上意味着：一条产线只做一种标准单元，就能拼出任意芯片。

5. 实验：用代码穷举真值表，验证德摩根

# ① 穷举，这是硬件验证的基本方法
def nand(a, b): return int(not (a and b))
def inv(a):     return nand(a, a)
def AND(a, b):  return inv(nand(a, b))
def OR(a, b):   return nand(inv(a), inv(b))
def XOR(a, b):  return AND(OR(a, b), nand(a, b))

for a, b in [(0,0),(0,1),(1,0),(1,1)]:
    print(a, b, "AND=", AND(a,b), "OR=", OR(a,b), "XOR=", XOR(a,b))

# ② 验证德摩根
for a in (0,1):
  for b in (0,1):
    assert nand(a,b) == OR(inv(a), inv(b))
print("德摩根 OK")

# ③ 只用 NAND 搭 XOR（4 个门），打印中间结果
for a, b in [(0,0),(0,1),(1,0),(1,1)]:
    n1 = nand(a, b); n2 = nand(a, n1); n3 = nand(b, n1); out = nand(n2, n3)
    print(a, b, "->", out)

第三条输出正是教科书里的经典 4-NAND XOR。这个电路会在第 06 课变成全加器的「和」输出——你现在搭的，就是 CPU 算术单元的最小零件。

7. 自测与动手

1

用 NAND 实现 OR，写出表达式。

看答案

OR(a,b) = NAND(NAND(a,a), NAND(b,b))，共 3 个 NAND。

2

为什么 CMOS 里 NAND 比 AND 便宜？

看答案

CMOS 输出天然反相，NAND 只需 4 个管子；AND 要在 NAND 后加一个反相器，多 2 个管子、多一级延迟。

3

A·B + A·B' 化简成什么？在硬件上省了什么？

看答案

等于 A。省掉了与门、非门与或门，关键路径从 3 级降到 0 级（直连）。

4

XOR 为什么叫「不相等检测器」？

看答案

两输入相同输出 0、不同输出 1，正是「不等」的判定。同理 XNOR 是相等检测器。

5

如果只允许用一种门搭 CPU，你选哪种？为什么？

看答案

NAND（或 NOR）。因为功能完备，且 CMOS 实现只需要 4 个管子，是所有门的性价比最优解。

  1. 跑完上面三段 Python，把 XOR 的 4 个 NAND 中间结果画成电路图。
  2. 手算 ¬(A∧B) 与 ¬A∨¬B 的真值表，逐项对比。
  3. 把 A·B + A·B' + A'·B 化简，再用 Python 穷举验证两边等价。
  4. 找一个你熟悉的判断逻辑（如「温度高且湿度低就报警」），写成布尔表达式并化简。
