硬件全书/六篇 52 章/教材：ALPHA V2.8 + CORE V2.0

硬件：从一块板子到能自己画板

这一套课不再讲「板子上大致有什么」，而是拿两块真实的原理图当教材，一个元件一个元件地过。核心板 8 页、底板 8 页，每一页都拆开讲：这根线叫什么、这个电阻为什么取这个值、拆掉它会怎样、拿万用表和示波器该看到什么。目标很具体：给你一块空板，你能自己画出一块能点亮的板子。

教材基准（不是示意图，是这两份 PDF）

  • 核心板：IMX6ULL_CORE_V2.0，8 页 —— 电源 / SoC 电源脚 / DDR3L / Flash / LCD 与 GPIO / 控制与复位与晶振 / 启动配置 / 连接器。
  • 底板：IMX6ULL_ALPHA_V2.8 —— 输入保护、外设供电、USB、以太网、串口与 CAN、LCD 与触摸、按键与 LED、扩展排针。
  • 文中出现的位号（U3、L2、C12、R33…）都来自这两份图，可逐页对照；重绘图只画讲解相关的部分，并保留位号与网络名。
  • 每个值都配一个算法或判据；每个结论都落在「量哪里、看到多少」上。

0六篇的关系

前三篇是「看懂」：先有电学的账（第一篇），再认识每类元件（第二篇），然后拿真图纸逐页读（第三篇）。后三篇是「做出来」：把所有值算一遍（第四篇），布成 PCB（第五篇），再解决可靠性与量产（第六篇）。

顺序读最稳；只想解决问题，可以直接跳到对应篇——但每一篇都假设你读过第一篇那三条公式：欧姆定律、功率、RC 时间常数。

旧版去哪了

原来的「认板子 8 章」和「电路与画板 6 章」不是删掉，是拆散重写：认板子并入第三篇（从核心板第 1 页开始逐页读），电源与接口的章节升级进第四、五篇，故障对照并入第四篇「测量与故障注入」。旧章节地址不再保留，站内链接已全部改到新目录。

怎么用这套课

手边有板子：每读完一章，就打开对应 PDF 页，找到文中那个位号，用万用表量一次。这一章才算读完。

没有板子：先读第一篇与第三篇（能看懂图），第四篇跟着算一遍，第五篇留到有板子再做。

只想画板：1.1–1.5 → 第三篇全篇 → 第四篇 → 第五篇，这四段是画板的最小闭环。
