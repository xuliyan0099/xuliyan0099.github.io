    上下拉与终端取值：4.7K、120Ω、360Ω 从哪来

    原理图上到处是 4.7K、10K、47K、120Ω、360Ω。这些不是「习惯值」，每一个都由上升时间、驱动能力、反射、偏置四件事反推出来。这一章把本板四类电阻全部算一遍。

    读完这一章，你应该能

    1. 用 tr=0.8473·R·C 反推 I2C 上拉的最大值，并校验灌电流下限
    2. 算出 CAN 双终端为什么是 120Ω+120Ω=60Ω，以及偏置 360Ω 的作用
    3. 解释 IO 上拉 10K/47K 在「耗电」与「抗扰」之间的取舍
    4. 用反射与阻抗解释 DDR 时钟 470Ω 串阻与 ODT 10K 下拉
    5. 判断一颗上拉电阻该不该装（DNP）的依据

    4.5.1上拉电阻的第一性原理

    开漏/开集总线（I2C、CAN、RS485、复位）空闲时靠上拉拉高。上拉值同时受两个约束：

    1. 上限（不能太大）：RC 充电太慢，边沿超过规范，通信误码。
    2. 下限（不能太小）：器件拉低时要灌电流，VOL 会抬高，且静态功耗大。

    上升时间公式（从 0 充到 0.7VDD，即 VIH）：

    tr = 0.8473 × R × Cbus

    I2C：本板 4.7K 的来历

    Fast mode（400kHz）要求 tr ≤ 300ns。本板总线只有 SoC + 一两个从器件，走线短，Cbus 估 60pF：

    tr = 0.8473 × 4700 × 60p = 239 ns ✓

    若挂 5 个器件、Cbus=200pF：tr=797ns，400kHz 就超了，必须把上拉降到 1.8K 左右。这就是「I2C 挂太多器件要减小上拉」的量化依据。

    下限校验：I2C 规定 VOL ≤ 0.4V @ 3mA。3.3V 上拉 4.7K 时灌电流 =(3.3−0.4)/4.7K=0.62mA，远小于 3mA ✓。若用 1K，灌电流 2.9mA，接近上限，且功耗 3.6mA×0.5（占空比）=1.8mA。

    4.5.2IO 上拉：10K 与 47K 的分工

    普通 GPIO/BOOT 脚的上拉不参与时序，只做「默认电平」。取值看两件事：

    • 漏电与功耗：若该脚可能被外部拉低（如按键、拨码），上拉电流 = V/R。3.3V/10K=0.33mA，3.3V/47K=70µA。
    • 抗扰：阻值越大，越容易被干扰拉偏。长线、有电机/继电器场合用 10K，板内静态配置用 47K。

    本板 BOOT 配置用 47K（R4–R24）：只在复位瞬间采样，平时不耗电，阻值大没关系；而 BOOT_MODE0/1 用 10K（R43/R44），因为它们还要经拨码开关接地，需要更强的下拉确定电平。

    「DNP（不贴）」也是取值的一部分：一颗上拉画在图上但不贴，等于「预留可能性」。本板 R26（ONOFF 100K 上拉到 VDD_SNVS_IN）标 DNP，是因为 SoC 内部已有上拉，外部再并一颗只是冗余。

    4.5.3CAN 终端：为什么是 120Ω + 120Ω

    CAN 是差分总线，电缆特性阻抗 120Ω。终端匹配的目的：

    1. 吸收反射：两端各接 120Ω，与电缆阻抗匹配，行波不反射。
    2. 提供隐性电平：CAN 收发器靠终端电阻把 CANH/CANL 拉回 2.5V 附近（隐性）。

    两点终端并联后，总线直流负载 = 60Ω。显性时驱动器输出约 1.5V 差分，电流 = 1.5/60 = 25mA，这就是 TJA1050 能驱动的最小负载。

    本板 R14=120Ω 一颗（节点端），RS1=120Ω（RS485 端）。注意：一条总线只能有两端终端，中间节点不能加，否则 3 个 120Ω 并联成 40Ω，电流过大、电平塌陷。

    RS485 偏置：360Ω + 22K 的作用

    RS485 总线在「无驱动器」时必须处于确定状态（fail-safe），否则接收器输出随机。本板用：

    • R25/R26 = 360Ω：A 上拉到 3.3V、B 下拉到 GND，形成约 4.6mA 的偏置电流；
    • R27 = 22K + Q4 SS8050 + R23 10K：自动方向控制，发送时把偏置「短路」掉，避免额外功耗与负载。

    偏置电流要大于「接收器阈值电流 + 终端漏电流」，太小则 fail-safe 失效；太大则增加总线负载。360Ω 在 3.3V 下给出 9.2mA/2≈4.6mA，是典型折中。若总线两端都有 120Ω 终端，偏置电流会多耗 4.6mA×2，所以很多设计把偏置放在主机端。

    4.5.4DDR 终端：470Ω、2.2pF、10K

    DDR3L 的 SDCLK 是差分时钟，频率可达 400MHz+，走线是传输线，必须做源端匹配与终端：

    • R47 470Ω 串在 SDCLK0_P：源端串联匹配，抑制二次反射。取值与驱动阻抗有关（SoC 输出阻抗约 40–60Ω，加上 470Ω 后接近线阻抗的一半，形成「弱驱动」以减小过冲）。同页注释直接写了 “CLK termination: Place RXX close to U2”。
    • C51/C52 2.2pF：与走线电感构成低通，压掉 GHz 级尖峰；也参与阻抗微调。
    • R50/R51 10K ODT 下拉：ODT（On-Die Termination）引脚在复位期间必须确定电平，10K 下拉保证不浮空；正常工作时由控制器驱动。
    • R48/R49 240Ω ZQ：不是上拉，是校准电阻。ZQ 引脚外接 240Ω 精密电阻（±1%），芯片用它校准输出阻抗，DDR3 规范强制要求。

    这些电阻值不能随便改：470Ω 改小会过冲、改大会边沿变慢导致建立时间不足；240Ω 改值会直接让 ODT 阻抗失配。

    4.5.5SD 卡上拉 47K 为什么可以很大

    TF 卡的 CMD/DATA 线在初始化阶段是开漏（OD）模式，需要上拉，规范要求 10K–100K。本板用 47K（R70–R75 是 47Ω 串阻，不同！），实际是 R1–R5 47K/NC。

    为什么能取 47K：SD 时钟初始化只有 400kHz，tr 要求宽松（<几 µs）；进入高速模式后总线改为推挽，上拉不再参与边沿。所以 47K 只负责「不浮空」，不影响速度。

    串阻 47Ω（R70–R75）则是另一个作用：抑制过冲与 EMI，与 SD 卡座的长走线构成阻尼。这与上拉完全是两回事，初学者常混。

    练习

    1. R=4.7K、C=200pF，tr 多少？400kHz 够吗？
    797ns > 300ns，不够，需降到 1.8K 左右。
    2. I2C 上拉 1K 时灌电流多少？有何风险？
    (3.3−0.4)/1K=2.9mA，接近 3mA 上限，且功耗大。
    3. CAN 为什么两端各 120Ω，中间节点不加？
    匹配 120Ω 电缆特性阻抗；中间加会并联成 40Ω，电流过大。
    4. CAN 显性时总线电流多少？
    约 1.5V/60Ω=25mA。
    5. DDR 的 ZQ 240Ω 是做什么的？
    输出阻抗校准基准，±1% 精度，不是上拉。
    6. SD 卡 CMD 用 47K 上拉为何不影响高速？
    高速模式改推挽，上拉只负责初始化阶段不浮空。
