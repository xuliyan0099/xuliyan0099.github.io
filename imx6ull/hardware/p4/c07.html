    分压与采样：12 位 ADC 的 0.8mV 与 1% 电阻

    「用两个电阻分压，接 ADC 就行」——这句话背后有三个坑：分压比精度、源阻抗与采样保持、参考电压噪声。这一章把 12 位 ADC 从 LSB 算到总误差，并给出本板可直接照抄的电池检测电路。

    读完这一章，你应该能

    1. 算 12 位 ADC 在 3.3V 参考下的 LSB，并换算成被测电压的分辨率
    2. 按量程反推分压比与电阻取值，兼顾功耗与源阻抗
    3. 算源阻抗对采样精度的影响，知道为什么建议 <10K
    4. 把电阻误差、参考误差、量化误差合成为总误差
    5. 设计 RC 抗混叠滤波器，并解释「采样前为什么要先缓冲」

    4.7.1LSB：一切精度的起点

    本板 ADC 为 12 位、参考 3.3V（ADC_VREFH 直接接 VDDA_ADC_3P3，C10 104 去耦）：

    LSB = VREF/212 = 3.3/4096 = 0.806 mV

    这只是「理想分辨率」。真实误差还包括：量化 ±0.5LSB、INL/DNL（i.MX6ULL ADC 典型 ±2LSB）、参考噪声、源阻抗引起的建立误差。合起来，有效位数 ENOB 往往只有 10–11 位。

    换算到被测端：若分压比 1/12（测 12V），则输入端每 1LSB 对应 12×0.806=9.7mV。这就是「12V 电池电压只能精确到 10mV」的来源，别指望用它做毫伏级测量。

    4.7.2分压比与电阻取值

    分压公式：VADC = Vin·R2/(R1+R2)。要求最大输入时 VADC ≤ VREF 且留 10% 余量。

    例：监控 12V 适配器（最高 13.2V），取 VADC,max=2.9V：

    R2/(R1+R2) = 2.9/13.2 = 0.22 ⇒ R1:R2 ≈ 3.55:1

    取 R1=100K、R2=28K（或 100K/27K）：分压比 0.2126，13.2V→2.81V ✓。此时分压支路电流 = 13.2/128K ≈ 103µA，一年耗电 0.9Wh，可接受。

    若取 R1=10K、R2=2.8K，电流 1mA，功耗大但源阻抗低（2.5K），采样更准。取舍点就是源阻抗。

    4.7.3源阻抗：为什么建议 <10K

    ADC 内部有采样电容 CS（典型 3–10pF）与采样开关电阻 RSW（典型 100–500Ω）。采样期间，外部源要给 CS 充电，建立时间常数：

    τ = (Rsource + RSW)·CS

    要建立到 0.5LSB（12 位要求约 8.3 个 τ），若采样窗口 1µs：

    τ ≤ 1µs/8.3 = 120ns ⇒ Rsource ≤ 120n/5p ≈ 24K

    本板建议 <10K 是留了 2 倍余量（含温度与批次）。100K/28K 的分压源阻抗 = 100K∥28K = 22K，刚卡在边界——所以高阻分压后面必须加一颗 100nF 电容（形成低通 + 提供电荷），或加运放缓冲。

    这是新手最容易忽略的一点：分压电阻选大了省电，但采样就不准了。折中做法是「高阻分压 + 100nF」：电容在采样瞬间提供电荷，静态功耗仍只有 100µA。

    4.7.4误差合成：把四项加起来

    误差源典型值折算到被测端（12V 量程）
    量化±0.5 LSB±4.8mV
    INL/DNL±2 LSB±19mV
    电阻 1%分压比 ±1.4%±170mV
    参考电压±1%（含纹波）±120mV

    RSS 合成：√(4.8²+19²+170²+120²) ≈ 210mV。结论很清楚：电阻精度与参考精度主导，ADC 位数不是瓶颈。

    所以工程做法：

    • 分压电阻用 1% 薄膜（不要 5% 碳膜），最好同一批次、同封装（温漂一致，比例误差抵消）；
    • 参考电压不要用 DCDC 直出，要经 LDO 或至少 LC 滤波；
    • 需要更高精度就做两点校准（软件乘斜率 + 偏移），可把电阻误差消掉。

    4.7.5RC 抗混叠：采样前必须滤波

    ADC 采样是「离散化」，高于 fs/2 的噪声会折叠到低频（混叠）。例如开关电源 500kHz 纹波，采样率 10kHz，会折到 10kHz−500kHz×n 的某个低频，表现为「读数缓慢漂移」。

    抗混叠滤波器截止频率应 ≤ fs/2：

    fc = 1/(2πRC) ≤ fs/2

    采样率 1kHz ⇒ fc ≤500Hz ⇒ 取 R=10K、C=33nF：fc=482Hz ✓。这颗电容同时兼任 4.7.3 的「采样电荷池」，一举两得。

    4.7.6本板可直接照抄的电池检测电路

    若要在 MINI 板上加「12V 输入电压监测」，接到 ADC1_IN0（GPIO1_IO00 复用）：

    • R1=100K（1%）、R2=27K（1%）→ 分压比 0.2126；
    • R2 并联 100nF（0805 X7R 25V）→ 与 22K 源阻抗构成 fc=72Hz 低通；
    • ADC 脚串 100Ω + 并 1nF 到地，抑制尖峰（可选）；
    • 软件按 13.2V 满量程标定，两点校准。

    算一下实际值：12.0V 输入 → 2.55V → 码值 2.55/0.806=3163。若读数 3100，反推 11.76V，误差 2%（主要来自电阻）。用 1% 电阻 + 两点校准可降到 0.5%。

    练习

    1. 3.3V 参考、12 位的 LSB 是多少？
    3.3/4096=0.806mV。
    2. 测 13.2V 满量程，R1=100K，R2 取多少？
    需分压比 ≤2.9/13.2=0.22，R2/R1 ≤0.28 ⇒ 27K 左右。
    3. 100K∥27K 的源阻抗？有何影响？
    约 21K，接近 24K 边界，建议并 100nF 提供电荷。
    4. 12V 量程下总误差约多少？主导项是什么？
    约 210mV，电阻 1% 与参考 1% 主导。
    5. 采样率 1kHz，抗混叠 RC 怎么取？
    fc≤500Hz，10K+33nF → 482Hz。
    6. 为什么 5% 碳膜电阻不能用？
    分压比误差 ±1.4% 以上，直接吃掉整个精度预算，且温漂大。
