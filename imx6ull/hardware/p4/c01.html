    电流预算与选型：一张表决定所有器件的余量

    设计一块板，第一件事不是画原理图，而是算电流。每一路的平均电流决定电感与铜箔，峰值电流决定电容与连接器，启动电流决定保险丝与上电时序。这一章用本板的真实数字，把三张表算出来。

    读完这一章，你应该能

    1. 列出五个必须分开统计的电流口径：静态、平均、峰值、启动、故障
    2. 用本板六路电源算出总输入功率并反推 12V 侧电流
    3. 按 1.3 倍峰值余量选电感饱和电流、连接器触点、保险丝
    4. 用 IPC-2221 公式算铜箔宽度，知道 1oz 铜 1A 大概多宽
    5. 解释「为什么 5V 母线上的 470µF 比 3.3V 上的更大」

    4.1.1五个电流口径，不能混用

    口径含义用来选什么本板例子

    新手最常犯的错是「只算平均」：平均 400mA 的 3.3V 域，峰值可能 1.5A，用电感 Isat=1A 的器件就会在负载跳变时饱和，输出电压瞬间塌陷，表现为「跑压力测试就重启」。

    汇总：3.3V 域合计约 550mA（含核心板各路），1.35V 域约 1.5A 峰值。把这些换算到 5V 与 12V 输入侧：

    P3V3 ≈ 3.3 × 0.55 = 1.82W（效率 88% → 输入 2.07W）
    P1V35 ≈ 1.35 × 1.0(平均) = 1.35W（效率 85% → 输入 1.59W）

    5V 母线总输入约 3.7W，加 5V 外设 0.75W，共 4.4W；12V 侧电流约 0.37A（再算上 U6/U4 的效率与静态）。所以 2A 保险丝、1A 级别的电感、0.5A/触点的连接器并联 4 个，都是「1.3 倍以上余量」的结果。

    4.1.3启动电流：被忽视的那一项

    上电瞬间，所有输出电容都是短路。以本板 5V 母线的 470µF 为例：

    Q = C·V = 470µF × 5V = 2.35mC
    若 DCDC 限流 1A，充电时间 t = Q/I = 2.35ms

    这 2.35ms 内，DCDC 一直工作在限流状态，输出电压缓慢上升。若下一级（3.3V Buck）在此时就使能，它会看到「输入不足」，可能反复启动（打嗝）。解决办法就是时序：5V 的 PG 经 RC 延时后再使能 3.3V（本板核心板 U6 的 EN 就是这样，R60 10K + C85 104，τ=1ms）。

    再看 USB：MT9700 限流 1.3A，插入 U 盘瞬间，U 盘输入电容（约 10–100µF）充电，电流被限制在 1.3A，电压跌落由 MT9700 的软启动控制。若没有这颗限流开关，插入瞬间可能拉低整板 5V，导致 SoC 复位。

    4.1.4铜箔能扛多少：IPC-2221 公式

    PCB 走线的载流能力不是「1A 对应 1mm」这种口诀，而是与铜厚、允许温升、走线是否外层有关。IPC-2221 的经验公式：

    I = k × ΔT0.44 × A0.725

    其中 A 是截面积（mil²），k 外层 0.048、内层 0.024，ΔT 是允许温升（°C）。反解宽度：

    A = (I/(k·ΔT0.44))1/0.725

    算一个实际值：外层 1oz 铜（35µm≈1.38mil），ΔT=10°C，I=1A：

    A=(1/(0.048×100.44))1.379≈(1/0.132)1.379≈13.9 mil²
    宽度 w=A/1.38≈10 mil ≈ 0.25mm

    也就是说 外层 1oz、10°C 温升下，1A 只需 0.25mm 宽。但工程上不会这么用：

    • 实际按 ΔT≤10°C 且电流×1.5 余量 设计，1A 走 0.5mm；
    • 内层散热差（k 减半），同电流需要约 1.7 倍宽度；
    • 过孔也载流：一个 0.3mm 孔径过孔约 1–2A（镀铜 25µm），大电流要打多个。

    本板的 3.3V 主干在主电源区用了铺铜而不是细线，就是因为 550mA 平均 + 峰值 1.5A，细线会有 20°C 以上温升。

    4.1.5选型的三条硬规则

    1. 电感 Isat ≥ 1.3×Ipeak，且 Irms ≥ Iout。饱和后电感量骤降，电流失控。
    2. 连接器每触点 ≤ 0.5×额定，电源脚并联。0.5A 额定的触点用 1A 会温升过高、接触电阻上升。
    3. 保险丝 ≥ 1.5×正常最大电流，≤ 后级器件耐受。2A 保险丝配 1.3A 限流开关，正常；若配 3A 就会「烧板不烧保险」。

    练习（答案在折叠里）

    1. 五个电流口径里，哪个决定电感饱和电流？
    峰值（µs–ms 级突发）。电感在峰值时必须不饱和。
    2. 470µF 充到 5V、限流 1A，需要多久？
    Q=2.35mC，t=2.35ms。
    3. 外层 1oz、10°C、1A 的走线宽度？
    约 10mil（0.25mm）；工程上按 0.5mm 设计。
    4. 为什么内层同电流要更宽？
    内层被介质包围，散热差，IPC 公式的 k 从 0.048 降到 0.024。
    5. 2A 保险丝配 1.3A 限流开关合理吗？
    合理：保险丝 ≥1.5×正常电流，且后级限流先动作，避免烧板。
    6. 3.3V 平均 550mA、峰值 1.5A，电感怎么选？
    Isat≥1.3×1.5≈2A，Irms≥0.6A，取 3A/2A 以上留余量。
