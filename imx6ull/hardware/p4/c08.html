    测量与故障注入：从「不上电」到定位到一颗电阻

    调试不是「换一颗试试」，而是先设计实验，再看数据，最后收敛到一颗元件。这一章给一套本板可直接执行的流程：限流上电五步、四个关键波形的正确测法、十种故障注入实验与判据表。

    读完这一章，你应该能

    1. 按「限流 0.1A 起」的安全流程给一块新板首次上电
    2. 正确测电源纹波、复位时序、晶振幅度、DDR 时钟（四种不同姿势）
    3. 用 BW=0.35/tr 判断示波器够不够、探头带不带得动
    4. 设计 10 组故障注入实验（短路/开路/拉偏/相位偏移/温变）
    5. 把「现象」映射到「最可能元件」，而不是瞎猜

    4.8.1工具与它们的边界

    工具能测不能测 / 陷阱
    数字万用表直流电压、电阻、通断、二极管高频纹波、动态电流；电阻档测在路电阻会被并联路径干扰
    示波器（100MHz+）纹波、时序、时钟、总线探头地线过长会引入假尖峰；带宽不足会「抹平」真实边沿
    限流直流电源首次上电、功耗限流过低会「假性不上电」；线损导致实际电压偏低
    电子负载负载跳变、效率低速负载无法模拟 CPU 的 ns 级跳变
    热像仪找发热点、LDO 过载发射率设置错误会读低 30°C 以上

    本板调试最少需要：万用表 + 100MHz 示波器 + 可限流电源。缺一样，很多结论就只能靠猜。

    4.8.2首次上电：五步法

    1. 断电测短路：万用表电阻档测 DCDC_5V、DCDC_3V3、VDD_ARM_SOC_IN 对地电阻。判据：>100Ω（1.35V 域可能只有几十 Ω，属正常，但要与同批板对比）。
    2. 限流 0.1A 上电：若电流立刻顶到 0.1A，说明有短路，立即断电。判据：空载电流 <50mA。
    3. 逐级量电压：DC_IN → VM → DCDC_5V → DCDC_3V3 → VDD_ARM_SOC_IN → DRAM_1V35 → NVCC_SD。每级都要在标称 ±5% 内。
    4. 看复位与时钟：POR_B 应为「低 200ms 后高」；OSC_OUT 应起振且 ≥1Vpp。
    5. 放开限流到 1A，观察温升：空载运行 10 分钟，摸 SoC/DCDC/PHY 温度。判据：无明显烫手（<60°C）。

    这五步的价值：把「不启动」拆成电源、复位、时钟三个可独立验证的条件。任何一步失败，后面的都不用看。

    4.8.3四种波形的正确测法

    对象探头设置判据
    电源纹波AC 耦合、20MHz 带宽限制、弹簧地针、10:13.3V <30mVpp；1.35V <20mVpp
    复位时序DC 耦合、双通道（POR_B + DCDC_5V）5V 稳定后 ≥100ms 才释放复位
    晶振×10 探头测 OSC_OUT、DC 耦合24MHz ≥1Vpp；频率 ±50ppm
    DDR 时钟差分探头或双通道相减、全带宽摆幅 1.35V 域约 0.6–0.9Vpp，无明显过冲/振铃

    最容易犯的错：用长地夹测纹波。地线 10cm 约 100nH，在 100MHz 时阻抗 63Ω，开关尖峰全被「测」进来，读数虚高 5–10 倍。

    示波器带宽够不够：BW = 0.35/tr

    被测信号的上升时间 tr 与所需带宽：

    BWmin = 0.35/tr

    DDR3L 数据边沿约 0.5ns ⇒ 需 700MHz 带宽；而 24MHz 晶振边沿约 5ns ⇒ 70MHz 足够。用 100MHz 示波器测 DDR 边沿，看到的是「圆角」，过冲/振铃判据就失效了——不是板子没问题，是仪器看不见。

    探头也有带宽：标配 ×10 探头通常 100–500MHz，且输入电容 10pF。测 400MHz 时钟时，探头电容已经在「加载」电路。

    4.8.4十组故障注入实验

    故障注入 = 主动制造一个已知故障，验证你的保护/判据是否成立。这是把「设计」变成「可验证设计」的关键一步。

    #注入方法期望现象
    15V 短路5V 对地接 1Ω限流电源立刻限流，F1 不应烧（2A）
    23.3V 开路断开 L1 一端SoC 不启动，POR_B 保持低
    3复位线卡低POR_B 对地短接完全无反应，电流很低
    4复位线卡高POR_B 上拉 3.3V可能启动但时序错，偶发挂死
    5晶振停振拆 C12不起振，串口无输出
    6负载电容偏大C12/C14 换 33pF频率偏低、起振变慢
    7输入欠压12V 降到 9V5V 仍稳（Buck 宽输入），但 USB 可能掉
    8输入过压12V 升到 16VTVS 钳位、保险丝不应烧（看 D1 SMBJ5.0A 在前级）
    9DDR VREF 偏R54 换 1.2KVREF 偏离 0.675V，DDR 训练失败/随机死机
    10温度应力热风 60°C 吹 10 分钟LDO 输出漂移、晶振频率漂移，观察是否重启

    做完这十组，你对这块板的「边界」就有量化认识了——这比读十篇文档都有效。

    4.8.5现象 → 元件：判据表

    现象先查再查最后查
    完全不上电，电流 0F1 保险、K1 开关、DC 座VD2 SS34 方向PCB 断线
    上电即限流各域对地电阻DCDC 输出短路、电容反贴SoC 击穿
    5V 正常、3.3V 无U4 EN 电压L1 开路、FB 分压U4 损坏
    电压全对但不启动POR_B 时序OSC_OUT 幅度BOOT 拨码/47K 阵列
    启动后随机死机DDR VREF 与 ZQ1.35V 纹波晶振 ppm 偏差
    串口无输出UART_3V3、CH340TXD/RXD 是否被 SGM3157 切走UART1 引脚复用配置

    4.8.6记录：让下一次调试更快

    每次调试至少记五项：板号、现象、测量值（含挡位）、结论、改动。原因很简单：同类故障会重复出现，而人的记忆只保留「结论」，不保留「当时怎么测的」。一份好的调试记录，半年后能让你 10 分钟内复现问题。

    练习

    1. 0.5ns 边沿需要多少带宽？100MHz 示波器够吗？
    0.35/0.5n=700MHz，100MHz 远不够，会抹平边沿。
    2. 测纹波为什么要开 20MHz 带宽限制？
    滤掉开关尖峰与探头拾取的辐射噪声，只看低频纹波本体。
    3. 首次上电限流设多少？判据是什么？
    0.1A；空载 <50mA，若立刻顶到限流说明短路。
    4. POR_B 一直低，怎么区分「复位芯片坏」与「电源没到」？
    量 U2 的 VDD 脚与 3.3V 域，若 VDD 正常仍低则查芯片/复位线短接。
    5. DDR VREF 应为多少？怎么算的？
    1.35×(1.5K/(1.5K+1.5K))=0.675V。
    6. 网口不亮先量哪三个点？
    VENET_3V3、25MHz 晶振、R64 RBIAS 2.49K。
    7. 为什么调试记录要写「挡位」？
    不同挡位内阻不同，在路测量结果差异大，复现时必须一致。
