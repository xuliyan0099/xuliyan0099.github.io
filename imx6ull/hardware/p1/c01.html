    三种基本量：电压、电流、电阻

    硬件所有的判断，最后都落到三个数：某两点之间的电压、流过某条路的电流、某段路的电阻。这三个量量不准，后面所有「应该是多少」都是猜。这一章不讲理论，只讲在这块板子上量哪儿、用哪个档、读数多少算正常。

    读完这一章，你应该能

    1. 说出这块板子上五路主要电压的标称值与允许范围，并找到对应的测试点
    2. 正确使用万用表的电压档、通断档、电阻档，知道「量电压要并联、量电流要串联」
    3. 解释为什么「GND 是所有测量的参考点」，以及量错参考点会得到什么荒谬结论
    4. 在板上量出 3.3V、1.35V、0V 三种电平，并判断哪一路异常

    1.1.1这块板子上有哪几种电压

    核心板第 1 页右下角有一张 I.MX6ULL PWR 表，列出每一路的 min/typ/max。按它在板上找点，是读图与测量的第一步：

    电压域标称板上网络名大致用途测试点
    输入5VDC5V底板 DC 座 / USB 供电电源座或排针
    IO 与常电3.3VDCDC_3V3、NVCC_GPIOIO、eMMC、PHY、LCDTP4（SNVS 侧）、各处 3.3V 点
    内核与 DDR1.35VVDD_ARM_SOC_IN、DRAM_1V35Cortex-A7、DDR3LTP3、TP7
    常电域3.0VVDD_SNVS_3V3RTC、唤醒、常开逻辑TP4
    SD 卡1.8 / 3.3VNVCC_SDTF 卡信号电平（可切换）TP6
    摄像头2.8VNVCC_CSICSI 接口（由 U12 产生）TP8

    注意最容易被忽略的一条：3.0V 不等于 3.3V。SNVS 是独立的一路（U7 ME6209A33 从 DC3V 产生 3.3V，再经内核稳压成 3.0V 域），量错点会得出「电源坏了」的错误结论。

    量哪一路选一个电压域，看测试点、正常范围与异常判读

    1.1.2电阻：不要断电就量「在板电阻」

    电阻档最常被误用：直接在线量一颗电阻，读数往往比标称小很多。原因很简单——它和板子上其他路径并联了。要判断一颗电阻是好是坏，正确做法是：断电、至少一端翘起（或拆下），再量。

    想确认什么怎么量正常读数异常说明
    上拉电阻是否装错断电，量该网络对 3.3V 的电阻≈ 标称（10k / 4.7k）远小于标称 → 别处有并联或短路
    是否短路到地断电，量该网络对 GND几百 Ω 以上（电容充电会爬升）接近 0Ω → 短路，禁止上电
    走线是否断通断档，量两端焊盘响（< 几 Ω）不响 → 断线或过孔开路
    电容是否击穿断电，量电容两端先低后升（充电）一直为 0 → 击穿
    三个会让读数骗你的情况

    1. 板上有电。万用表电阻档会给被测电路注入电流，有电时读数完全不可信。断电并等电容放完电再量。

    2. 手捏着表笔。人体电阻几百 kΩ 会并联进去，量 10k 上拉时读数明显偏小。

    3. 量的是「网络」不是「元件」。同一个网络上有多个元件，你量到的是它们的并联结果。

    1.1.3电流：只在必要时量，而且要串联

    电流是「流过某条路」的量，不存在「某点的电流」。所以量电流必须把这条路断开，把表串进去。板上更实用的做法有两个：

    1. 用限流电源读。把 5V 电源设成 5V/500mA 限流，直接看它显示的电流。这是首板调试的标准做法，既能量电流又能防烧板。
    2. 用 0Ω 电阻当分流点。原理图上不少地方有 0Ω 跳线（比如 R33 0R 串在 POR_B 上），拆掉它串入电流表或换成分流电阻，就能测某一段的电流。

    典型参考值（5V 输入侧，板子跑 Linux 空闲）：约 200–400mA；启动峰值可能到 600–800mA；屏幕亮起再加 100–300mA。看到 1A 以上且不发烫，先怀疑有短路。

    1.1.4GND：所有测量的基准，也是最大的坑

    「电压是两点之间的电位差」。你量 1.35V，量的其实是「测试点相对 GND」的电位。所以：

    • 黑笔必须接在这块板子的 GND，不能接在别的地方（比如电脑机箱、另一个电源的负极）。
    • 板上 GND 与 AGND 可能是两个网络（模拟地单独走），量模拟电路要以 AGND 为参考。
    • 用示波器时，探头的地夹就是这个「黑笔」。地夹位置不对，波形会带一堆噪声，甚至短路。
    为什么这块板要分「3.0V 常电」和「3.3V 主电源」

    因为 RTC 与唤醒逻辑要在整机断电后继续活着（否则时间丢失、无法按键唤醒）。所以设计上给它单独一路：VDD_SNVS_3V3，由 U7 从 DC3V 产生，再经内核内部 LDO 降到 3.0V 域，并由纽扣电池 VDD_COIN_3V 兜底（原理图上标了「确认断电放电 > 40µA 才可用」）。这一路的电流只有几 µA 到几百 µA，所以用小 LDO 完全够。

    自测

    量 TP3 得到 1.05V，说明什么？
    1.35V 域异常。先确认黑笔确实在 GND、表在直流档；再看这一路是否被负载拉塌（DDR 或内核短路）、DCDC（U6 MT3420B）是否正常起振、反馈分压电阻是否虚焊。不要先怀疑 SoC 坏了。
    为什么「在板量 10k 上拉」读数常常只有 2–3k？
    因为它与被拉网络上的其他元件并联了：芯片内部 ESD 二极管、其他上拉、去耦电容的漏电都会参与。要判断这颗电阻本身，必须断电并把它一端翘起再量。
    量 3.3V 时读数在 3.28–3.35V 之间跳，正常吗？
    正常。开关电源本身有纹波（几十 mV），负载也在变化。判断「稳不稳」要看纹波峰峰值（示波器 AC 耦合、20mV/格），而不是看万用表最后一位。但若跳到 3.0V 以下，就要查负载与电感。
