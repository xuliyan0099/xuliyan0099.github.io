    三种基本量：电压、电流、电阻

    硬件工程师的日常工作，八成时间在回答三个问题：这一点对地电压是多少？这条路上流过多大电流？这个节点等效电阻多大？这三个量不是三个公式，而是三套「看图说话」的方法。这一章从电位讲到实测，把万用表三档真正用会。

    读完这一章，你应该能

    1. 说清「电压是两点之差」的含义，并能解释为什么万用表要有一根表笔接 GND
    2. 说出本板五路主电压的名称、数值、负载与测试点，形成一张脑内地图
    3. 独立完成一次「上电五点体检」，并判断读数是否正常
    4. 在读数异常时，按「谁供电 → 谁稳压 → 谁负载」的顺序定位到具体一路

    1.1.1电压：不是「有多少电」，而是「差多少」

    很多人第一次学电学，会把电压理解成「电的多少」。这个理解会立刻在测板上翻车：你拿万用表量 3.3V，红表笔点在 3.3V 网络上，黑表笔悬空，表上显示的是一个乱跳的数字（通常是感应电压，几十毫伏到几伏）。为什么？因为电压永远是两点之间的差值，单独一个点没有电压。

    用一个更直观的类比：把电荷想成水，把导线想成水管。电压就是水位差（水压），不是水量。同一个水池，底部与水面的「压差」决定了水能推动多大的涡轮；而水池里存了多少水，那是「电荷量」，单位是库仑，跟电压不是一回事。

    电位的严格定义

    电场中某点的电位，等于「把单位正电荷从该点移到无穷远（或参考点）时，电场力做的功」。两点之间的电压（电位差）就是两个电位相减：UAB = VA − VB。

    这句话有两个直接推论：① 电压有方向（A 相对 B 是正还是负）；② 换参考点，所有电位一起平移，但任意两点之差不变。所以工程上永远说「某点对地电压」，把 GND 定为 0V 参考。

    第三条推论更实用：电压可以为负。当你把黑表笔接 3.3V、红表笔接 GND 时，表会显示 −3.3V。这不是「坏了」，只是你把参考点换了。RS485 的 A/B、运放的正负输入、电感的反向电动势，都会出现负电压——习惯它，比背公式重要。

    1.1.2本板的五路电压：一张必须背下来的地图

    i.MX6ULL 不是「一个 3.3V 供电的单片机」。它内部按功能分成多个电压域：内核要 1.35V（低压省电、速度快），DDR 要 1.35V（DDR3L 规范），IO 要 3.3V（兼容外部器件），SNVS 常电域要独立 3.3V（主电断了还得活着），摄像头 IO 要 2.8V，SD 卡还要能在 1.8V 与 3.3V 之间切。

    为什么不能全用 3.3V？两个原因：第一，先进工艺的晶体管栅氧很薄，3.3V 会直接击穿，所以内核必须降压；第二，降压能显著降低动态功耗（功耗与电压平方成正比，1.35V 相对 3.3V 只有约 1/6），这对靠电池或 USB 供电的设备是生死线。

    电压域数值主要喂给谁测试点为什么是这个值
    VDD_ARM_SOC_IN1.35VARM 核 + SOC 逻辑TP3工艺允许的最低工作电压附近，兼顾功耗与稳定性
    DRAM_1V351.35VDDR3L 颗粒与 DDR 接口TP7DDR3L 规范电压（DDR3 是 1.5V）
    DCDC_3V33.3VNVCC_GPIO、上拉、底板外设—与绝大多数外设电平兼容
    VDD_SNVS_3V33.3VRTC、唤醒逻辑、常电寄存器TP4主电断开仍要工作，独立 LDO
    NVCC_CSI2.8V摄像头并行接口 IOTP8CMOS 传感器常用 2.8V IO
    NVCC_SD1.8 / 3.3VSD 卡 IOTP6高速模式要求 1.8V，普通模式 3.3V

    这张表要背到什么程度？背到闭着眼睛能说出「TP3 是 1.35V、TP4 是 SNVS、TP6 是 SD、TP7 是 DDR、TP8 是 2.8V」。调试时这五个点就是你的「听诊器」，先量它们，再谈别的。

    1.1.3电流：电子跑得很慢，信号跑得很快

    电流的定义是「单位时间通过截面的电荷量」：I = Q/t，单位安培（A），1A = 1C/s。这里有个反直觉的事实：导线里电子的漂移速度只有每秒几毫米到几厘米，但电信号（电场/电磁波）的传播速度接近光速（PCB 上约 6mil/ps，即约 15cm/ns）。

    所以「一按开关灯就亮」不是因为电子从开关跑到灯泡，而是因为电场几乎瞬间建立，整条导线里的电子同时开始挪动。这个区分在高速设计里至关重要：信号完整性关心的是电场与阻抗，不是电子跑多快。

    工程上还有两个约定要记住：

    • 电流方向按「正电荷流动方向」约定，实际金属里是电子反向移动。算电路时一律按约定方向，不用管电子。
    • 电流分「稳态」与「瞬态」：稳态是万用表能读的平均值；瞬态是示波器/电流探头才能看到的脉冲。芯片的功耗几乎全是瞬态，所以「万用表量出 200mA，芯片却要 2A 峰值」很常见。

    1.1.4电阻：把电流翻译成电压的器件

    电阻的微观解释：电子在导体里移动时不断与晶格碰撞，碰撞把动能变成热。电阻 R = ρL/S（电阻率×长度/截面积），所以同样的材料，越细越长电阻越大。这也是 PCB 走线有电阻、过孔有电阻、连接器有接触电阻的原因。

    欧姆定律 U = IR 在下一章展开，这里先建立一个直觉：电阻是「电流的计量器」。你想知道一条路上流过多大电流，最常用的办法不是把表串进去（麻烦且危险），而是测它两端电压，再用 I = U/R 算出来。板上大量「采样电阻」「检测电阻」就是干这个的。

    1.1.5万用表三档：完整操作流程

    以常见数字万用表为例，三个档位的用法完全不同，混用会得到「看起来有数、其实是错的」结果。

    档位测什么怎么接必须先做的动作典型错误
    直流电压 V⎓两点电位差并联：红笔点被测点，黑笔接 GND选对量程（自动量程表跳过）黑笔没接 GND，读数乱跳
    直流电流 A⎓流过回路的电流串联：断开回路，把表串进去确认量程与保险丝并联在电源上 → 直接短路烧保险
    电阻 Ω两点间等效电阻并联在断电的元件两端必须断电，并放电带电测量 → 读数错，甚至损坏表

    1.1.6上电五点体检：把流程变成肌肉记忆

    板子「不启动」时，不要先怀疑软件。按下面五步走一遍，90% 的电源类问题在 3 分钟内定位。

    1. TP4（SNVS 3.3V）：这是常电域，最先要有。没有 → 查 U7 与输入。
    2. TP3（1.35V）：内核电压。没有或偏低 → 查 U1、L2、反馈分压。
    3. TP7（DRAM 1.35V）：DDR 电压。没有 → DDR 初始化必失败，串口通常停在早期。
    4. TP6（SD 电压）：随卡状态变化，未插卡时可能是 3.3V 或 0V，别当故障。
    5. TP8（2.8V）：摄像头 IO，缺失只影响摄像头，不影响启动。
    读数判据

    标称 ±5% 内算正常（1.35V → 1.28–1.42V；3.3V → 3.14–3.47V）。但「正常」还要看纹波：万用表只能读平均值，纹波要用示波器（交流耦合、20MHz 带宽限制）。一个「1.35V 正常」的轨，纹波 200mV 照样让 CPU 随机死机。

    1.1.7案例：TP3 只有 0.9V，怎么查

    这是真实会遇到的读数。0.9V 既不是 0 也不是 1.35V，说明「有输出但不对」，通常是反馈或负载问题。按下面这棵树走：

    1. 先断开负载？不。先量输入：U1 的 VIN 是否有 5V；若输入就低，问题在上一级。
    2. 量反馈点（FB）：若 FB 明显低于规格 Vref，芯片会拼命加大占空比，输出仍上不去 → 说明负载过重或电感饱和。
    3. 量 SW 节点波形：有开关但占空比接近 100% → 说明它在「全力输出仍不够」，查电感/短路。
    4. 断电量输出对地电阻：几欧甚至零欧 → 负载短路（常见是 DDR 或 SoC 内部）。
    5. 查反馈电阻：上端虚焊会让输出冲高；下端虚焊会让输出偏低。用电阻档在位对比两颗分压电阻。
    不要犯的三个错

    1. 用万用表「通断档」找短路：它只给几十毫伏，测不出低阻短路，应该用电阻档量具体阻值。

    2. 怀疑芯片之前不量输入：一半的「芯片坏了」其实是输入电容虚焊/前级没起来。

    3. 反复上电试：输出只有 0.9V 时可能伴随大电流，反复上电会烧更多东西。先断电量阻抗。

    1.1.8十条常见误区

    1. 「电压是电的多少」：错，电压是差值；电荷量是另一回事。
    2. 「黑表笔随便放」：错，黑笔必须接参考点（通常 GND），否则读的是「两点乱差」。
    3. 「万用表读数就是真实值」：错，它读的是平均值，纹波与瞬态看不到。
    4. 「3.3V 网络到处都是 3.3V」：错，同名网络在不同位置可能有压降（走线、连接器）。
    5. 「电流档可以当电压档用」：错，电流档内阻极小，并联在电源上等于短路。
    6. 「带电测电阻没问题」：错，读数错且可能损坏仪表。
    7. 「1.35V 低了就调高反馈」：错，先查负载与输入，盲目调反馈会烧后级。
    8. 「电压正常就电源没问题」：错，纹波、时序、上电斜率都可能是故障源。
    9. 「GND 就是 0V，处处相同」：错，大电流回流路径上地电位会抬升（地弹）。
    10. 「电子跑得快所以灯亮得快」：错，是电场传播快，电子漂移很慢。

    练习（答案在折叠里）

    1. 黑表笔接 3.3V、红表笔接 GND，读数是多少？为什么？
    −3.3V。电压是「红笔电位减黑笔电位」，参考点换了，符号就反了。
    2. 为什么不能把电流档并联在电源两端？
    电流档内阻很小（近似短路），并联会形成大电流回路，烧表内保险丝，严重时炸表笔/损坏电源。
    3. 量到 1.35V 完全正常，但板子随机死机，下一步查什么？
    查纹波与瞬态：示波器交流耦合量峰峰值，看负载跳变时的跌落；再查 DDR 的 VREF 与时钟。万用表平均值正常不代表电源合格。
    4. 在路量一颗 10k 电阻读到 6.8k，说明什么？
    说明它与其他元件并联，等效阻值变小。要准确测量需拆一端；6.8k 也提示「并联了一支约 22k 的通路」。
    5. TP4 有 3.3V、TP3 是 0V、TP7 是 0V，最可能的原因是什么？
    SNVS 正常说明输入与常电 LDO 正常；内核与 DDR 都没起来，通常是主 DCDC 的使能/时序没释放（EN 被拉低或前级 PG 未到）。
    6. 为什么「电压正常」还要看「上电顺序」？
    因为 SoC 要求内核、IO、DDR 按特定顺序建立，顺序错会导致 IO 灌电、内部闩锁或 Boot ROM 采样错误。电压对但顺序错，照样不启动。
