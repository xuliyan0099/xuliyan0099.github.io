    功率、发热与降额：一颗 0402 到底能扛多少毫安

    「这颗电阻会不会烧」不是靠手感回答的。它等于三道计算：实际功耗 P、降额后的允许功耗 Pallow、结温 Tj。这一章把这三道算完，并用本板真实位号（R6、R43–R50、R9/R10/R38、U4、U7）各算一遍——算完你会发现，大多数「烧了」不是功率不够，而是没降额、散热没算、或者瞬时脉冲没人管。

    读完这一章，你应该能

    1. 用 P=UI=I²R=U²/R 三种形式快速算功耗，并知道该选哪个
    2. 读懂电阻的降额曲线：为什么 70°C 之后额定功率要打折
    3. 用 Tj = Ta + P×θJA 判断「烫不烫、会不会热失控」
    4. 给本板六个真实功耗点算账：LED、BOOT 上拉、eMMC 上拉、DDR VREF、DCDC、LDO
    5. 区分「连续功率」与「脉冲能量」，知道 TVS 和浪涌电阻为什么按能量选

    1.3.1三个公式，四种场景

    功率的三个等价形式：P = U×I = I²R = U²/R。选哪个，取决于你手上有什么：

    • P = U×I：知道两端电压和流过电流。适合整体评估（这块板一共耗多少）。
    • P = I²R：知道电流和电阻。适合算电阻发热，也是「电流翻倍、发热四倍」的来源。
    • P = U²/R：知道压降和电阻。适合上拉、限流、分压这类「电压已知」的场合。

    场景一：LED 限流电阻（R6 = 510Ω）

    MINI 的电源指示灯由 3.3V 经 R6 510Ω 点亮。LED 正向压降 Vf 约 1.8–2.0V（红光），于是：

    I = (3.3 − 2.0)/510 ≈ 2.55mA
    PR6 = I²R = (2.55mA)²×510 ≈ 3.3mW
    PLED = Vf×I ≈ 2.0×2.55mA ≈ 5.1mW

    3.3mW 对 0402（额定 62.5mW）只有 5%，随便用。但若把它挪到 12V 上：I=(12−2)/510=19.6mA，P=I²R=196mW，已经超过 0805 的 1/8W——这就是「换电压不换电阻」的典型翻车。

    场景二：上拉阵列（R43–R50）

    BOOT 区 2×10k + 6×4.7k 全部上拉到 3.3V（第 1.2 章算过电流）：

    I总 = 2×(3.3/10k) + 6×(3.3/4.7k) ≈ 0.66 + 4.21 = 4.87mA
    P总 = 3.3×4.87mA ≈ 16.1mW，单颗最大 3.3²/4.7k ≈ 2.3mW

    单颗 2.3mW 毫无压力，但 16mW 是常驻功耗：电池设备待机 30 天，这点电流就要吃掉约 11.5Wh（0.016W×720h）。这就是低功耗设计要把「一直流」的上拉改成可控上拉的原因。

    场景三：DCDC 的效率损耗（U4）

    U4（DC JW5060T_6）把 DCDC_5V 降到 DCDC_3V3。假设负载 1A、效率 88%：

    • 输出功率 Pout = 3.32×1 = 3.32W；
    • 输入功率 Pin = 3.32/0.88 ≈ 3.77W；
    • 损耗 Ploss ≈ 0.45W：高侧 MOS 导通 + 开关损耗约 0.2W，低侧同步 MOS 约 0.1W，电感 DCR 约 0.1W，静态与驱动约 0.05W。

    0.45W 在 SOT-23-6 里是烫手的：θJA 约 200°C/W，温升 90°C。所以这类 DCDC 芯片底下必须有大铜皮/散热焊盘——这也是第 5.6 章单独讲「电源平面与散热」的原因。

    场景四：LDO 的压差损耗（U7）

    U7（ME6209A33）把 5V 降到 3.3V 给 SNVS。LDO 的损耗是「压差 × 电流」，全部变成热：

    P = (5 − 3.3) × Iout + 5×Iq ≈ 1.7×Iout

    50mA 时 85mW；150mA 时 255mW。SOT-23-5 的 θJA 约 250°C/W，255mW 就是 +64°C——环境 40°C 时结温 104°C。这就是「能用 LDO 的地方尽量别用大压差」的原因（完整算法见 4.3）。

    1.3.2额定功率的真相：它是在什么条件下测的

    数据手册上「0402 1/16W」有一行小字：在 70°C 环境、推荐焊盘、标准测试板上测得。换成你的板子，条件变了，这个数就不再成立。三个变量：

    • 焊盘与铜箔面积：焊盘越大、连的铜越多，散热越好；孤立小焊盘可能只有标称的 60%。
    • 环境温度：70°C 是降额起点，越热可用的功率越小。
    • 邻近热源：贴着 DCDC 电感、LDO、MOS 的电阻，等效环境温度高得多。

    所以工程第一原则是：按额定功率的 50% 用（高温环境 30%）。这不是保守，是把「焊盘、环境、批次」三个不确定量一次性吃掉。

    1.3.3降额曲线：70°C 之后线性打折

    厚膜贴片电阻的典型降额曲线：70°C 以下 100%，从 70°C 线性降到 155°C 的 0%。折算系数：

    k(T) = (155 − T)/(155 − 70)　（70°C ≤ T ≤ 155°C）

    • 85°C：k = 70/85 ≈ 0.82 → 0402 只剩 51mW；
    • 105°C：k = 50/85 ≈ 0.59 → 37mW；
    • 125°C：k = 30/85 ≈ 0.35 → 22mW。

    再叠加「50% 工程余量」，85°C 环境下 0402 的实际可用功率约 26mW。回到 R6：3.3mW，余量充足；BOOT 上拉单颗 2.3mW，也没问题；但你要用 0402 做过百毫安的采样电阻就必须换 0805/1206 或并联。

    并联不是「功率相加」那么简单

    两颗同阻值并联，总阻减半；同样电流下总功率只有原来一半，每颗承担 1/4——所以并联确实提高功率余量。但 两颗不等值时不会均分：阻值小的分到更多电流、更多热，先烧。做功率分配要么同批同值，要么每颗串一个小均流电阻。

    1.3.4结温：真正决定「会不会烧」的那个数

    器件坏不坏，看的是结温（内部芯片温度），不是外壳、也不是手指摸到的温度：

    Tj = Ta + P × θJA

    θJA 是「结到环境」热阻（°C/W），由封装、焊盘、铜箔、风道共同决定。常见量级：

    器件典型 θJA含义
    0402 电阻300–400 °C/W30mW → 温升 9–12°C
    0805 电阻200–250 °C/W125mW → 温升 25–31°C
    SOT-23-5 (LDO)200–250 °C/W250mW → 温升 50–62°C
    SOT-23-6 (DCDC)180–220 °C/W450mW → 温升 80–99°C
    SMA 二极管100–150 °C/W0.5W → 温升 50–75°C

    判据：Tj 要留 20–30°C 余量（商用级上限 125°C，工业级 150°C）。算出来 120°C 就是「已在悬崖边」——环境再高 10°C、负载再重一点就进热失控。

    压降 1.30 V

    1.3.5脉冲功率：为什么 TVS 标「峰值 400W」

    TVS（MINI p4 的 SMBJ5.0A / SMBJ3.3A）说明书上有吓人的数字：400W 峰值脉冲功率。但它只在 10/1000µs 波形下成立——脉冲很短，热量来不及扩散，芯片能瞬时承受远超连续功率的能量。判据不是功率，而是能量与结温：

    E = ∫U(t)·I(t)dt　　ΔT ≈ E / Cth

    所以选 TVS 看三条：① 钳位电压 Vc 低于后级耐压；② 峰值脉冲电流 IPP 大于浪涌电流；③ 波形与重复率匹配（雷击 8/20µs、ESD 接触放电，能量差几个量级）。连续功率那栏（通常几百 mW）只用于「稳态误接」评估。

    同理，浪涌/限流电阻（RS485 的 R27 22Ω、CAN 的 R57 510Ω）在浪涌瞬间承担的能量也远大于稳态：稳态几毫瓦，一个 8/20µs、10A 的浪涌就能让 22Ω 瞬时吃 2.2kW。选型看脉冲降额曲线，不是额定功率。

    1.3.6怎么在板上验证：四种测法

    1. 算：量压降与电流，P=UI。最准，但要断开回路串表。
    2. 反算：已知阻值，量两端电压，P=U²/R。不用断线，适合上拉、限流电阻。
    3. 摸：手指背轻触 3 秒。能按住 ≈ 低于 60°C；立刻缩手 ≈ 70–80°C；闻到味儿就该断电。只粗判，高压区别摸。
    4. 看：热像仪找热点；或热电偶贴器件表面，配合「已知 P 反推 θJA」验证散热是否达标。

    一个实用技巧：想知道某一级电路的总损耗，用「输入功率 − 输出功率」作差，比逐个器件算更快。

    三个真实翻车现场

    ① 用 0402 0Ω 当跳线过 1A：实测 30mΩ，P=30mW 没事；换成 0603 的「0」是 50mΩ，1.5A 就是 112mW，超过 1/10W 的一半——烫、变色、最终开路。0Ω 也要看额定电流。

    ② LDO 从 12V 降到 3.3V 带 200mA：P=1.7W，SOT-23 直接烧。大压差必须用 DCDC。

    ③ 三颗 0805 并联做 1A 采样：以为均分 0.33A/颗，实际一颗 0.5A、两颗 0.25A（阻值公差导致），热的那颗先漂移、再正反馈。并联要留均流设计。

    1.3.7五个设计误区

    1. 只看额定功率，不看降额。85°C 实际只剩 82%，125°C 只剩 35%。
    2. 把「室温手摸不烫」当安全。结温比壳温高几十度。
    3. 忽略邻近热源。贴在电感旁，等效环境温度可能高 20–30°C。
    4. 用连续功率评估脉冲。TVS、浪涌电阻、开机冲击都按能量算。
    5. 忽略铜箔散热。同样封装，1cm² 铜与孤立焊盘，θJA 能差一倍。

    练习（答案在折叠里）

    1. 3.3V 经 510Ω 点亮 Vf=2.0V 的 LED，电阻功耗多少？
    I=(3.3−2.0)/510=2.55mA；P=I²R≈3.3mW。0402 完全够。
    2. 0402（1/16W）放在 105°C 环境，允许功耗约多少？
    k=(155−105)/85≈0.59，62.5mW×0.59≈37mW；再按 50% 余量约 18mW。
    3. SOT-23-5 LDO 压差 1.7V、150mA、θJA=250、环境 40°C，结温？
    P=255mW；ΔT=0.255×250≈64°C；Tj≈104°C，接近 125°C 上限，需加铜箔或降流。
    4. 为什么 TVS 的 400W 不能用于稳态？
    400W 是 10/1000µs 脉冲峰值，热量来不及扩散；稳态看连续功率（几百 mW）与结温。
    5. 两颗 10k 并联当 5k 用，每颗功耗是原来的多少？
    总功率变 1/2，每颗 1/4。阻值不等时电流不均分，阻值小的更热。
    6. 手摸 0805「有点温」，能判断安全吗？
    不能。壳温 50°C 时结温可能 80–100°C；要算 Tj=Ta+P·θJA，或用热像仪/热电偶。
