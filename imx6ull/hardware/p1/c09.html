    数字电平：3.3V 与 5V 到底能不能直连

    「3.3V 输出接 5V 输入」不是看数字大小，而是看四个门限：VOH、VOL、VIH、VIL。它们之间的余量叫噪声容限，决定了你的板子在温度、负载、干扰下还能不能可靠识别 0 和 1。这一章把四个门限讲清，再给四种电平转换方案，最后落到本板：SD 卡 1.8/3.3V 切换、SGM3157 模拟开关、DDR 1.35V。

    读完这一章，你应该能

    1. 画出 VOH/VOL/VIH/VIL 四条线与噪声容限
    2. 判断「3.3V 驱动 5V TTL / 5V CMOS」是否可靠，并说清差在哪
    3. 给出四种电平转换方案及其代价（分压、MOS 双向、专用芯片、开漏上拉）
    4. 解释扇出、上升时间、负载电容对数字链路的影响
    5. 读懂板上 NVCC_SD 的 1.8V/3.3V 切换与 SGM3157 模拟开关的用途

    1.9.1四个门限：数字世界的「判决线」

    数字接口的规范只关心四个电压：

    参数含义典型（3.3V CMOS）
    VOH输出高电平的最小值（带规定负载）≥ VDD−0.4 ≈ 2.9V
    VOL输出低电平的最大值≤ 0.4V
    VIH输入认「1」的最低电压≥ 0.7×VDD ≈ 2.3V
    VIL输入认「0」的最高电压≤ 0.3×VDD ≈ 1.0V

    两个噪声容限：

    高电平容限 = VOH − VIH ≈ 2.9−2.3 = 0.6V
    低电平容限 = VIL − VOL ≈ 1.0−0.4 = 0.6V

    这就是「3.3V 系统能容忍 0.6V 干扰」的由来。凡是设计得当的接口，两个容限都不小于 0.3–0.5V；容限为负，就是「规范上就不保证」。

    1.9.23.3V → 5V：三种接收端的差别

    关键在接收端的 VIH：

    • 5V TTL（老 74LS 系列）：VIH 固定 2.0V。3.3V 输出的 2.9V > 2.0V → 可以直接驱动。
    • 5V CMOS（74HC/HCT）：VIH=0.7×5=3.5V。3.3V 输出只有 2.9–3.3V → 不保证，可能识别成 0 或抖动。HCT 系列是特例（TTL 门限，2.0V），可以兼容。
    • 5V 容忍输入（5V-tolerant）：手册明确写「输入可到 5.5V」，则 5V 器件可以直接驱动 3.3V 器件；但反过来 3.3V 驱动 5V CMOS 仍看 VIH。

    反方向（5V → 3.3V）更危险：i.MX6ULL 的 GPIO 由 NVCC_GPIO=3.3V 供电，不是 5V 容忍。5V 直接灌进 IO，会经 ESD 二极管灌到 3.3V 轨，轻则抬压、重则烧 IO。必须做电平转换或至少串阻+钳位。

    1.9.3四种电平转换方案

    方案适用代价 / 风险
    电阻分压单向、低速（<100kHz）高电平被压低、上升沿变慢、功耗常驻
    MOS 双向I2C 等双向开漏总线需要两侧上拉；速率受 RC 限制
    专用电平转换芯片高速、多路、双向成本、要选对方向与速率
    开漏 + 上拉到目标电压单向/双向、低速只能拉低，高电平靠上拉；速率受 RC 限制

    算例：5V → 3.3V 用 10k/20k 分压，得到 5×20/30=3.33V，看似刚好；但接收端 VIH=2.3V，余量只有 1V，且分压电阻与线容构成 RC，100kHz 以上边沿就圆了。分压只适合「慢速、单向、不关键」的信号。

    MOS 双向转换的经典结构：一个 NMOS，栅极接 3.3V，源极接 3.3V 侧、漏极接 5V 侧，两侧各加上拉。3.3V 侧拉低时，MOS 体二极管先导通把 5V 侧拉低，然后沟道建立，双方都到低；5V 侧拉低时同理。它的巧妙之处是自动识别方向，I2C 常用这个结构。

    1.9.4扇出、上升时间与负载电容

    一个输出能带几个输入，取决于电流能力与电容负载：

    • 直流扇出：IOH/IIH 与 IOL/IIL 取小者。CMOS 输入几乎不吸电流，所以扇出可以很大；TTL 输入要吸 0.4–1.6mA，扇出就小。
    • 交流扇出：每个输入有 3–10pF 电容，走线也有电容；tr≈2.2RC 会随负载增大而变慢，超过协议上限就出错。
    • 驱动强度可调：SoC 的 IO 通常可配驱动电流（如 4/8/12/16mA），强驱动边沿快但 EMI 大。

    本板的 I2C 就是典型：4.7k 上拉 + 100pF 总线电容，tr≈1µs，100kHz 勉强、400kHz 不行（第 1.2 章算过）。

    1.9.5本板的三个真实电平场景

    ① SD 卡：1.8V 与 3.3V 切换（NVCC_SD）

    U9（TMI6030）的输出不是固定 3.3V，而是由 SD1_VSELECT 选择：VSELECT=0 时约 3.27V，=1 时约 1.81V（CORE p1 上就印着这两个数）。原因：SD 3.0 规范在高速模式下要求 1.8V 信号，卡初始化用 3.3V，切到高速再降到 1.8V。同一组引脚，两种电平——这是「电平不是常量」的最好例子。

    ② UART 调试口：SGM3157 模拟开关

    MINI p4 用 U12/U13（SGM3157，单刀双掷模拟开关）把 CH340 的 TX/RX 在 UART1 与 UART3 之间切换。模拟开关不是电平转换，它只是「换线」，但要求信号幅度在它的供电范围内（3.3V 供电、信号 0–3.3V），否则会削顶或漏电。

    ③ DDR：1.35V 域

    DDR3L 的 IO 是 1.35V，与 3.3V 域之间没有直接连线（SoC 内部有专用 DDR 接口）。读图时看到 DRAM_* 网络，就不要指望它和 GPIO 直连——它们属于不同的电平域。

    1.9.6怎么测：示波器看边沿，万用表只能看「平均」

    1. 示波器：看 VOH/VOL 实际值、上升时间、过冲/振铃。探头要短地线，否则你看到的是探头振铃而不是电路。
    2. 万用表：只能测「平均电压」。一个 1MHz、50% 占空的方波，万用表读到 1.65V——不要用它判断数字电平。
    3. 逻辑分析仪：看协议层的 0/1 与时序，比示波器更适合排查「偶尔错一位」。

    一个实用判据：如果 VOH 实测只有 2.4V（规范 2.9V），先怀疑负载过重/上拉冲突/驱动能力配置过低，而不是接收端坏了。

    三个常见事故

    ① 5V 传感器直接接 3.3V GPIO：开机瞬间 IO 被灌到 4.5V，ESD 二极管长期导通，几个月后 IO 失效。

    ② 用万用表判断 UART 是否有数据：读到 1.6V 就以为「坏了」，其实是在正常翻转。

    ③ I2C 上拉接到 5V：3.3V 器件输入被拉到 5V，靠内部钳位硬扛，长期漏电发热。

    1.9.7四个设计误区

    1. 只看「3.3 < 5」，不看门限。TTL 能收、CMOS 不一定能收。
    2. 忽略 5V 容忍性。i.MX6ULL 的 IO 不是 5V 容忍。
    3. 上拉电压与器件电源不一致。I2C 上拉到 5V，3.3V 器件被过压。
    4. 用万用表测翻转信号。读到的是平均值，不是电平。

    练习（答案在折叠里）

    1. 3.3V CMOS 输出（VOH=2.9V）驱动 5V CMOS（VIH=3.5V），兼容吗？
    不兼容：2.9 < 3.5，接收端可能识别不出高电平；需电平转换或选 HCT（TTL 门限）器件。
    2. 3.3V 输出驱动 5V TTL（VIH=2.0V）呢？
    兼容，余量 0.9V。
    3. 5V 信号直接接 i.MX6ULL GPIO 会怎样？
    IO 非 5V 容忍，5V 会经 ESD 二极管灌入 3.3V 轨，可能抬高电源、损坏 IO。
    4. NVCC_SD 在 VSELECT=0/1 时分别是多少？为什么？
    约 3.27V / 1.81V；SD 初始化用 3.3V，高速模式切 1.8V。
    5. 4.7k 上拉、100pF 总线，tr 多少？能跑 400kHz 吗？
    2.2RC≈1.03µs；400kHz 规范上限 300ns，不行。
    6. 万用表测 UART TX 读到 1.6V，说明什么？
    多半是 50% 占空的方波平均值，信号在正常翻转；要用示波器/逻辑分析仪判断。
