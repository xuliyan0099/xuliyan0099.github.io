    电容：充放电、RC 时间常数，以及 22µF 与 0.1µF 为什么必须并存

    电容是板上数量最多的元件，也是最容易被当成「贴上去就行」的元件。它到底在干什么？只有两件事：存电荷（Q=CU）、抵抗电压变化（i=C·dv/dt）。把这两件事想清楚，你就能解释：为什么去耦要一大一小、为什么晶振要配 18pF、为什么 10µF 的 0402 实际只有 4µF。

    读完这一章，你应该能

    1. 写出 i=C·dv/dt 与 Z=1/(2πfC)，并算出指定频率下的阻抗
    2. 用 τ=RC 算充放电时间，判断复位、消抖、上电斜率是否够
    3. 解释「22µF + 0.1µF」并联的物理原因（ESL 与自谐振），而不是背口诀
    4. 说出 C0G/X5R/X7R/Y5V 的差别，以及偏压降容怎么吃掉你的容值
    5. 用本板位号验证：C21–C24（SoC 内核）、C65（DDR VREF）、C12/C13（24MHz 晶振）

    1.4.1两件事：存电荷，抵抗电压变化

    电容的定义式：Q = C·U。给它加电压，它就存电荷；容量 C 的单位是法拉（F），常用 µF（10-6）、nF（10-9）、pF（10-12）。

    对时间求导就得到最重要的动态方程：

    i = C · dv/dt

    这句话的含义是：电容两端的电压不能突变。想让它电压变化，必须灌入/抽出电流；变化越快（dv/dt 越大），需要的电流越大。反过来，电压恒定时（dv/dt=0）电流为零——这就是「隔直通交」的由来，不是电容「挡住了直流」，而是直流下它充满电后就不再吸收电流。

    同样重要的还有能量：E = ½CU²。22µF 充到 3.3V 存 120µJ；1000µF 充到 12V 存 72mJ——后者在断电瞬间能把一个 LED 点亮一小会儿，也能把一只手烫出泡（所以大电容要泄放电阻）。

    1.4.2阻抗：Z = 1/(2πfC)，频率越高越「通」

    正弦稳态下电容的阻抗：

    ZC = 1/(j·2πf·C)，模值 |Z| = 1/(2πfC)

    算几个真实数：

    • 0.1µF 在 1MHz：|Z| = 1/(2π×106×10-7) ≈ 1.6Ω；在 100MHz 降到 16mΩ（但此时 ESL 开始主导，见 1.4.4）。
    • 10µF 在 100Hz：|Z| ≈ 159Ω；在 100kHz 降到 0.16Ω。
    • 18pF 在 24MHz：|Z| ≈ 368Ω——晶振电路里它不是「滤波」，而是负载电容，与晶体一起决定振荡频率（1.4.6 讲）。

    所以「电容滤波」要看你滤什么频率：低频纹波（100Hz 工频）要大容量电解；高频开关噪声（几百 kHz–几十 MHz）要小容量 MLCC 且贴近引脚。

    1.4.3RC 时间常数：τ=RC，5τ 才「到位」

    电阻给电容充电，电压按指数上升：

    U(t) = U∞(1 − e−t/τ)，τ = R×C

    • 1τ：到 63%；2τ：86%；3τ：95%；5τ：99.3%——工程上认为「稳定」。
    • 放电同理：U(t) = U0·e−t/τ。

    算例：10k 上拉 + 100nF 电容 → τ = 10k×100nF = 1ms，5τ = 5ms。这种组合常见于按键消抖与复位延时。

    再看本板的两个 RC：

    • 复位：MAX809R（U2）的 RESET 输出经 R31 0Ω 直连 POR_B，去耦 C13 104。复位脉宽由芯片内部定时（典型 180ms 级），不是 RC 决定；但 POR_B 上的 104 会与上拉 R33 形成 τ=10k×0.1µF=1ms 的边沿，太大会拖慢释放——这就是「复位脚上不能乱加电容」的原因。
    • I2C 上拉：4.7k 上拉 + 总线电容 100pF → τ=470ns，上升时间 2.2τ≈1.03µs（第 1.2 章），刚好卡在 100kHz 规范边上。

    1.4.4为什么必须「22µF + 0.1µF」并存

    真实电容不是理想电容，它等效为 C 串 R(ESR) 再串 L(ESL)。于是阻抗曲线是个 V 形：低频段由 C 主导（随频率下降），高频段由 ESL 主导（随频率上升），谷底就是自谐振频率 SRF：

    SRF = 1/(2π√(L·C))

    以 0402 0.1µF（ESL≈0.5nH）为例：SRF ≈ 1/(2π√(0.5nH×0.1µF)) ≈ 22MHz。它只在 22MHz 附近阻抗最低；低于这个频率它还行，高于就变成「电感」。而 22µF 的 SRF 只有约 1.5MHz。

    所以两级分工：22µF 管低频（<1MHz）的大能量缓冲，0.1µF 管高频（10–100MHz）的快速电流。只留 22µF，高频段阻抗下不来；只留 0.1µF，低频段储能不够。两者并联，阻抗曲线在两个 SRF 之间互相填补——这就是「一大一小」的物理原因，不是玄学。

    1.4.5实际容值：偏压、温度、老化三把刀

    标称 10µF 的 X5R 0402，在 3.3V 直流偏压下可能只剩 4–5µF；在 5V 下更少。这叫直流偏压降容（DC bias derating），是高介电常数介质（X5R/X7R/Y5V）的固有特性，手册里有一条「Cap vs DC Bias」曲线，绝大多数人从来不翻。

    • 偏压：电场把介质里的偶极子「钉住」，有效介电常数下降 → 容值下降。X5R 在额定电压附近可能掉 50–70%。
    • 温度：X7R 在 −55~125°C 内变化 ≤±15%；X5R 是 ±15%（−55~85°C）；Y5V 能到 ±82%。C0G 几乎不变（±30ppm/°C）。
    • 老化：X5R/X7R 随时间缓慢损失容值（每十倍时间约 −1~−3%），C0G 不老化。

    选型结论：定时、滤波、谐振（晶振负载电容）必须 C0G；电源去耦可以用 X5R/X7R，但要把降容算进去——22µF 在 3.3V 下实际可能只有 12–15µF，这也是为什么板上要放好几颗并联，而不是一颗大容量的原因之一。

    1.4.6本板三个真实电容角色

    ① 去耦：C21–C24（内核 10 个球）

    3 颗 0.22µF + 1 颗 22µF，覆盖 VDD_SOC_CAP1–10。判据：每个电源球都要能在几十纳秒内拿到电荷，走线电感必须小，所以电容要贴着球放；容量按「瞬态电流 × 允许压降」估算：内核 1A 阶跃、允许 50mV、持续 100ns，需要 C ≥ I·t/ΔU = 1×100n/0.05 = 2µF——所以 22µF 是够的，0.22µF 负责更快的部分。

    ② VREF 滤波：C65 2µF + C66 0.1µF

    DDR 的 VREF 由 1.5k/1.5k 分压产生，源阻抗 750Ω（第 1.2 章）。若不接电容，任何耦合噪声都会直接叠在参考上；接了 2µF 后，在 1MHz 处阻抗从 750Ω 降到 0.08Ω（并联效果），噪声被旁路掉。

    ③ 晶振负载电容：C12/C13 18pF

    24MHz 晶振的负载电容 CL 必须与手册一致（这里 18pF）。晶体的振荡频率会随 CL 偏移：CL 偏大 → 频率偏低（典型每 pF 几十 ppm）。18pF 不是「滤波电容」，它和晶体、芯片内部反相器共同构成谐振回路，乱换会导致起振困难或频率偏差，进而让 USB/Ethernet 出错。

    「10µF 的 0402 比 0805 高级」是错的

    同容量同介质，封装越小，介质层越薄、层数越多，偏压降容越严重、机械应力越脆弱。0402 10µF 在 3.3V 下可能只剩 4µF，而 0805 10µF 能保住 7µF。电源去耦优先看「实际容值 + ESL + 位置」，不是看封装小。

    1.4.7怎么测：三种手段与一个陷阱

    1. LCR 表 / 电容档：测容值与 ESR。注意测试频率（1kHz vs 100kHz 结果不同），以及要在拆下来测才准。
    2. 在路测：万用表电容档在路读数会被并联支路拉偏，基本不可信；判断「电容是否短路」用电阻档/二极管档更实用。
    3. 看纹波：示波器 AC 耦合测电源纹波，是最能反映「去耦够不够」的实测手段；换不同容值组合对比，能直接看到效果。

    陷阱：MLCC 的失效模式大多是「开裂短路」，而不是容量慢慢衰减。板子摔过、分板应力大、焊接热冲击，都可能在陶瓷体上留下微裂纹，上电后击穿。表现为某路电源短路、发烫。所以「电容坏了」在维修现场通常等于「量到 0Ω」。

    1.4.8五个设计误区

    1. 按标称容值做设计，不算偏压降容，结果纹波超标。
    2. 只放一颗大电容，高频段阻抗下不来，EMI 变差。
    3. 电容放得离引脚太远，走线电感把 ESL 从 0.5nH 变成 2nH，SRF 掉到 5MHz。
    4. 把晶振负载电容换成「更大更好」，频率偏移、起振困难。
    5. 大容量电容不做泄放，断电后残留电压，维修时被电到或打坏器件。

    练习（答案在折叠里）

    1. 10k 与 100nF 组成 RC，τ 是多少？多久稳定？
    τ=1ms；5τ=5ms 认为稳定。
    2. 0.1µF 在 10MHz 的容抗？为什么实际可能更低？
    |Z|=1/(2π×10M×0.1µ)=0.16Ω。实测可能更低是因为接近自谐振（0402 约 22MHz），ESR 起作用。
    3. 为什么晶振的 18pF 不能换成 22pF？
    CL 变大频率偏低（几十 ppm），可能超出 USB/Ethernet 允许的时钟精度，或起振裕度变差。
    4. 22µF X5R 0402 在 3.3V 下实际可能多少？
    可能只剩 40–60%，即 9–13µF，具体查手册 DC bias 曲线。
    5. 给 1A 负载做 100ns 的瞬态支撑、允许 50mV 压降，至少需要多少电容？
    C ≥ I·t/ΔU = 1×100ns/0.05 = 2µF。实际还要加余量并考虑降容。
    6. 板上某个电容量出 0Ω，说明什么？
    多半是 MLCC 陶瓷体开裂击穿短路，需要拆下确认，直接上电会拉垮该路电源。
