有源器件：三极管与 MOS 管

第 03 章约 24 分钟★ 必读

为什么需要第三个脚

无源器件只会「按欧姆定律响应」。要让一个「小信号」控制「大电流」，需要一个受控的阀门——这就是有源器件（三极管、MOS 管）的本质。

它们的共同结构是三个脚：

器件控制端被控通道类型
BJT（双极型，NPN/PNP）基极 B（电流控制）集电极 C ↔ 发射极 E电流控制电流
MOSFET（N 沟道 / P 沟道）栅极 G（电压控制）漏极 D ↔ 源极 S电压控制电流

一句话区别：三极管是「用电流控制电流」，MOS 是「用电压控制电流」。

NPN：三个工作区

区域条件行为
截止Vbe < 0.7VC-E 不通，像断开的开关
放大Vbe ≈ 0.7V，Ic 未饱和Ic = β·Ib，β 通常 100–300
饱和Ib 足够大C-E 几乎短路，Vce ≈ 0.2V

开关用途只关心两个：截止与饱和。 放大区在这里不关心。

作为开关的接法（NPN 低边开关）：

负载（LED/继电器） → 集电极
发射极 → GND
基极 ← 电阻 ← GPIO

GPIO 输出高 → 基极有电流 → 三极管饱和 → 负载通。GPIO 输出低 → 截止。

基极电阻必须算：

Ib ≥ Ic / β　　再留 2–3 倍余量保证饱和。

例如驱动 20mA 负载、β=100：Ic/β = 0.2mA，取 1mA 更稳妥。GPIO 3.3V、Vbe 0.7V：

Rb = (3.3 − 0.7) / 0.001 = 2600 Ω　　取 2.2kΩ。

不串这颗电阻，GPIO 会直接被 Vbe 钳在 0.7V，电流可能大到烧 IO。

MOS 管：三个必须知道的点

① 栅极几乎不耗电，但有电容。

栅极是绝缘的氧化层，静态电流极小（nA 级）——这是 MOS 优于三极管的地方（不消耗持续驱动电流）。但栅极本身是个小电容（几百 pF），开关瞬间要充放电荷。因此高速开关时驱动能力仍然重要，而且栅极悬空时电位不定，可能半开半关、发热烧掉。

② 栅极电压要够（Vgs 阈值）。

N 沟道 MOS 的 Vgs(th) 常见 1–3V。用 3.3V GPIO 直接驱动「逻辑电平 MOS」可以；驱动普通 MOS（Vgs(th) 4V 以上）就不够，会停在放大区、发热。这就是「为什么有的板子要加一级三极管去推 MOS」。

③ 低边与高边。

  • 低边开关（N 沟道，源极接地）：常见、简单，但负载不再接地。
  • 高边开关（P 沟道，源极接电源）：负载保持接地，但需要「栅极比源极低」才导通，驱动逻辑反相。

板子上「控制一路 12V 电源」这类需求，常用高边 + P 沟道（或专用高边驱动芯片）。

和 GPIO 的关系：为什么常常不直接用 GPIO 驱动

i.MX6ULL 的 GPIO 驱动能力有限（看 Datasheet 的驱动电流档位，常见是 mA 级）。超过它的负载必须外加器件：

负载做法
一颗指示 LED（几 mA）GPIO 直接 + 限流电阻
多颗 LED / 大电流 LEDGPIO → 三极管/MOS 低边
继电器 / 电机三极管/MOS + 续流二极管
另一路电源域高边 MOS 或专用负载开关

继电器与电机必须加续流二极管：感性负载断电瞬间会产生反向高压尖峰，没有泄放路径就会击穿驱动管。

一个完整的例子：GPIO 控制 5V 蜂鸣器

需求：3.3V GPIO 控制 5V 有源蜂鸣器（约 30mA）。

方案：NPN 低边开关。

5V → 蜂鸣器 → 集电极
发射极 → GND
基极 → 2.2kΩ → GPIO

三点检查：

  1. Vce 饱和压降：约 0.2V，蜂鸣器实际得到 4.8V，够。
  2. 基极电流：3.3V/2.2k ≈ 1.2mA，足够饱和。
  3. 蜂鸣器是感性：并一颗反向二极管（阴极接 5V，阳极接集电极）做续流。

这三条检查就是「有源器件」这一章的全部实践价值。

本篇验收

  • 能说出三极管与 MOS 的控制方式差别（电流 vs 电压）。
  • 能画出 NPN 低边开关，并算出基极电阻。
  • 能解释「栅极不耗电」为什么仍然需要驱动能力。
  • 能区分低边与高边开关，并说出各自代价。
  • 能说出「感性负载必须加续流二极管」的原因。
