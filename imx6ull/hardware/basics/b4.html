数字电路的骨架：电平、门、组合、时序

第 04 章约 28 分钟★★ 核心含互动工具

电平不是一个点，是一个范围

数字电路看起来只有 0 和 1，物理上却是连续的电压。所以规范用「范围」定义：

术语含义
VOH输出高电平时，保证不低于这个电压
VOL输出低电平时，保证不高于这个电压
VIH输入认「高」的最低电压
VIL输入认「低」的最高电压

中间那块「VIH 与 VIL 之间」是禁止区：输入落在这里，输出不确定，还可能有振荡电流。

工程上必须满足：

VOH(驱动) > VIH(接收)　　VOL(驱动) < VIL(接收)

这就是「3.3V 器件能不能直接驱动 1.8V 器件」这类问题的唯一判断依据，不是看谁标称多少伏。

门电路：所有逻辑的原子

门表达式一句话
ANDy = a·b全 1 才 1
ORy = a+b有 1 就 1
NOTy = ā反过来
NANDy = ¬(a·b)AND 取反（最常用，因为 CMOS 里做起来最省）
NORy = ¬(a+b)OR 取反
XORy = a⊕b不同为 1

CMOS 工艺里 NAND 与 NOR 是最基础的单元，AND/OR 反而要「NAND + NOT」拼出来。这也是为什么芯片内部的逻辑综合偏爱 NAND。

真值表小工具 · 六种门

组合逻辑：门一排排接起来

把门连起来，输出只取决于当前输入，这叫组合逻辑。三个必须能自己画出来的例子：

半加器（两个 1 位相加）：

和   = a ⊕ b
进位 = a · b

全加器 = 两个半加器 + 一个 OR（多一个进位输入）。八位加法器 = 八个全加器串起来（进位逐级传，所以叫「行波进位」，速度受限于进位链）。

译码器（n 位输入 → 2ⁿ 根输出，只有一根为 1）。地址译码、片选都用它——「片选」本质上就是一个译码器的输出。

多路选择器（MUX）：n 位选择信号决定「哪一路输入接到输出」。CPU 内部的寄存器堆读写、总线的数据选择，全是 MUX。这也是为什么「多路复用」这个词会出现在引脚复用上——原理一模一样，只是物理上换成「一个脚接多个内部功能」。

时序逻辑：加上「记住」

组合逻辑有个根本限制：它不记得过去。加上一个「时钟控制的状态保持元件」，就有了时序逻辑。

D 触发器是最基本的存储单元：在时钟沿采样 D，输出 Q 保持到下一个沿。它的两条规矩，就是整门课的难点：

  1. 建立时间（setup）：数据必须在时钟沿之前稳定这么久。
  2. 保持时间（hold）：时钟沿之后还要保持这么久。

违反了会怎样？输出可能进入亚稳态——既不是 0 也不是 1，持续一段不确定时间后随机落定。这是硬件层的「偶发 bug」，软件层根本看不到原因。

寄存器 = 一组 D 触发器 + 一个公共时钟。 CPU 里的 r0–r15 就是这样一个寄存器组。

从门到时序：一条完整的链

门 → 组合逻辑（加法器/译码器/MUX）
  → 加时钟（D 触发器）→ 寄存器
  → 寄存器 + 组合逻辑 + 控制 → 状态机
  → 状态机 + 数据通路 → CPU

这条链是「数字电路」的全部内容。 你在软件里看到的「每个时钟周期执行一条指令」，就是这条链在跑。

三个必须记住的结论

  • 电平是范围，不是点。 接口能不能直连，看 VOH/VOL 与 VIH/VIL。
  • 组合逻辑无记忆，时序逻辑靠时钟。 「为什么需要时钟」不是玄学，是为了给「记住」一个统一的时刻。
  • 所有复杂数字系统 = 门 + 触发器 + 连线。 CPU 也不例外，只是数量级不同。

本篇验收

  • 能说出 VOH/VOL/VIH/VIL 四个词的含义，并写出互连的判定不等式。
  • 能默画半加器与全加器的逻辑（用 XOR 与 AND 表示）。
  • 能解释「片选就是一个译码器输出」。
  • 能说出 setup/hold 违反的后果（亚稳态），以及为什么它在软件层表现为偶发。
  • 能把「门 → 组合 → 触发器 → 状态机 → CPU」这条链讲一遍。
