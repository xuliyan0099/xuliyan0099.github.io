硬件基础课 · 从一颗电阻开始 · 第 01 章

电的四个字：电压、电流、电阻、功率

第 01 章约 24 分钟★ 必读含互动工具

四个字，四句话

量符号一句话单位
电压U两点之间的「电势差」，推动电荷的力量V
电流I单位时间流过多少电荷A
电阻R对电流的阻碍Ω
功率P单位时间消耗的能量（多半变成热）W

四者的关系只有一个公式（欧姆定律）：

U = I × R

以及功率的三种写法：

P = U × I = I2R = U2 / R

这五个等式是所有硬件计算的全部基础。 后面每一章都会回到它们。

电压是「相对的」

电压永远说「两点之间」。你量到的 3.3V，是「这一点相对 GND 是 3.3V」。所以：

  • GND 不是「零电位」，是「大家约定的参考点」。
  • 一块板子上所有 GND 必须连通（否则两边的「3.3V」互相没有意义）。
  • 「这个脚是 3.3V 电平」意思是「它相对 GND 是 3.3V」，不是绝对电位。

这就是为什么接错地线会「什么都读不对」——参考点错了。

串联与并联：两个必记结论

串联（电流只有一条路）：

R总 = R1 + R2 + ⋯　　电流处处相等，电压按电阻比例分。

并联（电压相同，电流分流）：

1 / R总 = 1 / R1 + 1 / R2 + ⋯　　两个电阻时 R总 = R1R2 / (R1 + R2)

一个常用直觉：并联永远小于其中最小的那个。两个 10k 并联 = 5k。

为什么 LED 必须串电阻

LED 的正向特性不是电阻性的：它的伏安曲线很陡——电压略微超过正向压降（Vf），电流就急剧上升。

假设一颗红色 LED 的 Vf ≈ 2.0V（具体看器件手册），接在 3.3V 上：

  • 不串电阻：LED 自己会把「多余的 1.3V」压在极小的内阻上，电流可能到几百 mA，瞬间烧掉。
  • 串一个 330Ω：电流 = (3.3 − 2.0)/330 ≈ 3.9 mA，安全且亮度够。

这就是「限流电阻」的全部含义：不是限制 LED，是限制电流。

实算：三种常见接法

接法 A：3.3V → 电阻 → LED → GND（高电平点亮）

R = (3.3 − 2.0) / 0.005 = 260 Ω　　取 E24 就近 270Ω，实际电流 4.8mA。

接法 B：LED 阳极接 3.3V，阴极 → 电阻 → GPIO（低电平点亮）

同样的电流，但逻辑反了：GPIO 输出 0 才亮。软件里要写成「active low」，否则你会以为「灯常亮是坏了」。

接法 C：多颗 LED 并联共用一颗电阻

看起来省事，实际是错的：每颗 LED 的 Vf 有离散性，Vf 最低的那颗会先导通、抢走大部分电流，亮度不均甚至烧掉。每颗 LED 一颗电阻。

用工具算一遍

LED 限流计算器 · 改电压与电流，看电阻与功耗

三个输入分别是：电源电压（V）、LED 正向压降（V）、目标电流（mA）。输出会给你理想电阻、E24 就近值、电阻功耗，以及「亮度/安全」判定。

试三组，把结论记住：

  • 3.3V / 2.0V / 5mA → 约 260Ω，正常指示。
  • 3.3V / 2.0V / 20mA → 约 65Ω，功耗还是很小，但已接近常规指示 LED 的上限。
  • 5V / 3.2V（蓝光）/ 10mA → 约 180Ω，注意蓝光 Vf 明显更高。

功率的直觉：什么时候要担心「热」

电阻是有功率上限的（常见 1/16W、1/8W、1/4W、1/2W、1W）。判断很简单：

P = I2R
  • LED 限流电阻：几 mA × 几百 Ω → 毫瓦级，1/4W 绰绰有余。
  • 但如果是「用电阻分压给某模块供电」，电流一大，电阻就发热，效率还极低——这时候该用稳压器，不是电阻。

一条经验：功率余量取 2 倍以上。算出来 0.2W 就用 1/2W，不要用 1/4W 贴着极限。

  • 能解释「电压是两点之间」的含义，以及为什么地线必须共。
  • 能算 3.3V 接一颗 2.0V LED、想要 5mA 时的电阻，并选出 E24 值。
  • 能说出「多颗 LED 共用一个电阻」错在哪。
  • 能判断「电阻分压供电」为什么不可靠。
