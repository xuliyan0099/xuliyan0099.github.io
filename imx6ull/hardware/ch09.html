读原理图：从符号到一根信号

原理图不是画给人欣赏的图，是一张连接关系的说明书。它唯一要回答的问题是：这个球（引脚）上，接了谁。学会读它，你就能把「板子上有个电阻」变成「这个 22Ω 电阻在 UART 的 TX 上，作用是抑制过冲」——这是从玩家变成设计者的分界线。

读完这一章，你应该能

  1. 说出位号、网络标号、电源符号、分页连接各自的作用，以及它们为什么能「不用画线也连上」
  2. 用五步法在十分钟内读懂一页陌生原理图
  3. 把一根信号从 SoC 的球追到连接器，途中每个器件都说出它为什么在那
  4. 识别四种典型误读：同名不同页、0Ω 跳线、NC 位号、多电源域

2.1.1四个基本记号

记号长什么样作用新手最容易错的点
位号R37 C105 U2 J4元件的唯一身份证，和 BOM 一一对应把位号当作「第几个」，其实顺序不连续
网络标号UART1_TXD DDR_DQ0隐形导线：同名即相连，跨页也连以为必须看到线；其实看名字
电源符号GND VDD_3V3 VDD_SOC全局网络，同名同电位以为所有 GND 都一样（其实有模拟地/数字地之分）
分页连接页框端口 / off-page connector把一页的信号接到另一页只看本页，漏掉另一页的负载

核心一句：原理图里「连没连」由名字决定，不由线决定。线只是让人好读的排版。

2.1.2五步读图法

  1. 先找电源页。所有原理图的第一页通常是电源树：输入从哪来、经过哪几级、产生哪几个轨。这一步决定后面所有器件「靠什么活着」。
  2. 再找主控。找到 U1（SoC），看它周围的去耦、晶振、复位、启动脚——这四组就是最小系统。
  3. 按功能块分页。存储（eMMC/DDR/TF）、通信（UART/USB/网口/CAN）、人机（LED/按键/屏）、扩展（排针）。每页只解决一类事。
  4. 挑一根信号从头追到尾。例如 UART1_TXD：SoC 球号 → 串阻 → 排针脚号。中途遇到上拉、TVS、电平转换、跳线，都要说出它为什么在。
  5. 写下你关心的三件事。比如「这板子能不能接 5V 传感器」「这个口是不是 3.3V 电平」「这颗电阻能不能拆」。带着问题读，比通读快十倍。
从「球号」开始，而不是从「名字」开始

原理图上 SoC 的引脚通常标成 UART1_TXD / GPIO1_IO04 / SD1_CMD 这种斜杠列表——这不是三个引脚，是一个球的多重身份（第 1.6 章讲过 MUX）。读图时要问的是：出厂配置下它被复用成什么？这由设备树决定，不由原理图决定。原理图只告诉你「这个球接到了排针第 3 脚」。

2.1.3追一根信号：完整路径

以最常见的调试串口 UART1_TXD 为例，一条典型路径上有六个环节，每一个都有明确理由：

环节典型值为什么在这里拆了会怎样
SoC 球—信号源，推挽输出—
串阻22–33Ω抑制过冲与振铃，改善 EMI长线时波形台阶变差，偶发误码
测试点TP5插针/焊盘，方便示波器抓波形排查只能飞到球上，风险高
ESD 阵列TVS排针被静电打到时钳位静电可能直接打死 SoC 的 IO
上拉10k（可选）空闲电平确定，防悬空误触发悬空时接收端可能读到随机跳变
连接器排针 J4-3对外接口—

这六个环节不是每块板都有，但每一个都有存在的理由。读图的功力，就是看到器件能立刻说出这个理由；画板的功力，是能判断「我这块板需不需要它」。

2.1.4四种典型误读

①同名不同页 → 以为没关系

SD1_CMD 在 SoC 页出现，在 TF 卡座页也出现——两处是同一根线。如果在 SoC 页加了个上拉，卡座页也必须有对应的上拉位置，否则总线上只有一个上拉，边沿会变慢。

②0Ω 电阻 → 以为是装饰

0Ω 不是电阻，是可拆的跳线。常见三种用途：隔离两个电源域（调试时断开量电流）、选择启动配置（焊哪个决定 BOOT 电平）、把同一网络分成两段方便布板。看到 0Ω 先问：它连的是哪两个名字？

③NC / DNP 位号 → 以为坏了

NC（no connect）、DNP（do not populate）表示这个位置留了焊盘但默认不装。它不是缺失元件，是设计预留。很多「我这板子少个电容」的疑问都出在这。

④多电源域 → 以为都是 3.3V

VDD_3V3、VDD_SNVS_3V0、VDD_HIGH_2V5、VDD_SOC_1V35 是不同轨，电压不同、上电时序不同。看到器件的电源脚，先确认它挂在哪一轨上，再看这轨什么时候建立。

读图时不要做的两件事

不要按位置判断连接。两条线在图上交叉但没圆点，就是不连；有圆点才连。

不要相信「看起来对称」。TX 串阻 22Ω、RX 串阻 22Ω 看似对称，但 RXD 可能还挂了个 10k 上拉——漏掉它，你会误判空闲电平。

2.1.5从读图到画图，只差这三问

读懂一张图和画出第一张图之间，其实只差三问：

  • 这个信号需要什么电气条件？电平（3.3V 还是 5V）、方向（单向还是双向）、速率（多少 MHz）、终端（要不要匹配）。
  • 这个器件为什么在这里？上拉、串阻、TVS、滤波，各自解决一个具体问题。说不出理由的，就是抄来的。
  • 如果我拿掉它，最坏会发生什么？能回答这个问题，说明你真的理解了这一环。

这三问会贯穿后面五章：电源（第 2.2）、时钟复位（2.3）、接口（2.4）、PCB（2.5）、打样（2.6）。

自测

原理图上两个 UART1_TXD 之间没有画线，它们连不连？
连。网络标号同名即相连，这是原理图的语法，不是排版习惯。EDA 生成网表时就是按名字归并的，所以 PCB 上它们本来就是同一段铜。
看到某个电阻位号标着 NC，说明什么？
说明焊盘存在、默认不装（DNP）。它通常是设计预留：可能用于调试、可选上拉、或者将来改版用。不要把它当成「漏焊」或「板子坏了」。
为什么读图要从电源页开始，而不是从 SoC 开始？
因为电源决定了所有器件「活着的前提」，也决定了上电顺序。先看电源树，你就知道哪几路先建立、哪些器件依赖哪一路；直接从 SoC 看，会看不懂为什么有些信号要等电源好才有效。
