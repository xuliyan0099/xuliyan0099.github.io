板子地图：认元件

认板子不是背布局。同一颗芯片在不同板厂可能换位置、换型号、换封装，但认法永远一样：看丝印 → 翻原理图对应的那一页 → 找它的电源脚和信号脚 → 用表量。这一章把这套动作拆开练，配一张可点的地图。

读完这一章，你应该能

  1. 凭丝印在 30 秒内说出这颗芯片是干什么的（SoC / DDR / eMMC / PHY / PMIC）
  2. 拿到原理图，找到某个网络名对应到板子上的哪个脚、哪一页
  3. 知道每颗主要芯片「该有多少伏、该有几路电」，并会用万用表验证
  4. 区分「板级元件」和「排针外设」，知道问题该往哪一层查

1.2.1先看地图：一张典型 i.MX6ULL 板子的分区

下面按正点原子 / 野火这一类的 MINI、ALPHA 板画的布局示意，不是某一家精确丝印。但分区逻辑是通用的：中间是 SoC 与存储（信号最短、走线最贵），左上电源，右侧接口，下侧排针。

1.2.3看丝印：一条从型号到用途的推理链

丝印就是你手上的「最短文档」。以一颗常见的 DDR 颗粒 MT41K256M16TW-107 为例：

  1. 认出厂商与系列。MT = Micron，41K = DDR3L 系列。系列决定它的工作电压是 1.35V，不是 1.5V——这颗板子若按 1.5V 供，会过热。
  2. 读容量编码。256M16 = 256M 个存储单元 × 16 位宽。换成字节：256M × 16bit ÷ 8 = 512MB。板子标「512MB」就是这么来的。
  3. 读速度等级。-107 对应约 1866MT/s 的能力，实际跑多少由 u-boot 的 DDR 配置决定，不必跑满。
  4. 反查原理图。用网络名（如 DRAM_A0、DRAM_DQ0）在原理图里搜，就能看到它连到 SoC 的哪组引脚，以及供电来自哪一页。

同样的方法可以读 eMMC（…08G… = 8GB）、PHY（KSZ8081 = 10/100M RMII）、串口芯片（CH340）。不会读没关系，关键是知道「丝印里一定有这些字段」，查一次就会了。

原理图怎么找

板厂一般提供 PDF 原理图，几十页，按功能分页：电源页、SoC 页、DDR 页、eMMC 页、接口页、排针页。最快的用法是「先在 SoC 页找到这个信号名，再用网络名反查它接到了谁」——网络名是全图通用的钥匙，比记住页码可靠。

1.2.4每颗芯片的「电源脚」和「信号脚」

判断一颗芯片是否「活着」，永远先看电源脚，再看信号脚。这张表是通用套路，换芯片只是数字不同：

芯片该有的电压信号脚先看哪个典型异常
SoC3.3V（IO）、1.35V（DDR IO）、~1.2V（内核）24MHz 晶振脚、复位脚、UART1 TX某一路缺 → 完全不启动
DDR1.35V（VDD）、0.675V（VREF，通常由分压产生）时钟 CK/CK#、片选 CS#VREF 偏 → 时序余量不足，随机死机
eMMC3.3V（VCC）、1.8V 或 3.3V（VCCQ）CLK、CMD、DAT0VCCQ 不对 → 识别不到或读错
PHY3.3V（模拟）、1.2V 或 2.5V（内核/IO 视型号）REF_CLK（50MHz 或 25MHz）、RXDV时钟没到 → 网口灯不亮
USB 转串口5V（VBUS）或 3.3VTX/RX 与 GND只供电无数据 → 线是充电线

记住一条经验：任何一颗芯片，如果它的供电脚电压对、参考时钟在、复位已释放，却完全没反应，才轮到怀疑它本身或焊接。顺序反了，会把「没供电」误判成「芯片烧了」。

三个真实翻车点

1. 拿 1.5V 的 DDR3 参数去配 1.35V 的 DDR3L。能跑起来，但高温下随机死机；丝印上的 L 就是提示。

2. 用「能充电」的 USB 线接串口。没数据线芯，PC 端一切正常，板子就是没输出。换一根，问题消失。

3. 拨码在 TF 模式，eMMC 里有系统。上电先找 TF 卡，卡不对就停住。新手最容易在这里怀疑「烧录失败」。

1.2.5动手：给板子做一张自己的地图

花二十分钟，画一张只属于你这块板子的地图，比看别人的图有用得多：

  1. 拍照打印，或用白纸描出板子轮廓，标出安装孔与接口位置。
  2. 把 1.2.2 表里的八类元件圈出来，写上丝印关键字（只要前 6 位）。
  3. 在图上标三样东西：5V 输入、串口、拨码。这是排障时最先摸的三个点。
  4. 对着原理图，把 SoC 页的网络名抄到对应元件旁（只抄 3–4 个关键信号即可）。
  5. 把这张图贴在工位，下次接线出错先看它，而不是翻 PDF。

自测

一颗 DDR 颗粒丝印是 MT41K256M16TW-107，容量是多少、供电多少伏？
512MB，1.35V。256M × 16bit = 4Gbit = 512MB；41K 表示 DDR3L 系列，工作电压 1.35V。-107 是速度等级，约 1866MT/s 能力，实际频率由 u-boot 配置决定。
为什么「先量电源脚，再看信号脚」？
因为没有正确的供电，信号脚上的一切测量都没有意义：芯片不工作，TX 不会输出波形，CS 不会拉低。反过来，如果电源对、时钟在、复位释放，信号仍不对，才说明问题在配置或芯片。这条顺序能把「硬件死」和「软件没配」分开。
原理图几十页，怎么最快定位一个信号？
用网络名，不要用页码。先在 SoC 页找到引脚名（如 UART1_TXD → UART1_TX_DATA），记住网络名，再全图搜这个网络名，就能看到它连到了 USB 转串口芯片的哪个脚。板厂改版时页码会变，网络名基本不变。
