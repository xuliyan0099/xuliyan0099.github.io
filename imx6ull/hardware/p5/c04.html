    布线：阻抗连续、回流、过孔、串扰的七条规则

    布线不是「把网表连通」，而是让每条线的电磁环境保持一致。这一章给七条可判定的规则，每条都配得上一个数字：3W 的 −20dB、1.8A 的过孔、6.7ps/mm 的时序。

    读完这一章，你应该能

    1. 说清「阻抗不连续」的三种来源，并知道怎么避免
    2. 算过孔载流与过孔电感，决定大电流要打几个孔
    3. 用 3W 规则把串扰压到 −20dB 以下，并算出间距
    4. 把「等长」换算成时间偏差，判断 DDR/USB 的容差
    5. 处理层间切换与参考平面切换时的回流问题

    5.4.1规则一：阻抗连续

    阻抗突变会引起反射，反射系数：

    Γ = (Z2−Z1)/(Z2+Z1)

    50Ω 线上遇到 30Ω（线宽突然变宽）：Γ=(30−50)/80=−0.25，即 25% 反射。三种常见突变：

    1. 线宽变化：从 BGA 焊盘出的细线（0.15mm）到常规线（0.35mm），中间没有渐变；
    2. 参考平面缺失：走线下方地平面被挖空（比如为了避让过孔）；
    3. 连接器/排针：排针的寄生电容电感与 50Ω 不匹配。

    对策：线宽变化处用「阶梯过渡」（每段 ≤1/10 波长）；平面挖空处补「桥」；高速信号避免走排针（本板的 2×24 排针只走低速 IO）。

    5.4.2规则二：过孔——载流、电感、残桩

    载流：0.3mm 孔径、25µm 镀铜，环形截面积 ≈ π×0.3×0.025 = 0.0236mm²（约 37mil²）。按 IPC-2221、ΔT=10°C：

    I = 0.048×100.44×370.725 ≈ 1.8 A/孔

    所以 3A 的电源要打 2–3 个孔（并留余量）。本板 DCDC 输出 1.5A 峰值，用 2–3 个过孔并联是合理的。

    电感：一个通孔约 0.5–0.8nH。高速信号每换一层就多 0.6nH，若换 3 次层，累积 2nH，在 500MHz 时阻抗 6Ω，足以造成可见反射。

    残桩：通孔在离开信号层后仍有未用的铜筒（stub）。stub 长度 L 会在 f=vc/(4L) 处产生谐振（vc 为介质中光速，FR4 约 170mm/ns）。1.6mm 板厚的通孔，若信号走 L1→L2，stub 约 1.4mm，谐振在 30GHz，影响不大；但 3mm 厚背板就要用盲埋孔。

    5.4.3规则三：3W 与串扰

    相邻线的容性/感性耦合随间距迅速衰减，近似：

    Vxtalk ∝ 1/(1+(s/h)2)

    s 是线间距，h 是到参考平面距离。当 s=3h（即 3W 规则，h≈w）：

    1/(1+9) = 0.1 ⇒ 约 −20dB（10% 耦合）

    要更低就取 5W（−28dB）或加地线隔离（guard trace，需密集地过孔）。本板 DDR 数据线间距按 3W 以上布，DQS 与时钟旁边留空。

    注意：3W 是「线边到线边」还是「线中心到线中心」常有争议——按边到边 ≥2 倍线宽（即中心距 3W）执行最稳妥。

    5.4.4规则四：等长与时间偏差

    FR4 中信号传播速度约 170mm/ns，即 6.7 ps/mm（表层微带稍快，约 160mm/ns）。

    接口允许偏差换算长度来源
    DDR3L 数据组内±0.2ns±30mm（很宽松）400MHz 周期 2.5ns 的 1/10
    DDR 时钟差分对±20ps±3mm差分对内偏斜
    USB 2.0 D+/D−±50ps±7mm差分对内
    RMII TX/RX 组±1ns±150mm50MHz 参考

    「等长」不是绝对值相等，而是组内相对偏差在容差内。所以布线时先布最长的那根（通常是时钟或最外侧数据），其余按它绕线。

    5.4.5规则五：层间切换要「伴随地过孔」

    信号从 L1 换到 L4，参考平面从 L2 变成 L3。若 L2 与 L3 不是同一网络（一个是地、一个是电源），回流必须跨过这两个平面之间的电容——而平面间电容只有 nF 级，高频回流几乎断掉。

    对策：在信号过孔旁 0.5mm 内放一个「地过孔」，连接 L2 与 L3 的地（若 L3 是电源，则放缝合电容）。这叫「回流过孔」。

    5.4.6规则六：电源与地

    • 电源走线用铺铜而不是细线，宽度按 4.1 的 IPC 公式；
    • 每个电源引脚旁的去耦电容过孔成对（电源孔 + 地孔）；
    • 地平面不要开长槽；必须开槽时，槽的走向垂直于信号流向。

    5.4.7规则七：可制造性布线

    • 线到板边 ≥0.3mm，孔到板边 ≥0.5mm；
    • 最小线宽/间距按板厂能力（嘉立创常规 5/5mil，进阶 3.5/3.5mil）；
    • 过孔不要打在焊盘上（除非树脂塞孔+电镀，成本高）；
    • 测试点：每个电源域留一个，直径 ≥1mm，间距 ≥2.54mm 便于探针。

    练习

    1. 50Ω 线遇到 30Ω，反射系数多少？
    (30−50)/80=−0.25，即 25%。
    2. 0.3mm 孔、25µm 铜，单孔能过多大电流（10°C）？
    约 1.8A。
    3. 3W 规则对应多少串扰？
    s/h=3 时 1/(1+9)=0.1，约 −20dB。
    4. 10mm 长度差对应多少 ps？
    10×6.7=67ps。
    5. 为什么换层要加地过孔？
    参考平面变了，回流需要就近通路，否则高频回流断开。
    6. 电源为什么用铺铜而不是细线？
    载流与散热，细线在大电流下温升过高。
