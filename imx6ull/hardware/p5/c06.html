    电源平面与散热：平板电容、铜箔热阻、过孔阵列

    电源平面有两个身份：供电网络和高频电容；同时它还是散热器。这一章把三个身份都算成数字：0.4nF 的平板电容、74K/W 的铜箔、176K/W 的单孔。

    读完这一章，你应该能

    1. 算两层铜构成的平板电容，解释它为什么能管 100MHz 以上
    2. 决定哪些平面要分割、哪些绝对不能分割
    3. 用 R=L/(kA) 算铜箔与过孔的热阻
    4. 为 SoC、LDO、DCDC 分别设计散热路径
    5. 用热像仪验证散热设计是否达标

    5.6.1平板电容：免费的高频电容

    两层平行铜就是电容：

    C = ε0·εr·A/d

    取 10cm² 面积（0.001m²）、介质厚 0.1mm、εr=4.3：

    C = 8.854e-12×4.3×0.001/1e-4 ≈ 0.38 nF

    0.38nF 在 100MHz 时阻抗 = 1/(2π×100M×0.38n) = 4.2Ω——不算低，但关键在于它的 ESL 极低（<0.1nH），而 0402 电容在 100MHz 已经呈感性（0.5nH→31Ω）。所以高频段平面比电容更有效。

    推论：L2 地与 L3 电源要尽量贴近（介质越薄，C 越大），且不要在两平面之间走信号（会挖洞减少面积）。

    5.6.2分割原则：地不分割，电源按域分割

    • 地平面整片不分割：所有回流共用，分割会切断回流。唯一例外是「模拟地/数字地」，且要单点连接（本板 ADC 参考与主地之间用 0Ω 或磁珠）。
    • 电源平面按电压域分割：3.3V、1.35V、5V 各自一块，缝宽 ≥0.3mm。
    • 分割缝不要走线：缝下方的信号没有参考平面，阻抗失控。
    • 跨域信号要缝合：如 3.3V 域的 IO 与 1.35V 域的 DDR 之间有信号，需在跨点放缝合电容。

    本板 CORE 的 L3 上有 DRAM_1V35、DCDC_3V3、NVCC_SD 等多块分割——这是必要的，因为电压不同；但 DDR 信号走 L1/L4，参考 L2 地，避开了分割缝。

    5.6.3铜箔热阻：横向散热

    热量在铜箔里横向扩散，热阻：

    Rθ = L/(k·w·t)

    铜的 k=385 W/(m·K)。取 1oz（t=35µm）、10mm 长、10mm 宽：

    R = 0.01/(385×0.01×3.5e-5) = 0.01/1.35e-4 ≈ 74 K/W

    也就是说，1W 热量经 1cm 铜箔散出，温升 74°C——铜箔不是「超导体」，短距离还行，长距离散热迅速失效。

    这就是为什么散热要「就近大面积铺铜 + 打过孔到内层」，而不是「拉一条长铜线到板边」。

    5.6.4过孔热阻：垂直通路

    单个 0.3mm 孔、25µm 镀铜、板厚 1.6mm：

    A = π×0.3×0.025 = 0.0236 mm²
    R = 0.0016/(385×2.36e-8) ≈ 176 K/W

    10 个并联 → 17.6K/W；20 个 → 8.8K/W。所以 SoC 底部散热焊盘通常打 16–25 个过孔，不是为了载流，是为了导热。

    注意：过孔要「填铜/树脂塞孔」才有好的导热，普通过孔内部是空腔 + 薄镀层，热阻比理论值高。

    5.6.5三类器件的散热路径

    器件主要热路径本板做法
    SoC（BGA）芯片 → 焊球 → PCB 内层地 → 空气底部散热焊盘 + 多过孔到 L2 地；BGA 下方铺铜
    DCDC（SOT-23-6）结 → 引脚 → 焊盘 → 铜箔GND 脚铜箔 ≥25mm²；SW 脚不要大面积铜（噪声）
    LDO（SOT-23）结 → GND 脚 → 铜箔GND 脚周围 25–100mm² 铜（4.3 节算过）

    一个常被忽略的点：散热铜箔要连到内层地，而不是孤立在顶层。孤立铜箔只能靠空气对流，热阻高一个量级。

    5.6.6实测：热像仪怎么用

    1. 设置发射率：PCB 绿油约 0.9，金属焊盘约 0.1（不设对会读低 30°C 以上）；
    2. 满载运行 15 分钟到热平衡；
    3. 读 SoC、DCDC、LDO、PHY 四处温度；
    4. 判据：SoC 壳温 <85°C、DCDC <100°C、LDO <90°C（环境 40°C）。

    若 LDO 超过 90°C，先按 4.3 节算结温，再决定「加铜箔 / 降电流 / 换封装」三选一。

    练习

    1. 10cm²、0.1mm、εr=4.3 的平板电容多少？
    约 0.38nF。
    2. 为什么地平面不能分割？
    回流共用，分割会切断回流路径，阻抗与辐射恶化。
    3. 1oz 铜、10×10mm 的横向热阻？
    约 74K/W。
    4. 单个 0.3mm 过孔的热阻？16 个并联？
    约 176K/W；16 个并联约 11K/W。
    5. SoC 底部为什么打 16–25 个过孔？
    导热到内层地，单靠顶层铜箔无法散出。
    6. 热像仪为什么必须先设发射率？
    发射率错会把金属或绿油温度读低 30°C 以上。
