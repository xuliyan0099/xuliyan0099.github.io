    DRC 与 DFM：丝印、拼板、工艺边、测试点

    DRC 通过不等于能生产。板厂退单的 90% 原因都在 DFM：丝印压焊盘、工艺边不够、Mark 点缺失、阻焊桥太窄。这一章给一份 12 项出厂前检查清单。

    读完这一章，你应该能

    1. 分清 DRC（设计规则）与 DFM（可制造性）的区别
    2. 按尺寸规则设计丝印、Mark 点、测试点
    3. 选对拼板方式（V-cut / 邮票孔）并留够工艺边
    4. 跑完 12 项 DFM 检查，避免被板厂退单

    5.7.1DRC 与 DFM 不是一回事

    类别检查什么谁定义漏了会怎样
    DRC线宽、间距、孔径、环宽、短路你的软件规则无法生产或电气失效
    DFM丝印、阻焊桥、拼板、工艺边、Mark板厂工艺能力能画出来但做不出来/良率低

    典型误判：DRC 全绿，但丝印字号 0.5mm、压住焊盘——板厂照做，回来字符糊成一团，极性看不清，贴片贴反。

    5.7.2丝印四条硬规则

    • 字高 ≥0.8mm、线宽 ≥0.15mm：再小印不出来（丝网印刷极限约 0.15mm 线宽）；
    • 丝印不得压焊盘/过孔：绿油上的丝印在焊盘上会被焊膏冲掉，且造成焊接不良；
    • 极性标记必须可见：二极管阴极、钽电容正极、IC 的 1 脚、连接器 1 脚；
    • 位号不要被元件盖住：贴片后仍要能看到 R12、C34，便于维修。

    本板的做法：二极管用「阴极端一条粗线」，IC 用「1 脚圆点 + 缺口」，Type-C 用「开口方向 + 1 脚标记」。这些小标记在调试时能省几小时。

    5.7.3Mark 点与测试点

    Mark 点（光学定位）：贴片机用它校正。要求：

    • 直径 1.0–1.5mm 的实心圆，周围 2mm 内无铜、无丝印（留出对比度）；
    • 至少 3 个，呈不对称分布（防呆，避免旋转 180° 也能对上）；
    • 拼板上每个小板至少 1 个，整板 3 个。

    测试点：

    • 直径 ≥1.0mm，间距 ≥2.54mm（探针床间距）；
    • 每个电源域、复位、关键时钟各留一个；
    • 测试点不要盖绿油（要开窗），且不要放在元件正下方。

    5.7.4拼板：V-cut 还是邮票孔

    方式适用优点缺点
    V-cut（V 形槽）矩形板、边缘直线成本低、掰板整齐不能做异形、槽深占板厚 1/3
    邮票孔（Mouse bites）异形板、圆角、拼板间隙小适应性好掰后有毛刺，需打磨
    双面 V-cut较厚板应力小成本略高

    工艺边：拼板四周留 ≥5mm（贴片机轨道夹持需要），并在工艺边上放 Mark 点与定位孔（孔径 3–4mm）。拼板间隙：V-cut 为 0（共边），邮票孔为 2–3mm。

    算一下利用率：一块 100×80mm 的板，在 300×200mm 拼板内做 2×2，加 5mm 工艺边：

    拼板尺寸 = (100×2+10) × (80×2+10) = 210×170mm
    利用率 = 4×100×80/(210×170) = 32000/35700 ≈ 89.6%

    若改成 1×2（210×90），利用率 = 16000/18900 ≈ 84.7%——拼得多不一定更省，要看边料占比。

    5.7.5DFM 十二项检查清单

    1. 最小线宽/间距 ≥ 板厂能力（常规 5/5mil，本板 BGA 出线用 4/4mil 需选进阶工艺）
    2. 最小孔径 ≥0.2mm，孔环 ≥0.15mm（否则破环）
    3. 阻焊桥 ≥0.1mm（IC 引脚间），否则连锡
    4. 丝印字高 ≥0.8mm、不压焊盘
    5. 板边 ≥0.3mm 无铜，≥0.5mm 无孔
    6. 工艺边 ≥5mm，Mark 点 3 个
    7. 拼板 V-cut 深度 = 板厚 1/3，邮票孔孔径 0.5–0.8mm
    8. 槽孔/异形孔用「槽孔」层标注，不要用焊盘叠
    9. 金手指/Type-C 做倒角，避免插拔刮伤
    10. 大面积铜箔做「网格」或「十字连接」，防翘曲
    11. BGA 区域阻焊开窗按焊盘 +0.05mm，不要整体开大窗
    12. 每层都做「对比度检查」：Gerber 与设计图叠合，确认无缺失层

    5.7.6本板三处容易踩的 DFM 坑

    • RJ45 变压器：ATK9111A 的引脚间距 2.0mm，焊盘间阻焊桥只有 0.12mm，需要板厂做「阻焊桥加宽」或接受少量连锡风险；
    • Type-C 16pin：0.5mm 间距，钢网开窗要做「纳米涂层 + 阶梯」，否则连锡；
    • BGA-289 0.8mm：焊盘 0.45mm、阻焊开窗 0.5mm，需激光钢网 + 0.1mm 阶梯，普通钢网下锡量不足。

    练习

    1. DRC 全绿为什么还可能做不出来？
    DFM 问题（丝印、阻焊桥、工艺边、Mark）不在 DRC 规则里。
    2. 丝印最小字高与线宽？
    字高 ≥0.8mm、线宽 ≥0.15mm。
    3. Mark 点尺寸与周围净空？
    直径 1–1.5mm，周围 2mm 无铜无丝印。
    4. 工艺边为什么 ≥5mm？
    贴片机轨道夹持需要，太窄会夹不住或压到元件。
    5. V-cut 与邮票孔怎么选？
    直线边缘用 V-cut（成本低）；异形/圆角用邮票孔。
    6. 阻焊桥太窄会怎样？
    引脚间连锡，尤其在 0.5mm 间距器件上。
