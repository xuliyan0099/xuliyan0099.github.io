    出图、贴片、首板点亮：从文件到一块能跑的板

    设计完成到板子跑起来，中间还有五道关卡：出图、审核、打样、贴片、点亮。每一道都有「一次做错、整批重来」的坑。这一章把它们排成一条可执行的时间线。

    读完这一章，你应该能

    1. 列出 Gerber 与钻孔文件的完整清单，知道漏哪一层会怎样
    2. 检查 BOM/CPL 的五个常见错误（极性、旋转、封装、位号、DNP）
    3. 用面积比判断钢网能不能下锡，选对钢网厚度
    4. 说出回流曲线的四个区间与峰值温度
    5. 按十步法点亮首板，并知道每一步的判据

    5.8.1Gerber 清单：少一层就废

    文件内容漏了会怎样
    GTL / GBL顶层/底层铜没线路，板子是白板
    GTS / GBS顶层/底层阻焊焊盘被绿油盖住，焊不上
    GTO / GBO顶层/底层丝印无位号，维修困难
    GKO / 板框外形铣切板厂不知道切多大
    DRL（Excellon）钻孔 + 槽孔没有孔，插件装不进
    GTP / GBP钢网（SMT 用）贴片厂无法开钢网

    内层还要 G1/G2（内层铜）与对应阻焊（一般无）。检查方法：把 Gerber 用 KiCad/Gerbv 打开，逐层与设计图叠合看，重点看「钻孔是否落在焊盘中心」。偏移 0.1mm 就会破环。

    5.8.2BOM / CPL：五个必查项

    1. 位号与封装对应：BOM 写 SOT-23，CPL 写 SOT-23-5，贴片厂直接贴错；
    2. 极性/方向：二极管、LED、钽电容、IC 的 1 脚；CPL 里必须有 rotation 字段；
    3. DNP 标记：不贴的元件要在 BOM 里单独列或删除，否则贴片厂照贴（本板 R26、R85 等标 DNP）；
    4. 替代料：缺货时的 pin-to-pin 替代必须同封装同极性，否则要改板；
    5. 坐标原点：CPL 原点必须与 Gerber 一致（通常板左下角），否则整体偏移。

    经验：BOM/CPL 出错导致的返工，比设计错误更常见。发出去前一定用「贴片厂提供的模板」核对一遍格式。

    5.8.3钢网：面积比决定能不能下锡

    钢网开窗的「面积比」：

    AR = 开窗面积 / 孔壁面积 = (W×L)/(2×(W+L)×t)

    AR ≥0.66 才能可靠脱模。以 0.5mm 间距 IC、开窗 0.25×0.6mm、钢网 0.12mm：

    AR = (0.25×0.6)/(2×0.85×0.12) = 0.15/0.204 = 0.735 ✓

    若钢网 0.15mm：AR=0.15/0.255=0.588 ✗，下锡不足，虚焊。所以细间距器件要 0.1–0.12mm 薄钢网，或做「阶梯钢网」（局部减薄）。

    BGA 还要按「焊盘 1:1 开窗 + 0.05mm 外扩」处理；本板 BGA-289 的 0.45mm 焊盘对应开窗 0.5mm。

    5.8.4回流曲线：四个区间

    无铅（SAC305）典型曲线：

    区间温度时间作用
    预热室温→150°C60–90s溶剂挥发，防爆锡
    恒温150–190°C60–120s助焊剂活化，均匀受热
    回流217°C 以上45–90s焊膏熔化、润湿
    冷却峰值→室温≤4°C/s形成细晶粒焊点

    峰值温度 235–245°C（SAC305 熔点 217°C）。峰值过高会损伤塑料件（Type-C 座、按键），过低会虚焊。本板有 Type-C 与轻触开关，峰值取 240°C 上限内。

    5.8.5首板点亮十步法

    1. 目检：有无漏贴、错贴、立碑、连锡（放大镜 + 显微镜）；
    2. 测短路：各电源域对地电阻（同 4.8 五步法第一步）；
    3. 限流 0.1A 上电，量 DC_IN、VM、5V；
    4. 量 3.3V、1.35V、2.8V、NVCC_SD；
    5. 测 POR_B 时序（低→高，≥100ms）；
    6. 测 24MHz 起振（≥1Vpp）；
    7. 接串口，看是否有 U-Boot 输出；
    8. U-Boot 下测 DDR：mtest 或 memtester；
    9. 测 eMMC/SD 识别、网口链路、USB 枚举；
    10. 烧系统，跑 24h 压力测试，记录温度。

    每一步都要有「通过判据」，否则「看起来能跑」会在两周后变成随机死机。

    练习

    1. 漏了阻焊层会怎样？
    焊盘被绿油覆盖，无法焊接。
    2. BOM 与 CPL 封装不一致会怎样？
    贴片厂按 CPL 贴，元件与焊盘不匹配，整批报废。
    3. 面积比公式与判据？
    AR=(W×L)/(2(W+L)t)，要求 ≥0.66。
    4. SAC305 熔点与峰值温度？
    217°C；峰值 235–245°C。
    5. 为什么细间距要用 0.1–0.12mm 钢网？
    厚钢网面积比不足，脱模不良导致下锡量不够、虚焊。
    6. 首板点亮第一步为什么是目检？
    漏贴/错贴/连锡能在上电前发现，避免烧板。
