    库与封装：一个封装画错，整批板报废

    原理图错了改一根线，封装错了要废一批板。封装是唯一「不能靠改代码补救」的错误。这一章讲六种真实翻车方式、命名的强制规范、IPC-7351 焊盘算法，以及一个 5 分钟就能做的 1:1 打印验证。

    读完这一章，你应该能

    1. 说出六种封装错误的后果，并知道每种在什么阶段能发现
    2. 按「引脚数_体宽_间距」规范命名，避免同名不同物
    3. 用 IPC-7351 的思路算焊盘长宽，而不是「差不多」
    4. 用 1:1 打印 + 实物比对，在打样前拦住 80% 的封装错
    5. 检查本板六类关键封装（SOT-23-5、SMA、Type-C、BGA、排针、晶振）

    5.1.1六种翻车方式

    #错误后果在哪一步能发现
    1引脚数错（SOT-23 画成 SOT-23-5）焊不上，或飞线救1:1 打印比对
    2焊盘过长/内距太宽回流时立碑（tombstone）打样首板
    3极性反（二极管/钽电容/LED）上电即炸或完全不亮原理图符号 + 丝印
    40.5mm 间距 QFN 焊盘过宽连锡、桥接钢网/首板 X 光
    5丝印压在焊盘上焊接不良、字符残缺DRC 丝印检查
    6封装外形与结构件干涉装不进外壳/顶到电池3D 装配检查

    第 2 种最隐蔽：焊盘稍微长一点，手工焊完全正常，一上回流焊就立碑——因为两端焊膏表面张力不平衡。这类问题只有首板能暴露，所以第一次打样不要一次打 50 片。

    5.1.2命名：让封装名自带信息

    推荐格式：类型-引脚数_体宽x体长mm_P间距mm，例如：

    • SOT-23-5_1.6x2.9mm_P0.95mm
    • SOP-8_3.9x4.9mm_P1.27mm
    • QFN-32_5x5mm_P0.5mm_EP3.1mm
    • BGA-289_17x17mm_P0.8mm

    为什么必须带尺寸：不同厂家的「SOT-23」体宽可能 1.2–1.4mm，焊盘按 1.2 画、实物 1.4，就会出现「引脚够不着焊盘」。名字里带尺寸，就不会拿错。

    本板的 i.MX6ULL 是 MAPBGA-289、0.8mm 间距、17×17mm；核心板 60pin 连接器是 3710M060046G3FT01（0.5mm 间距双排），这类连接器的封装必须用厂家提供的 STEP/DXF，不能自己画。

    5.1.3焊盘尺寸：IPC-7351 的三条边

    焊盘不是「和引脚一样大」，而是由三段组成：

    • Toe（脚尖外伸）：提供焊点外形，典型 0.1–0.3mm；
    • Heel（脚跟内伸）：保证根部润湿，典型 0.1–0.2mm；
    • Side（侧向外伸）：防止偏移，典型 0.05–0.15mm。

    简化算法（翼形引脚，如 SOP/QFP）：

    焊盘长 = 引脚长 + Toe + Heel ≈ L + 0.4mm
    焊盘宽 = 引脚宽 + 2×Side ≈ W + 0.2mm
    内距 = 引脚跨距 − 引脚长（保证脚跟落在焊盘上）

    以 0402（体 1.0×0.5mm，端头各 0.25mm）为例，IPC 中密度（Level B）推荐：焊盘 0.55×0.60mm，两焊盘中心距 0.90mm。若你把焊盘做到 0.8mm 长、中心距 1.1mm，两端焊膏量差一点就会立碑。

    密度等级：A（最大，手工/返修友好）、B（标准）、C（最密，高密度板）。手工焊选 A，回流+钢网选 B，不要一律用 C。

    5.1.45 分钟拦住 80% 的错：1:1 打印

    1. PCB 软件导出顶层/底层 PDF，关闭「适应页面」，按 1:1 打印；
    2. 打印后量一条已知线（如 2.54mm 排针间距），确认真的是 2.54mm（打印机常有 1–3% 缩放）；
    3. 把实物（芯片、连接器、晶振）放上去，看引脚是否正好压在焊盘上；
    4. 重点看：极性标记方向、1 脚位置、连接器开口朝向、晶振四脚是否对称。

    这一步成本 5 分钟，能拦住引脚数错、间距错、极性反、连接器朝向错——四类最常见的报废原因。

    练习

    1. SOT-23 与 SOT-23-5 的差别在哪？画错会怎样？
    引脚数 3 vs 5；画错焊不上，只能飞线或报废。
    2. 为什么焊盘过长会导致立碑？
    两端焊膏量/润湿力不平衡，回流表面张力把元件拉起。
    3. IPC 密度等级 A/B/C 分别适合什么场景？
    A 手工返修、B 标准回流、C 高密度细间距。
    4. 0402 的推荐焊盘尺寸（Level B）？
    约 0.55×0.60mm，中心距 0.90mm。
    5. 1:1 打印第一步要确认什么？
    打印是否真 1:1（量 2.54mm 排针间距），排除打印机缩放。
    6. 3225 四脚晶振按两脚画会怎样？
    1/3 脚被短接到外壳地，晶振不起振。
