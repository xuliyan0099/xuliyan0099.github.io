    信号完整性基础：传输线判据、四种端接、眼图与 TDR

    「线短就没事」是错的——决定要不要当传输线看，是边沿时间，不是频率。这一章给判据公式、四种端接的取舍、眼图怎么读，以及用 TDR 把反射点算成毫米。

    读完这一章，你应该能

    1. 用 tr 与传播延迟判断一条线要不要端接
    2. 选源端/并联/戴维南/AC 端接，并算出电阻值
    3. 读懂眼图的眼高、眼宽与模板关系
    4. 用 TDR 的往返时间算出不连续点的位置

    6.3.1传输线判据：看边沿，不看频率

    当信号的上升时间与走线延迟可比时，走线必须按传输线处理。判据：

    Lcrit ≈ tr/(2×延迟/单位长度)

    FR4 表层约 6ps/mm（内层约 5.9ps/mm）。例：

    信号trLcrit结论
    I2C 100kHz~300ns25m板内任何长度都不必端接
    UART 115200~10ns0.83m板内不必
    RMII 50MHz~2ns167mm板内 <100mm 通常可
    DDR3L 400MHz~0.5ns42mm超过 42mm 必须端接
    USB HS 480Mbps~0.3ns25mm必须按差分传输线设计

    注意：这是「要不要端接」的判据，不是「能不能走」的判据。DDR 的线长往往超过 42mm，所以必须靠 ODT（片内端接）+ 源端串阻来控制。

    6.3.2四种端接

    方式接法功耗适用
    源端串阻驱动器 → Rs → 线低点对点、单向（本板 DDR 时钟 470Ω、CSI_MCLK 22Ω）
    并联端接线末端 → R → GND（或 VDD）高（直流一直耗）短线、低速
    戴维南两个电阻分压到 VDD/2中总线、需要偏置
    AC 端接R + C 串联到地低高速时钟、DDR 地址

    源端串阻的原理：驱动器输出阻抗 Zout（CMOS 约 10–30Ω）加上 Rs 等于线阻抗 Z0（50Ω），实现「源端匹配」，反射回到源端被吸收。取 Rs=50−Zout：

    Zout=10Ω ⇒ Rs=40Ω；Zout=30Ω ⇒ Rs=20Ω

    本板 CSI_MCLK 串 22Ω、DDR 时钟串 470Ω（后者是「弱驱动 + 阻尼」，因为 DDR 时钟是差分、驱动强，470Ω 主要压过冲）。这两个值都不是「随手」，而是按驱动器阻抗与线阻抗调的。

    6.3.3反射与振铃：怎么读波形

    反射系数 Γ=(ZL−Z0)/(ZL+Z0)。开路端 Γ=+1（全反射），短路端 Γ=−1。典型波形特征：

    • 过冲：第一次到达末端时电压超过稳态 20% 以上 → 端接不足；
    • 振铃：多次来回反射形成的衰减振荡 → 阻抗不连续 + 损耗低；
    • 台阶：波形中途出现平台 → 中间有阻抗突变（如过孔、连接器）。

    判据：过冲 ≤10% Vswing、振铃在 3 个周期内衰减到 5% 以内。

    6.3.4眼图：把一千个 bit 叠起来

    眼图是把所有 bit 周期的波形叠加，形成「眼睛」。三个关键量：

    • 眼高：垂直开口，反映噪声与幅度余量；
    • 眼宽：水平开口，反映抖动（jitter）与上升时间；
    • 模板（mask）：标准规定的「禁区」，眼图不能侵入。

      • USB 2.0 HS 的眼图模板要求眼高 ≥525mV、眼宽 ≥0.45UI（约 0.94ns）。DDR3L 的读取眼图由控制器训练决定，实测眼宽应 >0.6UI。

      眼图变差的三类原因：幅度不足（驱动/端接）、抖动大（时钟质量/电源噪声）、边沿慢（带宽/负载电容）。

      6.3.5TDR：把反射算成距离

      TDR 发射阶跃，测反射回来的时间。不连续点距离：

      d = (t往返×v)/2

      v≈170mm/ns（内层）。若反射在 2ns 后出现：d=2×170/2=170mm。这告诉你「问题在第 170mm 处」——如果板只有 100mm 长，那就是连接器或电缆。

      TDR 还能读出阻抗：波形平台高度对应 ZL。50Ω 线上出现 60Ω 平台 = 线宽偏窄或参考平面有洞。

      6.3.6实测注意

      • 测高速信号用差分探头或「双通道相减」，单端探头会引入地环路；
      • 探头带宽 ≥3 倍信号带宽（0.35/tr）；
      • 测眼图要「长存储 + 时钟恢复」，不能用普通触发；
      • 测 TDR 要先校准（短路/开路/50Ω 负载）。

      驱动器 Zout 15 Ω
      线阻抗 Z0 50 Ω
      TDR 往返时间 2.0 ns

      练习

      1. DDR3L tr=0.5ns 的临界线长？
      0.5ns/(2×6ps/mm)≈42mm。
      2. Zout=20Ω、Z0=50Ω，源端串阻取多少？
      30Ω。
      3. 源端串阻为什么能吸收反射？
      源端阻抗与线阻抗匹配，反射回到源端被吸收不再往返。
      4. 眼图三个关键量？
      眼高、眼宽、模板（mask）。
      5. TDR 反射 2ns 后出现，距离多少？
      2×170/2=170mm。
      6. 为什么测高速信号要用差分探头？
      避免地环路与共模噪声，保持带宽与阻抗匹配。
