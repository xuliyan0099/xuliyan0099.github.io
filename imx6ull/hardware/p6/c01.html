    ESD 与浪涌：TVS 选型四步与钳位计算

    接口器件死于「第一次插拔」。TVS 不是「随便并一个」，而是四个参数全部要算：工作电压、击穿电压、钳位电压、峰值功率。这一章用本板 D1 SMBJ5.0A / D2 SMBJ3.3A 走一遍。

    读完这一章，你应该能

    1. 按四步选出 TVS 的工作电压、击穿电压、钳位电压与功率
    2. 算 IEC 61000-4-2 接触放电 8kV 的峰值电流与 TVS 承受能力
    3. 算 8/20µs 浪涌的能量，判断 TVS 会不会烧
    4. 说出「TVS 放在连接器内侧 10mm 内」的原因，并识别错误布局

    6.1.1ESD 到底有多狠

    IEC 61000-4-2 接触放电模型：150pF 电容 + 330Ω 电阻。8kV 时峰值电流：

    Ipeak ≈ V/R = 8000/330 = 24 A（上升时间 <1ns）

    空气放电 15kV 时可达 45A。这个电流在 1ns 内流过，di/dt = 24A/ns，任何走线电感都会产生巨大电压：1nH × 24A/ns = 24V。所以 ESD 防护的关键不是「TVS 有多大」，而是TVS 离接口多近。

    6.1.2TVS 选型四步

    1. VRWM（反向工作电压）≥ 1.1×正常电压，且 ≤ 被保护器件耐压。本板 5V 母线选 SMBJ5.0A（VRWM=5.0V），3.3V 选 SMBJ3.3A（VRWM=3.3V）。
    2. VBR（击穿电压）≈1.1–1.2×VRWM：太低会漏电，太高保护晚。
    3. VC（钳位电压）< 后级绝对最大额定。SMBJ5.0A 在 24A 时 VC≈9.2V；后级 DCDC 耐压 18V，OK。若后级是 3.3V CMOS（绝对最大 4.6V），就不能用 5V TVS 保护它——必须用 3.3V 型号（VC≈6.5V 仍偏高，需加限流电阻）。
    4. PPK（峰值脉冲功率）≥ VC×Ipeak。SMBJ 系列 600W（10/1000µs 波形）。ESD 是 ns 级，能量远小于 10/1000µs，所以 600W 器件扛 24A 没问题。

    注意 VC 是在特定电流（如 24A）下测的。若 ESD 电流更大，VC 会更高——这就是「钳位电压随电流上升」的非线性。

    6.1.3浪涌：能量才是杀手

    8/20µs 电流波形（浪涌模拟）下，能量：

    E ≈ 0.5×VC×Ipeak×t等效

    取 1kV/2Ω 源、500A 峰值、20µs 等效宽度、VC=9.2V：E ≈ 0.5×9.2×500×20µ = 46 mJ。SMBJ 的 600W/10/1000µs 对应能量约 6J，46mJ 只占 0.8%，安全。

    但如果是「雷击感应」1.2/50µs + 8/20µs 组合波、且 TVS 前面没有阻抗，电流可达上千安，TVS 会烧。所以接口防护要「分级」：GDT/压敏电阻（大能量）→ 限流/共模电感 → TVS（快速钳位）→ 芯片。

    6.1.4放哪儿才有用：三条铁律

    • TVS 在连接器内侧 ≤10mm，且「先 TVS 后芯片」——ESD 电流必须先被旁路到地，不能先流过芯片。
    • TVS 的地要接「接口地」，并用短过孔连到主地；地线长度每 1mm 增加 1nH，24A/ns 下就是 24V。
    • 被保护线在 TVS 之后不要「绕路」：绕路的部分等于没保护。

    本板 DC 输入：DC_IN → F1 保险 → VD2 SS34（防反接）→ D1 SMBJ5.0A → DCDC。顺序是「先保险、再防反、再钳位」，符合分级思路。

    常见错误：把 TVS 画在 DCDC 输出侧（3.3V），但接口在 5V 侧——ESD 从接口进来时，先经过 DCDC 才到 TVS，DCDC 已经被打穿。

    6.1.5USB/以太网/串口的差异

    接口防护要点本板做法
    USBVBUS 用 5V TVS；D+/D- 用低电容 ESD 阵列（<1pF）MT9700 限流 + Type-C CC 5.1K
    以太网变压器隔离 + 共模扼流 + TVS 阵列ATK9111A 变压器 + L3/L4 磁珠
    RS485/CAN差分 TVS（双向）+ 共模电感 + 终端TJA1050/SP3485 + 120Ω + 360Ω 偏置

    USB 的 D+/D- 是 480Mbps，TVS 的寄生电容必须 <1pF，否则信号被「吃掉」。所以不能用普通 SMBJ，要用专门的 ESD 阵列（如 0.5pF 的 DFN 封装）。

    练习

    1. 8kV 接触放电的峰值电流？
    8000/330≈24A。
    2. TVS 选型四步是哪四个参数？
    VRWM、VBR、VC、PPK。
    3. 3.3V CMOS（绝对最大 4.6V）能用 SMBJ5.0A 保护吗？
    不能，钳位 9.2V 远超 4.6V；要用 3.3V TVS 并加限流。
    4. 浪涌 500A、20µs、VC=9.2V 的能量？
    约 46mJ。
    5. TVS 地线为什么要短？
    地线电感在 24A/ns 下产生几十伏压降，钳位失效。
    6. USB D+/D- 为什么不用 SMBJ？
    寄生电容太大（>100pF），会破坏 480Mbps 信号。
    7. 「先 TVS 后芯片」是什么意思？
    ESD 电流先经 TVS 旁路到地，再到达芯片；布局顺序不能反。
