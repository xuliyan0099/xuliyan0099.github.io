打样到首板点亮

设计文件和一块真板子之间，隔着工艺、物流和一次「敢不敢上电」。这一章把这段路拆成可执行的步骤：出图 → 下单 → 焊接 → 分段上电 → 点亮，每一步都有验收标准。做完这一章，你就真的画过一块板。

读完这一章，你应该能

  1. 导出一套完整的制板文件（Gerber、钻孔、BOM、坐标），并知道每个文件的作用
  2. 独立完成一次打样 + 贴片下单，估算出成本
  3. 按「分段上电」的顺序给首板上电，而不是一次性全插上
  4. 在首板不亮时，用十步法定位到具体环节

第一次画板建议做「最小系统 + 一个外设」：电源、SoC、DDR、eMMC、串口、一个 LED。功能越少，首板成功率越高，学到的东西一样多。

2.6.3焊接：回流曲线与手焊的分界

  1. 点锡膏（钢网）。钢网对齐焊盘，刮刀 45°，一次刮过；锡膏量以覆盖焊盘 70% 为宜。
  2. 贴件（贴片机或手动）。先贴小件（0402、QFN），再贴大件，最后贴 BGA；贴完核对极性。
  3. 回流。典型四段：预热 150℃（60–90s）→ 保温 180℃ → 回流峰值 235–245℃（30–60s）→ 冷却。峰值过高会伤器件，过低会虚焊。
  4. 检查。放大镜或显微镜看连锡、偏位、立碑；BGA 只能靠 X 光或通电判断。
  5. 手焊补充。插件、排针、大电容最后手焊；0402 以下建议不要手焊，成功率低。

2.6.4首板点亮：十步，不许跳

核心原则：每加一步，只验证一件事。一次全插上再上电，烧了也不知道烧在哪。

  1. 目视 + 万用表量短路。量 5V 对地、3.3V 对地、1.35V 对地，正常是几百 Ω 以上或充电上升；接近 0 就是短路，先别上电。
  2. 只上电源，不装 SoC（如果可以）。量各路电压是否建立、纹波多大。板厂贴好的板跳过此步。
  3. 上电，量三路电压。5V ≥4.9V、3.3V 3.2–3.4V、1.35V 1.30–1.40V，且带载不塌。
  4. 量复位脚。上电后应为高（释放），按下复位键变低。
  5. 量晶振。示波器（10×探头）看 24MHz 是否起振、幅度是否够。
  6. 接串口。TX/RX 交叉、GND 共地、115200，看 Boot ROM 是否打印。
  7. 看启动介质。确认拨码指向的介质里有有效镜像，或进 USB 下载模式。
  8. 进 u-boot。能进命令行就算「板子活了」，此时先别急着跑内核。
  9. 测内存。u-boot 里跑 mtest 或多次读写，确认 DDR 无误。
  10. 起内核。确认串口、根文件系统、网口，最后再测外设。

现象原因判据 / 修法
各路电压都对，串口无输出封装画错 / 焊接偏位 / TXRX 反量 SoC 引脚是否真有信号；对照封装尺寸图
3.3V 只有 1.2VDCDC 反馈电阻错 / 电感虚焊断电量反馈分压；补焊电感

网口灯不亮PHY 供电 / 变压器 / 25MHz 晶振量 PHY 电源与晶振；核对变压器型号

上电前必须做的三件事

1. 用限流电源（比如 5V/500mA 限流），一短路就限流而不是烧板。

2. 手摸温度：上电 10 秒内摸 SoC 与 DCDC，烫手立刻断电。

3. 别插屏、别插卡、别接外部设备：首板只验最小系统，外设后加。

到这里你已经走完的路

从「这块绿板子是什么」→ 认出每个元件 → 看懂原理图 → 算电源与接口 → 画叠层布铜 → 出图打样 → 首板点亮。这条路的下一步不是「再学一门课」，而是复制一遍：换一颗芯片，从它的数据手册重新画一次最小系统。第二块板会比第一块快三倍，因为你会查表了。

自测

为什么首板要「分段上电」，而不是一次全部装好再上电？
因为一次全装，任何一处短路或贴错都会让整板异常，且无法定位。分段上电把「电源是否正常」「芯片是否活着」「介质是否有效」分开验证，出错时能立刻缩小范围。
Gerber 齐全但没写阻抗要求，会怎样？
板厂按默认工艺做，线宽对应的阻抗可能偏离目标（比如 50Ω 变成 40Ω 或 65Ω）。低速时看不出来，USB/以太网/DDR 上就表现为误码、训练失败、偶发死机。
回流峰值温度为什么不能太高？
过高会让焊料过度氧化、IMC 层过厚（焊点变脆），还可能超过器件的最髙回流温度（多数塑料封装 245–260℃）。判据是看器件规格书的 reflow profile，取所有器件里最低的那个上限。
