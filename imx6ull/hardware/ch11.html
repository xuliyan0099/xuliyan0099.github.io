复位、时钟与启动

电源给了板子生命，复位、时钟、启动配置这三样给了它秩序：什么时候开始跑、每秒跑多快、从哪儿读第一条指令。这三处出问题，现象往往是「上电毫无反应」——比死机更难查，因为它们连日志都不给你。

读完这一章，你应该能

  1. 算出一个 RC 复位电路的脉宽，并判断它够不够芯片要求的最小宽度
  2. 由晶振的负载电容规格算出外接电容值，并说出为什么不加就会频率偏
  3. 画出 24MHz → PLL → 各外设的时钟路径，说出 528MHz 和 396MHz 是怎么来的
  4. 区分 BOOT_MODE 引脚与 eFuse，知道改哪个会「一改就变砖」

2.3.1复位：一个宽度有下限的脉冲

复位不是「按一下按钮」这么随意。芯片手册会给出复位最小脉宽（常见 1–20ms，POR 可能要求更长）。电路必须保证：电压建立后，复位脚保持低电平足够久，再释放。

最简单的 RC 复位：上电瞬间电容未充电 → 复位脚被拉低；随着电容经电阻充电，电压升到阈值以上 → 复位释放。时间常数近似：

\( \tau = R \cdot C \)　　\( t_{delay} \approx 0.7\,\tau \text{（到约 50% 阈值时）} \)

RC 复位脉宽计算器调电阻与电容，看复位保持多久、够不够

为什么很多板子用复位芯片而不是 RC

RC 的问题是阈值不确定：不同批次的施密特门阈值不同，电源上升斜率也随负载变化，导致复位释放时刻漂移。专用复位芯片（如带 delay 的 supervisor）给出确定的阈值与延时，代价是几毛钱。自己画板子时，只要负载重、电源上升慢，就别省这一颗。

2.3.2晶振：负载电容算错，频率就偏

晶振规格书会写 CL = 12pF（负载电容）。它不是你随便挑的电容，而是晶振要求「看到」的总电容。外接两个电容串起来（对交流而言串联），再加上 PCB 杂散电容：

\( C_L = \dfrac{C_1 \cdot C_2}{C_1 + C_2} + C_{stray} \)，通常 \(C_1 = C_2\)，\(C_{stray} \approx 3\text{–}5\,\mathrm{pF}\)

若 CL = 12pF、杂散取 4pF，则每侧电容 ≈ 16pF（取标准值 15pF 或 18pF 后实测微调）。电容偏大 → 频率偏低；偏小 → 偏高。偏几十 ppm 在串口上可能看不出来，在 USB、以太网、CAN 上就会直接不通。

2.3.3时钟树：24MHz 怎么变成 528MHz

i.MX6ULL 内部有一整套 PLL + 分频器（CCM 模块），所有外设的时钟都从这里派生。关键理解：外设不是「自己有时钟」，而是「被分配到某个时钟源再分频」。所以改一个外设的时钟，可能连带影响另一个共用同源的外设。

为什么串口乱码有时不是波特率设错

如果 UART 的源时钟被分频到偏离 115200 的整数倍太远（误差 > 2–3%），即使软件里写「115200」，实际波形也不是。判据：用示波器测一位宽度，标称 8.68µs，实测偏差超过 3% 就是时钟路径问题，回去查 CCM 的分频与源。

2.3.4启动配置：引脚与 eFuse 的优先级

上电后 Boot ROM 要判断「从哪儿读代码」。它看两处：BOOT_MODE 引脚电平（可随时改，靠拨码/跳线）和 eFuse 里的配置位（一次烧写，不可逆）。通常顺序是：若 eFuse 已「锁定」，以 eFuse 为准；否则以引脚为准。

组合行为典型用途风险
BOOT_MODE[1:0] = 00内部 Boot（USB/串口下载）救砖、量产烧录没有退出机制，需手动拨回
= 01从 SD/eMMC 启动正常启动介质里没有有效镜像就卡住
= 10从 NAND/其他特定存储方案型号不匹配会读不到
eFuse 已烧固定启动介质量产防误拨不可逆，烧错就变砖
烧 eFuse 前必须做的事

先在一台可救回的机器上验证整条启动链（拨码模式能进系统、uuu 能下载）；再确认 eFuse 的值与板子实际介质一致；最后才烧。eFuse 烧完不能改，只能靠 USB 下载模式救——而下载模式本身也依赖 BOOT_MODE 引脚没有被彻底封死。

画板时的启动脚处理

BOOT_MODE 脚要明确上下拉，不要悬空（悬空时电平不确定，可能随机进下载模式）。用拨码时串 1kΩ 限流并加 TVS；用跳线时留测试点，方便万用表量。

自测

R = 10kΩ、C = 100nF，复位保持大约多久？
\(\tau = 10^4 \times 10^{-7} = 1\,\mathrm{ms}\)，到 50% 阈值约 0.7ms。如果芯片要求最小 1ms，这就不够——把 C 加到 220nF（τ≈2.2ms）或换复位芯片。
晶振负载电容 CL = 12pF，外接两个电容应该多大？
两电容串联值 + 杂散 ≈ CL。取杂散 4pF，则串联值 8pF → 每个 16pF，实际选 15pF 或 18pF，再看频率偏差微调。算错会让频率偏几十 ppm，USB/以太网直接不通。
为什么改一个外设的时钟可能影响另一个外设？
因为它们可能共用同一个 PLL 源或同一级分频器（CCM 的 clock group）。改分组分频会同时改变组内所有外设的频率。所以改时钟前要查「这个外设挂在哪个 clock root」。
