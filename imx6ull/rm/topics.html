芯片手册 · 专题重组/60 章已全部上线/七条主线

七条主线：把 60 章按工程链路重排

按章号读，读到第 20 章就忘了第 3 章。真正写代码时也不是这个顺序：要启动，就从晶振一路查到 NOR 的 LUT；调不通串口，先怀疑引脚复用，再怀疑门控。这七条线是把 60 章按「上板时事情发生的顺序」重新串一遍，每条线给顺序、给理由、给最短三章。每一章都能点进去看四到七步的交互讲解。

00怎么用这七条线

三条使用规矩

  1. 先读首章，再按表走——每条线的第一章都是总览，先把「这一段在整颗芯片里占什么位置」建立起来，后面的章才有落点。
  2. 不必读完——表里写了「为什么在这一步」，如果你手上没有这块硬件（比如没接 NAND），整行跳过，不影响后面。
  3. 卡住时反向查——现象定位用目录页的「按问题查」表；这条线用来回答「接下来该配什么」。
一条线读完大概多久

每章四到七步，逐步点，平均 6–10 分钟。一条主线 6–8 章，约一小时；七条线全部过一遍是 6–8 小时，相当于把整本手册走一遍，但顺序是你能记住的那个顺序。

一从冷启动到 shell

8 章 · 上电到第一行日志

这条线回答一个问题：手指按下复位键之后，到串口打出第一行字，中间经过了谁。它同时也是排障顺序——板子不亮，就按这条线从上往下查。

章为什么在这一步落地到
RM08 启动流程Boot ROM 是第一段代码，它怎么找镜像、怎么验 IVT 与 DCDIVT / Boot Data / DCD 三块结构
RM05 熔丝表从哪个介质启动、几位宽，全由 BOOT_CFG 决定BOOT_CFG1–4 与 BT_FUSE_SEL
RM51 复位控制器先分清是 POR 还是看门狗复位，否则会查错方向SRSR 复位源、SBMR 锁存启动配置
RM60 晶振24 MHz 不起来，后面所有 PLL 都是空谈主振与 32.768 kHz RTC 晶振
RM02 内存映射解释为什么 0x0 是 ROM、0x6000_0000 是外部 NOR片内 ROM 与各外设基址
RM43 ROM 补丁复位向量可以被补丁改写，这是外部启动的一环0x0 处换成跳转，16 个比较器
RM42 QuadSPI最常见的启动介质，读镜像靠 LUT 里那条 0xEB 序列LUT 读序列与 0x6000_0000 窗口
RM58 uSDHCSD 卡与 eMMC 走另一条启动路径，量产更常见命令/ADMA、卡识别与分区
只读三章

RM08 → RM05 → RM51：能把「为什么这块板从 NOR 起、为什么复位后日志在 UART1」讲清楚，就够用了。

二时钟、电源与复位

8 章 · 让芯片跑起来并睡下去

这条线是所有外设的前置：任何外设不工作，第一步都该问「它的门控开了吗、根时钟选对了吗」。做完再谈低功耗。

章为什么在这一步落地到
RM10 时钟电源总览先看清 PLL 树与电源域的骨架，再进细节PLL 链、域划分、DVFS 概念
RM18 CCM门控与根时钟的实际开关都在这CCGR、PLL 配置、时钟根选择
RM27 GPCWFI 之后芯片去哪儿，由它决定电源域状态机与低功耗模式
RM39 PMU提频必须先提压，LDO 的步进在这里片上 LDO 与调压寄存器
RM51 复位控制器warm reset 要等 DDR 确认，等不到就降级SCR / SRSR / SBMR
RM48 SNVS主电断掉以后，谁还活着、谁记得时间RTC、单调计数、GPR 保持域
RM52 温度监控高温降频是硬保护，不看它会被动撞墙三档阈值与温度换算
RM59 看门狗最后一道保险，也是「莫名重启」的常见元凶喂狗窗口与复位因果
只读三章

RM18 → RM27 → RM51：会开门控、会让芯片睡着、分得清是谁把它叫醒。

三DMA 与数据搬运

6 章 · 别让 CPU 搬字节

摄像头、音频、NAND、网络都在等数据自动流动。这条线讲清「谁触发、谁搬、搬到哪、搬完怎么通知」这四件事。

章为什么在这一步落地到
RM03 中断号与事件号DMA 不是轮询，它靠事件号被外设叫醒外设事件号表与中断号表
RM46 SDMA32 个虚拟通道共用一套脚本内核，通用搬运都走它CHNENBL / CHNPRI、CCB 与 BD
RM38 OCRAM脚本、描述符、小缓冲放哪儿，直接影响搬得动搬不动片上 RAM 的地址与访问宽度
RM15 APBH 与专用 DMANAND 与墨水屏有专用通道，不走 SDMAAPBH 桥与 BCH 的挂接
RM17 NAND ECCECC 引擎靠 DMA 喂页数据，配错就全是错码BCH 参数与页级校验
RM14 AIPSTZ某个主控能不能看见某个外设，由权限挡着主控权限与访问越界的表现
只读三章

RM46 → RM03 → RM38：会开通道、会找事件号、知道缓冲该放哪块 RAM。

四显示与图形

6 章 · 从帧缓冲到合成

一条 RGB 屏点亮的完整链路：引脚 → 时钟 → 控制器 → 合成加速 → 采集 → 特殊屏。花屏和偏移九成出在前两章。

章为什么在这一步落地到
RM32 引脚复用24 位数据线加四根同步信号，复用组选错就是全黑LCD 引脚 ALT 模式与电气设置
RM18 CCM像素时钟来自哪条 PLL，除出来是不是正好 33.3 MHzLCDIF 根时钟与分频
RM34 eLCDIF时序参数、帧地址、双缓冲都在这CTRL、VDCTRL、帧缓冲指针
RM41 PXP要叠加、缩放、旋转时，别让 CPU 去拷像素PS/AS 合成、缩放倒数、两级旋转
RM19 CSI摄像头数据先落地成帧，再交给 PXP 处理CSI 接收与打包格式
RM23 EPDC墨水屏刷新逻辑完全不同，要靠波形表EPDC 时序与 WFE 波形
只读三章

RM34 → RM41 → RM32：能把一块 800×480 的屏点亮，并叠一层图标上去。

五存储与外设总线

6 章 · DDR、NOR、SD、NAND

四种存储四种性格：DDR 要校准、NOR 要 LUT、SD 要命令、NAND 要 ECC。这条线讲清各自的初始化门槛。

章为什么在这一步落地到
RM02 内存映射先知道每种存储在地址空间里占哪一段窗口与基址
RM35 MMDC 与校准DDR 不稳多半是校准没做完，不是频率太高初始化序列、读写校准、模式寄存器
RM42 QuadSPINOR 的读命令与时序差异全在 LUT 里填LUT 序列、AHB 窗口、四个缓冲
RM58 uSDHCSD 与 eMMC 靠命令交互，ADMA 才是高速关键命令寄存器、ADMA 描述符
RM29 GPMI + RM17NAND 的时序与 ECC 必须成对配，单独调不通GPMI 时序、BCH 校验
RM49 SPBA多个主控抢外设时，谁有权限、谁被挡PRR 寄存器与轮转仲裁
只读三章

RM35 → RM42 → RM58：把板上的 DDR、NOR、SD 三条路都跑到能读写。

六串口、总线与音频

8 章 · 芯片怎么和外面说话

从上电调试用的 UART，到板上传感器走的 I2C，再到音频这条独立链路。共同点是：引脚、时钟、协议三样缺一不可。

章为什么在这一步落地到
RM55 UART八路基址、波特率公式、FIFO 水位，调试第一工具UBIR/UBMR、USR1/2、上电顺序
RM31 I2C传感器与 PMIC 都挂在这，仲裁与时钟拉伸是难点I2CR/I2SR、START 与 ACK
RM20 ECSPI屏幕、Flash、ADC 常见，四路片选要靠软件管CONREG、FIFO、片选控制
RM26 FLEXCAN车载场景必读，位时序与 Bus-Off 恢复邮箱、位时序、错误状态机
RM45 SAII2S 音频主路径，两级分频决定采样率TCR1–5、FIFO 与帧同步
RM50 S/PDIF光纤与同轴输出，block 结构与 DPLL 锁定时钟子帧格式、SIS 与 STC
RM16 ASRC两路采样率不一致时，靠它做异步转换转换比设置与 FIFO
RM36 MQS没有 DAC 时，用 PWM 直接推喇叭的最小方案四页内容：分频与占空比
只读三章

RM55 → RM31 → RM20：串口能打日志、I2C 能读到传感器 ID、SPI 能读回 Flash 的 JEDEC。

七安全与调试

7 章 · 谁能进来，怎么拦住

这条线两头都硬：一头是熔丝，烧了就不可逆；一头是 JTAG，配错就连不上。做量产或做安全启动时按顺序读。

章为什么在这一步落地到
RM11 安全总览先建立信任链：谁验谁、密钥在哪HAB 流程与安全启动阶段
RM05 熔丝表SEC_CONFIG 与 JTAG 禁用位一旦烧写就回不去熔丝位定义与影响
RM37 OCOTP熔丝控制器的影子寄存器与烧写时序影子寄存器、写保护、烧写步骤
RM47 SJCJTAG 拓扑与三档安全模式，连不上先看这里MOD 引脚、指令表、挑战应答
RM07 调试架构DAP、CTI、ETM 谁接谁，决定能不能断点调试组件拓扑
RM54 TZASC把 DDR 分区保护起来，越界访问直接拦区域配置与违规中断
RM48 SNVS单调计数防回滚，掉电也要记得LP 单调计数器与 tamper
只读三章

RM11 → RM47 → RM37：知道安全启动卡在哪一步、JTAG 为什么连不上、熔丝怎么烧。
