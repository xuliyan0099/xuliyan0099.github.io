新建页模板

这一页的用途：复制本文件、改个名字、改内容，就是知识库里的新一页。

用法两步：① 把 模板页.html 复制到任意文件夹（例如 notes/），改名成 gpio-笔记.html；② 在 Linux学习手册 目录跑一次 pwsh -File .\deploy-edgeone.ps1。线上地址就是 /notes/gpio-笔记.html，并自动出现在 /sitemap.html。

为什么不用改脚本

部署现在是「整个文件夹镜像上传」：根目录下除 dist、build、build-scripts 三个工作目录外，你放进去的任何文件、任何子文件夹都会原样上线。不需要登记、不需要改代码、不需要新建 EdgeOne 项目。

唯一要注意的：文件名和文件夹名会直接变成 URL，尽量用英文或简短中文，别带空格和特殊符号；上层目录里的 assets/ 可以直接用相对路径引用，例如 <link href="../assets/style.css">。

三级标题

普通段落。术语加 code 标记，比如 0x08000000、ldr r0, [r1, #4]。

ldr r0, [r1, #4]   ; 从 r1+4 取一个字到 r0
cmp r0, #8         ; 与 8 比较，置标志位
bne loop           ; 不相等就回 loop
寄存器作用
R0参数 / 返回值
R13SP 栈指针
