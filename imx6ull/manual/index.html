看懂一份芯片手册
1396 页不是拿来通读的

NXP 给的文档一共六份、将近两千页。没人从头读到尾，每一页都是被一个具体问题叫出来的：这个脚能复用成什么、这两位是干什么的、为什么时钟没开写进去没反应。这里把它拆成八篇，每篇解决一类问题。

一句话：手册是字典，不是小说

查字典的前提是知道「要查哪个词」。绝大多数人卡住，不是看不懂英文，而是不知道该翻哪一份、哪一章、哪一张表。八篇之后，你应该能从「板子上一个不亮的 LED」倒推出要查的三张表，并在十分钟内查到那两位。

8 篇的路线

八篇可以顺着读，也可以当工具书用：遇到具体问题直接跳对应一篇。05、06 两篇是核心，其余是准备与善后。

读完这个路口，你应该能

  • 能说清 Datasheet 与 Reference Manual 各回答什么问题，不再拿错文档
  • 拿到一个新外设，能按固定顺序找到「基地址、时钟、引脚、寄存器位域」四样东西
  • 能逐列读一张寄存器表，把 Reserved / R/W / W1C / 复位值都读对
  • 能把手册上的一个位域，翻译成四条读写代码（读、清、置、写回）
  • 能从原理图上的一根线，查到 dts 里该写哪一行
