第 15 课 · 九种寻址方式：一条指令放进一个「地址」

所有访存指令都要回答一个问题：地址怎么算出来。ARM 提供了九种算法，从「直接给数字」到「加上一个移位后的寄存器，再把新地址写回」。这一课把它们列清楚，因为C 语言里访问数组、结构体成员、栈、指针，编译出来就是这九种方式的组合。

这一课要回答的问题

① 地址的三种来源分别是什么？② 前索引与后索引差在哪？③ 写回（!）是干什么的？④ 一次读多个寄存器有什么用？⑤ 结构体成员访问编译出什么？

1. 九种方式一览

; ① 立即数偏移
ldr  r0, [r1, #4]          ; r1 + 4

; ② 寄存器偏移
ldr  r0, [r1, r2]          ; r1 + r2

; ③ 寄存器移位偏移（最常用于数组）
ldr  r0, [r1, r2, lsl #2]  ; r1 + (r2 * 4)  ← arr[i]

; ④ 前索引 + 立即数（与①同，但语义上强调「先算地址再访问」）
; ⑤ 前索引 + 写回
ldr  r0, [r1, #4]!         ; 先 r1 += 4，再用新 r1 读（r1 被修改）

; ⑥ 后索引
ldr  r0, [r1], #4          ; 先读 r1，然后 r1 += 4  ← 遍历数组

; ⑦ PC 相对（取常量或跳转表）
ldr  r0, [pc, #16]         ; 从 PC+8+16 处读

; ⑧ 多寄存器（批量存取，用于栈与拷贝）
ldmia r0!, {r1-r4}         ; 从 r0 连续读 4 个字，r0 递增
stmdb sp!, {r0-r12, lr}    ; 压栈（满递减栈，先减后存）

; ⑨ 寄存器间接（偏移为 0 的特例）
ldr  r0, [r1]              ; 就是 r1 指向的值

2. 结构体成员访问：常量偏移

struct point { int x; int y; int z; };
struct point p;

// C: p.y = 5
// 汇编（假设 p 地址在 r0）：
    mov r1, #5
    str r1, [r0, #4]      ; p.y 在偏移 4 处；p.z 就是 [r0, #8]

这就是「偏移是立即数」的用处：成员位置是编译期常量，直接编码进指令，零额外指令。但立即数偏移范围有限（12 位，±4095），所以大结构体或大数组的访问会退化成「先算地址再访问」。

3. 栈操作：多寄存器寻址的主场

ARM 的栈是「满递减」（FD）：栈向低地址增长，SP 指向最后压入的元素。压栈用 stmdb sp!, {...}（先减后存），出栈用 ldmia sp!, {...}（先读后加）。

一次压 14 个寄存器只需一条指令——这是「靠批量传输解决结构冒险」的典型例子，CPU 为它专门做了多寄存器通路。

4. 与 Linux 的接缝：一次系统调用的寻址链

// 用户态 write(fd, buf, len) 最终变成：
//   mov r7, #4        ; syscall 号
//   svc #0            ; 陷入内核
// 内核里 copy_from_user 从 buf 拷贝：
//   一串 ldrb / strb（字节访问）+ 地址递增
//   地址来自用户指针 → 经 MMU 转换（第 25 课）

// 你写的驱动里，最常见的两种寻址：
writel(val, base + REG_OFFSET);        // 立即数偏移
for (i = 0; i < n; i++) buf[i] = ...;  // 寄存器移位偏移

5. 实验：让编译器告诉你它在用哪种寻址

// t.c
int sum(int *a, int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}
struct S { int x, y, z; };
int gety(struct S *p) { return p->y; }

// gcc -O2 -S t.c
// 观察 sum: 是否用了 ldr r3, [r1], #4   ← 后索引
// 观察 gety: 是否用了 ldr r0, [r0, #4]  ← 立即数偏移

跑一次你会看到编译器几乎总是选「后索引」做数组遍历、选「立即数偏移」做结构体访问。这两个选择不是随意的，是寻址方式与使用场景的最佳匹配。

7. 自测与动手

1

ldr r0, [r1], #4 与 ldr r0, [r1, #4]! 的区别？

看答案

前者：先用 r1 读，再 r1+=4（后索引）；后者：先 r1+=4，再用新值读（前索引写回）。

2

arr[i]（int 数组）为什么是 lsl #2？

看答案

int 占 4 字节，索引要乘 4；左移 2 位等于 ×4，不必过乘法器。

3

结构体成员访问为什么用立即数偏移而不先算地址？

看答案

偏移是编译期常量，可直接编码进指令，省一条 add；超范围时才退化为先算地址。

4

压栈为什么用 stmdb 而不是 str 循环？

看答案

多寄存器一次完成，减少指令数与总线事务，语义上也更利于一致性。

5

为什么 PC 相对寻址对位置无关代码重要？

看答案

代码整体平移时，PC 与目标的相对距离不变，常量与跳转表都仍可正确访问，无需重定位。

  2. 写遍历数组的 C 函数，-O2 -S 看是否用后索引。
  3. 故意写超过 4095 偏移的结构体访问，看编译器怎么变通。
  4. 在驱动里写 writel 与 writel_relaxed，比较反汇编差异。
