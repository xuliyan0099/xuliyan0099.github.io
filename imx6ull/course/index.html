从零学计算机 · 49 课

这套课只有一个目标：让你从「不知道 0 和 1 是什么」开始，一路走到「能看懂 CPU 在执行什么、能解释软件为什么这样跑、能在自己的板子上跑起自己写的驱动」。每一课都回答一个具体问题，每一课都留一个能跑的实验。

这套课与参考卷的关系

参考卷（理论 T01–T18 / 实践 C01–C14，34 页）是与本课程并行的一套：讲得更深、成体系，按「理论卷 / 实践卷」并列编排，适合按章查细节、按章照着做。本课程是主线：按「一个现象 → 一个硬件机制 → 一个可跑实验」的因果链重排，49 课、约 168 小时。遇到需要更深细节的地方，课内会直接给参考卷的链接，不重复写。

4. 每课的固定规格（写课与验收都按这个）

板块必须包含验收方式
问题一句话疑问句标题；本章要解决的问题清单能背下这一课要回答什么
直觉一个生活类比，且必须注明「类比在哪里失效」能说出类比的边界
硬件寄存器/门/时序级别的动作，不写「大概是这样」能画出时序或数据通路
软件对应的 Linux 现象 + 可观察的位置（文件或命令）能在自己机器上指出那个位置
图1–3 个可视化块（结构图、时序、对照）不看文字能讲出图的意思
实验可直接复制的命令，有无板都能做的版本输出能贴出来，与预期一致
误解三条常见错误说法 + 正确说法能指出别人的错在哪
自测/预告五题 + 下一课的钩子五题至少答对四题

6. 三条硬规矩

  1. 不许跳过实验。每课都设计成「不做就答不出自测题」，这是防自欺的唯一机制。
  2. 不许跳课。课程是单链因果：07 的补码要用 06 的加法器，32 的切换要用 29 的异常。
  3. 不许只读不写。每课结束必须留 200 字的「讲给自己听」，写不出来就是没懂。
