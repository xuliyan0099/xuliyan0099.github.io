第 16 课 · 汇编只有四类动作

汇编看起来指令很多，但按「动作类型」分只有四类：搬、算、跳、陷。其余几百条指令都可以归进这四类，或者只是同类的变体。这一课用这四类把一段带 if / 循环 / 函数调用的 C 代码完整重写成汇编，你会发现读汇编的门槛一下子低了很多。

这一课要回答的问题

① 四类动作分别覆盖哪些指令？② 一条 if-else 在汇编里长什么样？③ 为什么 cmp 和 bne 总成对出现？④ 函数的开头为什么总要 push {...}？⑤「伪指令」是什么，为什么需要它？

1. 搬：只有两条路

数据只能在两个地方之间流动：寄存器 ↔ 寄存器（mov/mvn），寄存器 ↔ 内存（ldr/str）。ARM 是 load-store 架构：ALU 只能操作寄存器，不能直接操作内存。所以 a += b 在 ARM 上是：

ldr r0, [addr_a]     ; 读 a
ldr r1, [addr_b]     ; 读 b
add r0, r0, r1       ; 算
str r0, [addr_a]     ; 写回 a

四步。x86 可以一条 add [a], ebx 直接改内存——这就是 RISC 与 CISC 最本质的区别：ARM 用更多指令换更简单的硬件。

2. 算：ALU 能做的都不出圈

算术：add、sub、rsb、mul（乘法）、sdiv（除法，ARMv7 后期才有硬件除）。逻辑：and、orr、eor、bic（位清除）、orn。移位：lsl、lsr、asr、ror——它们通常不是独立指令，而是作为操作数修饰符出现。

比较：cmp = subs（只更新标志）、tst = ands（测试某些位）、teq = eors。这三个「比较类」指令的共同点是不写结果寄存器，只写标志。

3. 跳：四种子形态

b    label       ; 无条件，改 PC
bl   func        ; 改 PC 且把返回地址存 LR
bx   reg         ; 跳到寄存器指向的地址（可切换 ARM/Thumb）
beq / bne / blt  ; 条件跳转（看 CPSR 标志）

加上第 11 课讲的「条件执行」（addne 这种），跳转的全部形态就齐了。

4. 陷：唯一的越界通道

svc #0（旧写法 swi #0）把 CPU 从用户态切到内核态，并按 r7 里的编号跳到对应的内核函数。这是 Linux 系统调用的物理实现。

; write(1, "hi\n", 3) 的汇编版（ARM EABI）
    mov  r0, #1          ; fd = 1（stdout）
    adr  r1, msg         ; buf
    mov  r2, #3          ; len
    mov  r7, #4          ; __NR_write
    svc  #0              ; 陷入内核
msg: .ascii "hi\n"

内核侧的入口在 vector_swi，它读 r7 查系统调用表。这条链路把「软件」和「硬件特权级」缝在一起——第 29、30 课会展开。

5. 伪指令：汇编器的善意

有些写法看起来像指令，其实汇编器会翻译成别的东西：

伪指令真实生成用途
ldr r0, =0x12345678常量池里的 ldr 或 movw/movt加载任意 32 位常量
adr r0, labeladd/sub pc 相对偏移取附近地址（位置无关）
nopmov r0, r0占位、对齐、延时
push {r4, lr}stmdb sp!, {...}压栈（GNU 语法糖）

6. 实验：手写一段汇编

// 目标：int max3(int a, int b, int c) 返回最大值
// 手写（AAPCS：参数 r0 r1 r2，返回值 r0）

    .text
    .global max3
max3:
    cmp   r0, r1          ; a vs b
    movlt r0, r1          ; a < b → r0 = b  （条件执行）
    cmp   r0, r2          ; 现在 r0 是 max(a,b)
    movlt r0, r2          ; 若 r0 < c → r0 = c
    bx    lr

// 对照 gcc -O2 的输出，很可能一模一样
// 整个函数 5 条指令、无分支、无栈操作 —— 这就是条件执行的价值

把这段编进一个 C 工程（gcc -c max3.S），在 C 里调用它。跑通一次，你就真的「写过汇编」了。

7. 三条常见误解

8. 自测与动手

1

为什么 ARM 的 a += b 至少要四条指令？

看答案

load-store 架构：ALU 不能直接操作内存，必须先 ldr 到寄存器、运算、再 str 回去。

2

cmp 与 sub 的关系？

看答案

cmp 就是 subs：做减法、更新标志、丢弃结果。

3

为什么函数开头常要 push {r4-r7, lr}？

看答案

保存 callee-saved 寄存器（r4-r11）与返回地址（r14），保证调用者现场不被破坏；这是 AAPCS 的要求。

4

ldr r0, =0x12345678 为什么不能直接是一条指令？

看答案

立即数字段只有 8 位 + 4 位旋转，装不下任意 32 位常量；汇编器会放到常量池或生成 movw/movt。

5

svc 与普通函数调用有什么本质区别？

看答案

svc 会切换 CPU 特权级（用户→内核），并走异常向量表；普通 bl 不改变特权级。

  1. 手写 max3 并编进 C 工程跑通，再与 gcc 输出对比。
  2. 把一段 C 的 for 循环改写成汇编（用后索引寻址）。
  3. 用 strace 看一次 write，确认它对应 svc。
  4. 写一个 .S 文件里的 svc 调用，观察返回值从 r0 出来。
